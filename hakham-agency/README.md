# 하캄솔루션 AI Agent Agency

마케팅 전문 AI 에이전트 에이전시 프로젝트. 클라이언트 브리프 하나로 6개 전문 팀이 협업하여 실행 가능한 마케팅 패키지를 생성한다.

## 프로젝트 개요

하캄솔루션 에이전트 에이전시는 로컬 비즈니스(의료, 법률, 세무 등 전문직 및 일반 서비스업)를 위한 풀스택 마케팅 AI 시스템이다. 오케스트레이터가 클라이언트 브리프를 받아 6개 팀에 작업을 배정하고, 각 팀이 산출물을 생성한 뒤 품질 게이트를 거쳐 최종 실행 패키지를 완성한다.

### 핵심 원칙

- **산출물 우선**: 분석이나 전략에서 끝나지 않고, 바로 집행 가능한 결과물까지 완성
- **사실 기반**: 확인되지 않은 효능, 과장, 보장, 비교비하, 단정 표현 금지
- **컴플라이언스 내장**: 의료광고법 등 업종별 규제를 프로세스에 내장

## 디렉토리 구조

```
hakham-agency/
├── briefs/                  # 클라이언트 브리프 및 인테이크 관련
│   ├── client_brief_template.md   # 브리프 작성 템플릿
│   ├── intake_questions.md        # 필수 확인 질문 가이드
│   └── example_brief_clinic.md    # 예시 브리프 (치과)
│
├── rules/                   # 운영 규칙 및 가이드라인
│   ├── hakham_team_operating_rules.md   # 팀 운영 원칙
│   ├── hakham_compliance_rules.md       # 컴플라이언스 규칙
│   ├── hakham_measurement_rules.md      # 측정 규칙
│   └── tone_of_voice_guide.md           # 톤앤매너 가이드
│
├── protocols/               # 팀 간 핸드오버, 품질 게이트 프로토콜
│
├── agents/                  # 개별 에이전트 프롬프트 및 설정
│
├── teams/                   # 팀별 구성 및 워크플로우
│
└── assets/                  # 템플릿, 이미지, 참고 자료
```

## 사용법

### 1단계: 브리프 작성

`briefs/client_brief_template.md`를 기반으로 클라이언트 정보를 수집한다. 누락된 항목이 있으면 `briefs/intake_questions.md`의 질문으로 보완한다.

```
입력: 클라이언트 원시 정보
출력: 완성된 클라이언트 브리프
```

### 2단계: 오케스트레이터 실행

오케스트레이터(에이전트 00)가 브리프를 분석하고, 갭을 확인한 뒤 팀별 요청 티켓을 발행한다.

```
입력: 완성된 클라이언트 브리프
출력: 프로젝트 실행 계획 + 팀별 요청 티켓
```

### 3단계: 팀별 산출물 생성

6개 팀이 각자의 영역에서 산출물을 생성하고, 핸드오버 포맷으로 제출한다.

```
입력: 요청 티켓 + 클라이언트 브리프
출력: 팀별 산출물 (핸드오버 포맷)
```

### 4단계: 품질 게이트

오케스트레이터가 산출물을 검토하여 통과/수정/반려를 판정한다. 컴플라이언스 이슈는 최우선 처리한다.

```
판정 기준: 실행 가능성, 컴플라이언스, 브리프 일치도, 품질 기준 충족
```

### 5단계: 집행

최종 승인된 산출물을 기반으로 채널별 캘린더, 광고 구조, 측정 체크를 확정하고 집행한다. 48시간 1차 점검 후 7일 단위 개선 루프를 운영한다.

## 최소 패키지 (모든 프로젝트 필수 산출물)

1. **캠페인 원페이지** - 목표, 타깃, 오퍼, 메시지, 채널, KPI
2. **제작 브리프** - 카피/디자인/영상용
3. **집행 구조** - 광고 캠페인 구조 또는 게시 캘린더
4. **측정/리포트 템플릿** - 학습 3개 + 다음 액션 3개
