# 하캄솔루션 톤앤매너 가이드

이 문서는 하캄솔루션 에이전트 에이전시가 생성하는 모든 카피, 콘텐츠, 광고 소재, 커뮤니티 답변에 적용되는 톤앤매너 기준을 정의한다.

---

## 1. 브랜드 보이스 정의

### 핵심 보이스: "전문적이면서 친근한"

하캄솔루션이 만드는 콘텐츠의 톤은 **"믿을 수 있는 이웃 전문가"**다. 권위적이지 않으면서도 전문성이 느껴지고, 가볍지 않으면서도 부담스럽지 않은 톤을 유지한다.

### 보이스 속성 4가지

| 속성 | 정의 | 강도 |
|------|------|------|
| **신뢰감** | 사실과 근거에 기반한 표현. 과장 없이 정확하게 전달한다. | 항상 유지 |
| **전문성** | 해당 분야를 잘 아는 사람이 쓴 글이라는 느낌. 용어를 적절히 사용하되 설명을 곁들인다. | 항상 유지 |
| **친근함** | 딱딱하지 않고 대화하듯 전달한다. 고객의 상황에 공감하는 어조. | 채널에 따라 조절 |
| **실용성** | 읽는 사람이 "그래서 나는 뭘 하면 되지?"를 알 수 있게 쓴다. 행동 유도가 자연스럽다. | 항상 유지 |

### 보이스 스펙트럼

```
격식체 ←─────────────────────────────────→ 구어체
         │               ▲                │
         │          우리의 위치            │
         │                                │
권위적 ←─────────────────────────────────→ 캐주얼
         │               ▲                │
         │          우리의 위치            │
```

- 격식체 쪽으로 치우치지 않는다 (관공서 문체 금지)
- 구어체 쪽으로 치우치지 않는다 (인터넷 유행어 남발 금지)
- 권위적이지 않다 (위에서 내려다보는 톤 금지)
- 지나치게 캐주얼하지 않다 (전문성이 훼손되지 않는 선)

## 2. 업종별 톤 변형

기본 보이스를 유지하되, 업종 특성에 따라 아래와 같이 조절한다.

### 2-1. 의료 (치과, 피부과, 성형외과, 한의원)

| 속성 | 조절 방향 | 이유 |
|------|----------|------|
| 신뢰감 | 강화 (최고 수준) | 건강/신체 관련 의사결정은 신뢰가 핵심 |
| 전문성 | 강화하되 쉽게 풀어 설명 | 전문 용어만 나열하면 고객이 이탈 |
| 친근함 | 중간 (공감 중심) | 과하면 가볍게 보임, 부족하면 차갑게 보임 |
| 실용성 | 강화 (다음 행동 명확히) | "상담 예약"으로 자연스럽게 유도 |

**톤 키워드**: 안심, 정밀, 꼼꼼, 개인 맞춤, 경험

**예시**:
```
Good: "CT 촬영 후 3D 시뮬레이션으로 식립 위치를 미리 확인합니다.
       궁금하신 점은 상담에서 자세히 안내드리겠습니다."

Bad:  "우리 병원은 최첨단 장비로 완벽한 임플란트를 해드립니다!"
```

### 2-2. 법률 (변호사, 법무사)

| 속성 | 조절 방향 | 이유 |
|------|----------|------|
| 신뢰감 | 강화 (최고 수준) | 법률 문제는 불안감이 크므로 신뢰가 핵심 |
| 전문성 | 강화 (법률 용어 + 쉬운 설명 병기) | 전문성이 서비스의 본질 |
| 친근함 | 약간 낮춤 (진중하게) | 법률은 가벼운 톤이 부적절 |
| 실용성 | 강화 (절차 안내) | "어떤 순서로 진행되는지"가 고객의 핵심 관심 |

**톤 키워드**: 명확, 체계적, 경험, 절차, 안내

**예시**:
```
Good: "부당해고를 당하셨다면, 먼저 해고 통지서와 근로계약서를 확인해야 합니다.
       노동위원회 구제 신청은 해고일로부터 3개월 이내에 가능합니다."

Bad:  "해고당하셨나요? 걱정 마세요! 저희가 확실하게 해결해 드립니다!"
```

### 2-3. 세무/회계 (세무사, 회계사)

| 속성 | 조절 방향 | 이유 |
|------|----------|------|
| 신뢰감 | 강화 | 돈과 관련된 서비스이므로 신뢰 필수 |
| 전문성 | 강화 (세법 근거 + 실무 용어) | 세법을 아는 사람이라는 인식이 핵심 |
| 친근함 | 중간 (부담 낮추기) | 세금은 스트레스 요인이므로 심리적 부담을 낮춤 |
| 실용성 | 최대 (절세 방법, 기한, 체크리스트) | 실용적 정보가 가장 큰 가치 |

**톤 키워드**: 절세, 기한, 체크리스트, 정리, 안내

**예시**:
```
Good: "5월 종합소득세 신고 전 확인해야 할 3가지:
       1) 사업용 경비 증빙 정리 2) 기부금 영수증 확인 3) 의료비/교육비 자료 수집"

Bad:  "세금 걱정 끝! 저희에게 맡기시면 세금을 확 줄여드립니다!"
```

### 2-4. 일반 서비스업 (인테리어, 학원, 뷰티 등)

| 속성 | 조절 방향 | 이유 |
|------|----------|------|
| 신뢰감 | 유지 | 기본 수준 유지 |
| 전문성 | 약간 낮춤 (생활 언어 중심) | 전문 용어보다 결과와 경험이 중요 |
| 친근함 | 강화 (대화체) | 일상적 서비스이므로 친근한 톤이 효과적 |
| 실용성 | 강화 (가격, 시간, 절차) | 실용 정보가 의사결정의 핵심 |

**톤 키워드**: 편리, 합리적, 깔끔, 경험, 후기

## 3. 채널별 톤 변형

### 3-1. 블로그 (네이버 블로그, 티스토리)

| 항목 | 기준 |
|------|------|
| 톤 레벨 | 전문성 80% + 친근함 20% |
| 문장 길이 | 1문장 30자 이내 권장, 최대 50자 |
| 문단 길이 | 3-5줄 후 줄바꿈 |
| 존칭 | "-습니다" 체 기본, 필요시 "-요" 체 혼합 |
| 특징 | 정보 제공 중심. 검색 의도에 맞는 답을 먼저 주고, 상세 설명을 이어간다 |

**예시**:
```
Good: "임플란트 수술 시간은 1개 기준 평균 30분~1시간입니다.
       다만 뼈이식이 필요한 경우 추가 시간이 소요될 수 있습니다.

       수술 시간에 영향을 주는 요소 3가지를 정리해 드리겠습니다."

Bad:  "안녕하세요~~ 오늘은 임플란트 수술 시간에 대해 알아볼게요!ㅎㅎ
       다들 궁금하시죠?? 그럼 바로 시작해 볼까요~?"
```

### 3-2. SNS (인스타그램, 스레드)

| 항목 | 기준 |
|------|------|
| 톤 레벨 | 전문성 60% + 친근함 40% |
| 문장 길이 | 1문장 20자 이내 권장 |
| 캡션 길이 | 핵심 3줄 + 상세 (선택) |
| 존칭 | "-요" 체 기본 |
| 특징 | 시각적 콘텐츠에 맞춘 짧고 임팩트 있는 카피. 첫 줄에서 멈추게 만든다 |

**예시**:
```
Good: "교정 1년 차, 변화가 보이기 시작합니다.
       매달 체크업 때마다 기록한 사진이에요.

       투명교정이 궁금하시면 프로필 링크에서 상담 예약하세요."

Bad:  "교정 전후 사진 공개합니다!! 놀라운 변화!!
       지금 바로 상담받으세요!! 선착순 할인!!"
```

### 3-3. 광고 카피 (검색광고, 메타 광고)

| 항목 | 기준 |
|------|------|
| 톤 레벨 | 실용성 70% + 신뢰감 30% |
| 문장 길이 | 헤드라인 15자 이내, 설명 30자 이내 |
| 존칭 | 생략 또는 "-요" 체 |
| 특징 | 핵심 정보(지역, 서비스, 차별점)를 최소 글자로 전달. CTA가 명확해야 한다 |

**예시**:
```
Good: [헤드라인] 역삼역 5분, 디지털 임플란트
      [설명] 3D 가이드 수술 / 평균 30분 / 지금 상담 예약

Bad:  [헤드라인] 강남 최고의 임플란트 치과
      [설명] 최신 장비 완비! 부담 없는 가격! 지금 바로!
```

### 3-4. 랜딩 페이지

| 항목 | 기준 |
|------|------|
| 톤 레벨 | 신뢰감 40% + 실용성 40% + 친근함 20% |
| 문장 길이 | 섹션별 상이 (히어로: 짧게, 상세: 보통) |
| 존칭 | "-습니다" 체 기본 |
| 특징 | 스크롤에 따라 신뢰를 쌓아가는 구조. 각 섹션이 "왜 여기?"에 답한다 |

**예시 (히어로 섹션)**:
```
Good: "점심시간에 끝나는 임플란트 상담
       역삼역 3번 출구 도보 5분

       [오늘 빈 시간 확인하기]"

Bad:  "강남 최고의 임플란트!
       놀라운 가격! 놀라운 실력!

       [지금 바로 예약!]"
```

## 4. 금지 톤

아래 톤은 어떤 채널, 어떤 업종에서도 사용하지 않는다.

### 4-1. 과장 톤

말의 크기를 키워서 관심을 끌려는 톤. 신뢰를 훼손한다.

```
Bad:  "놀라운 효과!" / "기적 같은 변화!" / "이것만 알면 인생이 바뀝니다!"
Good: "3개월간의 변화를 사진으로 확인하세요." / "많은 분들이 궁금해하시는 3가지"
```

### 4-2. 불안 조성 톤

공포심이나 불안감을 자극하여 행동을 유도하는 톤. 특히 의료 업종에서 위험하다.

```
Bad:  "이대로 두면 큰일 납니다!" / "지금 안 하면 늦습니다!" / "당신의 치아가 위험합니다!"
Good: "조기에 확인하면 치료 옵션이 더 다양합니다." / "정기 검진을 통해 미리 확인하는 것을 권합니다."
```

### 4-3. 비하 톤

경쟁사, 다른 시술법, 고객의 현재 상태를 깎아내리는 톤.

```
Bad:  "다른 치과에서 실패하셨나요?" / "저렴한 곳에서 하면 이렇게 됩니다" / "아직도 그 방법을?"
Good: "다른 곳에서 시작한 치료도 이어서 진행 가능합니다." / "다양한 방법 중 본인에게 맞는 것을 함께 찾아드립니다."
```

### 4-4. 강매 톤

지나치게 적극적으로 구매/예약을 압박하는 톤.

```
Bad:  "지금 바로!! 예약하세요!!" / "오늘만 이 가격!" / "선착순 마감 임박!!"
Good: "궁금하신 점이 있으시면 상담에서 자세히 안내드리겠습니다." / "편하실 때 예약해 주세요."
```

### 4-5. 무책임 톤

근거 없이 결과를 약속하거나, 책임을 회피하는 톤.

```
Bad:  "무조건 만족!" / "실패 걱정 제로!" / "알아서 다 해드립니다~"
Good: "시술 전 충분한 상담을 통해 기대와 현실을 함께 조율합니다."
```

## 5. Good/Bad 대조 종합표

| 상황 | Bad | Good |
|------|-----|------|
| 서비스 소개 | "최고의 실력으로 완벽한 결과" | "대한교정학회 정회원, 누적 2,000케이스 경험" |
| 통증 관련 | "무통 시술! 아프지 않습니다" | "통증을 줄이기 위해 디지털 가이드 방식을 적용합니다" |
| 가격 안내 | "파격적인 가격! 부담 제로!" | "상담 시 개인별 치료 계획과 비용을 안내드립니다" |
| CTA | "지금 당장 전화하세요!!!" | "궁금하신 점은 전화 또는 온라인으로 편하게 문의해 주세요" |
| 경쟁 차별화 | "다른 곳과는 차원이 다릅니다" | "X-Guide 디지털 가이드 시스템으로 수술 전 식립 위치를 3D로 확인합니다" |
| 후기 활용 | "모든 환자분이 만족하셨습니다" | "실제 내원하신 분의 후기입니다 (개인 경험이며, 결과는 개인에 따라 다를 수 있습니다)" |
| 예약 유도 | "마감 임박! 서두르세요!" | "온라인 예약 시 원하시는 시간을 선택하실 수 있습니다" |
| 전문성 표현 | "이 분야의 신" / "갓OO" | "해당 분야 15년 진료, OO학회 정회원" |
| 시술 설명 | "간단한 시술입니다~" | "개인 상태에 따라 다르지만, 일반적으로 OO분 내외로 진행됩니다" |
| 문제 인식 | "이 증상 방치하면 큰일!" | "해당 증상이 지속된다면 전문가 상담을 권합니다" |
