# 하캄솔루션 컴플라이언스 규칙

이 문서는 하캄솔루션 에이전트 에이전시의 모든 산출물에 적용되는 컴플라이언스 규칙을 정의한다. 컴플라이언스 이슈는 **최우선 순위**로 처리하며, 위반이 발견되면 산출물 전체를 반려한다.

---

## 1. 의료광고법 주요 조항 요약

의료법 제56조(의료광고의 금지 등) 및 의료법 시행령 관련 조항을 기반으로 마케팅 산출물에 적용하는 핵심 규칙이다.

### 1-1. 금지되는 의료광고 (의료법 제56조)

| 항목 | 내용 | 마케팅 적용 |
|------|------|------------|
| 거짓/과장 광고 | 의료인의 기능/진료 방법에 대해 거짓/과장 금지 | 검증 불가 수치, 과장된 효과 표현 전면 금지 |
| 비교/비방 광고 | 다른 의료기관을 비방/비교하는 광고 금지 | 타 기관 언급, 우위 비교 표현 금지 |
| 객관적 사실 위배 | 객관적으로 인정되지 않거나 근거 없는 내용 금지 | 학술적 근거 없는 효과 주장 금지 |
| 소비자 기만 | 소비자를 기만하거나 오인하게 하는 내용 금지 | 모호한 표현, 오해 유발 문구 금지 |
| 수술 장면 직접 노출 | 수술 장면을 직접적으로 노출하는 광고 금지 | 수술 중 사진/영상 사용 금지 |
| 환자 유인 | 부당한 경제적 이익으로 환자를 유인하는 광고 금지 | "무료 시술", "공짜 상담" 등 과도한 혜택 표현 주의 |

### 1-2. 의료광고 사전 심의 대상

- TV, 라디오, 신문, 잡지, 인터넷 매체 등에 게재하는 의료광고
- 실무 적용: 블로그, SNS, 유튜브 등 온라인 매체도 포함 대상임을 인지하고, 심의 수준의 기준을 자체 적용

## 4. 전후 사진 규칙

### 사용 가능 조건 (모두 충족 시)

1. **환자 서면 동의**: 마케팅 활용 동의서를 서면으로 확보
2. **동일 촬영 조건**: 조명, 각도, 거리가 동일해야 함
3. **보정 금지**: 포토샵 등으로 과도한 보정 금지 (밝기/대비 보정 정도만 허용)
4. **개인정보 보호**: 환자 식별 정보(이름, 얼굴) 노출 금지 또는 별도 동의
5. **기간 명시**: "시술 후 OO개월 시점" 등 촬영 시점 명시
6. **대표성 주의**: "개인차가 있으며, 모든 분께 동일한 결과를 보장하지 않습니다" 고지문 필수

### 금지 사항

- 동의서 없는 환자 사진 사용
- 다른 환자의 사진을 합성하거나 차용
- 촬영 조건이 다른 사진을 전후 비교로 사용 (조명/각도 조작)
- 타 의료기관 사진 무단 사용

## 5. 후기 사용 규칙

### 사용 가능 조건

1. **작성자 동의**: 마케팅 활용에 대한 동의 확보
2. **대가성 명시**: 대가(할인, 사은품 등)를 제공한 경우 반드시 명시 ("본 후기는 OO을 제공받고 작성되었습니다")
3. **사실 확인**: 후기 내용이 실제 시술/서비스와 일치하는지 확인
4. **효과 보장 아님 명시**: "개인의 경험이며, 결과는 개인에 따라 다를 수 있습니다" 고지
5. **수정 금지**: 후기 내용을 임의로 수정하거나 과장하지 않음 (오타 수정 정도만 허용)

### 금지 사항

- 가짜 후기 작성 (자작 후기)
- 후기 내용 왜곡/과장
- 부정적 후기만 삭제하고 긍정적 후기만 노출
- 의료 효과를 단정적으로 표현하는 후기를 선별적으로 활용

## 6. 가격 표시 규칙

### 허용

- 실제 시술/서비스 가격을 정확하게 표시
- "상담 후 개인별 견적 안내" 표현
- 가격대 범위 표시 (예: "임플란트 1개 기준 OO만원~OO만원")

### 주의

- 할인율 표시 시 원래 가격이 실제로 적용된 적 있어야 함 (허위 할인 금지)
- "~부터" 가격 표시 시 최저 가격에 해당하는 서비스 조건을 명시
- 부가세 포함/별도 여부 명시

### 금지

- 허위 할인 (원래 가격을 부풀려 할인율을 과장)
- 미끼 가격 (극히 제한적인 조건의 가격만 노출하고 실제 상담에서 업셀링)
- "무료", "공짜" 표현 (의료 업종)
- 타 기관 가격과의 직접 비교

## 7. 전문직별 특수 규제

### 7-1. 의료 (치과, 피부과, 성형외과, 한의원 등)

| 규제 항목 | 내용 |
|----------|------|
| 근거법 | 의료법 제56조, 의료법 시행령 제23조~제24조 |
| 사전심의 | 의료광고는 사전 심의를 받아야 함 (단, 의료기관 명칭/위치/진료과목 등 단순 정보 제외) |
| 전문의 표기 | 전문의 자격을 보유한 경우에만 "OO 전문의" 표기 가능 |
| 비급여 가격 | 비급여 진료 항목의 가격 공개는 허용 (오히려 권장) |
| 치료 경험담 | 환자의 치료 경험담은 사전 동의 + 개인차 고지 필수 |
| 의료기기 광고 | 식약처 허가/인증된 의료기기만 언급 가능 |

### 7-2. 법률 (변호사, 법무사)

| 규제 항목 | 내용 |
|----------|------|
| 근거법 | 변호사법 제23조, 대한변호사협회 변호사 광고에 관한 규정 |
| 성공률 표기 | "승소율 OO%" 등 성공률/승소율 광고 금지 |
| 결과 보장 | "반드시 이긴다", "확실한 결과" 등 결과 보장 표현 금지 |
| 수임료 광고 | 과도하게 저렴한 수임료 광고 주의 (품위 유지 의무) |
| 전문 분야 | "OO 전문"은 대한변호사협회 등록 전문 분야에 한해 사용 |
| 타 변호사 비방 | 다른 변호사/법무법인 비방 금지 |

### 7-3. 세무/회계 (세무사, 회계사)

| 규제 항목 | 내용 |
|----------|------|
| 근거법 | 세무사법 제12조, 공인회계사법 |
| 결과 보장 | "세금 OO% 절감 보장" 등 결과 보장 금지 |
| 탈세 조장 | 탈세를 조장하거나 암시하는 표현 절대 금지 |
| 자격 표기 | 세무사/회계사 자격 등록 번호 표기 권장 |
| 비밀유지 | 고객 사례를 활용할 때 개인정보/기업정보 익명화 필수 |
| 수수료 광고 | 과당 경쟁을 유발하는 수수료 광고 주의 |

## 8. 컴플라이언스 체크 프로세스

모든 산출물은 게시/집행 전 아래 체크리스트를 통과해야 한다.

### 체크리스트

- [ ] 금지 표현 32개 항목 중 사용된 것이 없는가?
- [ ] 조건부 표현은 근거가 첨부되어 있는가?
- [ ] 전후 사진은 6개 조건을 모두 충족하는가?
- [ ] 후기는 5개 조건을 모두 충족하는가?
- [ ] 가격 표시는 규칙을 준수하는가?
- [ ] 업종별 특수 규제를 확인했는가?
- [ ] 비교/비하 표현이 없는가?
- [ ] 효과를 단정/보장하는 표현이 없는가?
- [ ] 고지문(개인차, 대가성 등)이 필요한 곳에 포함되어 있는가?

### 위반 발견 시 처리

1. 산출물 **즉시 반려**
2. 위반 항목과 위치를 구체적으로 명시하여 오너 팀에 전달
3. 대체 표현을 제안
4. 수정 후 재검토 (컴플라이언스 항목만 집중 확인)
5. 반복 위반 시 해당 팀의 전체 산출물을 재검토
