# 필수 확인 질문 가이드

브리프에 누락되거나 모호한 정보가 있을 때 사용하는 질문 목록이다. 오케스트레이터는 이 목록에서 **5개 이내**로 선별하여 클라이언트에게 확인한다. 답을 가정하지 않는다.

---

## 1. 비즈니스 기본

브리프의 업종, 경쟁 환경, 매출 구조를 파악하기 위한 질문이다.

| # | 질문 | 왜 필요한가 |
|---|------|-------------|
| 1-1 | 업종 내 세부 전문 분야가 있습니까? (예: 치과 중 임플란트 전문, 교정 전문) | 타깃과 메시지가 완전히 달라진다 |
| 1-2 | 개원/창업 시점은 언제입니까? | 신규(인지도 구축)와 기존(전환 최적화) 전략이 다르다 |
| 1-3 | 현재 월 매출 규모는 어느 정도입니까? (대략적 범위도 가능) | 예산 대비 ROI 기대치 설정에 필요하다 |
| 1-4 | 주요 경쟁업체 2-3곳을 알고 계십니까? (상호명 또는 위치) | 포지셔닝과 차별화 전략 설계에 필수다 |
| 1-5 | 매출 비중이 가장 높은 서비스는 무엇입니까? | 마케팅 자원을 집중할 서비스를 결정한다 |
| 1-6 | 시즌별 매출 차이가 있습니까? (예: 여름 성수기, 연말 비수기) | 캘린더와 예산 배분에 반영한다 |
| 1-7 | 직원 수와 하루 수용 가능한 고객/상담 수는? | 과도한 문의 유입 시 서비스 품질 저하를 방지한다 |

---

## 2. 타깃 고객

타깃의 구체적 상황, 행동 패턴, 의사결정 과정을 파악하기 위한 질문이다.

| # | 질문 | 왜 필요한가 |
|---|------|-------------|
| 2-1 | 가장 많이 오시는 고객의 연령대와 성별은? | 페르소나 설계의 기본 데이터다 |
| 2-2 | 고객이 처음 문의할 때 가장 많이 하는 질문 3가지는? | 콘텐츠와 광고 메시지의 핵심이 된다 |
| 2-3 | 고객이 결정을 망설이는 가장 큰 이유는? (가격/시간/불안/기타) | 반론 처리 전략과 CTA 설계에 필수다 |
| 2-4 | 고객이 귀사를 처음 알게 되는 경로는? (검색/소개/SNS/간판) | 채널 우선순위를 정하는 근거다 |
| 2-5 | 단골/재방문 고객 비율은 어느 정도입니까? | 신규 획득 vs. 리텐션 전략 비중을 결정한다 |
| 2-6 | 고객의 평균 객단가(1회 이용 금액)는? | CPL/CPA 목표 설정의 기준이 된다 |
| 2-7 | 주로 어떤 시간대/요일에 문의가 집중됩니까? | 광고 스케줄링과 콘텐츠 게시 시간에 반영한다 |
| 2-8 | 기존 고객 중 "이상적인 고객" 유형을 한 문장으로 묘사한다면? | 타깃 페르소나의 핵심 기준이 된다 |

---

## 3. 마케팅 현황

현재 운영 중인 마케팅 활동, 예산, 성과를 파악하기 위한 질문이다.

| # | 질문 | 왜 필요한가 |
|---|------|-------------|
| 3-1 | 현재 마케팅에 월 얼마를 쓰고 있습니까? (광고비/대행비/제작비 분리) | 예산 배분과 채널 전략의 기본 제약이다 |
| 3-2 | 지금 가장 효과 있다고 느끼는 채널은? 왜? | 기존 성과를 활용한 전략 설계에 참고한다 |
| 3-3 | 지금 가장 효과 없다고 느끼는 채널은? 왜? | 개선 또는 중단 판단에 필요하다 |
| 3-4 | 마케팅 대행사를 이용 중이거나 이전에 이용한 적이 있습니까? 만족/불만족 이유는? | 기대 수준과 과거 실패 원인을 파악한다 |
| 3-5 | 네이버 플레이스(또는 구글 마이비즈니스) 리뷰 수와 평점은? | 신뢰 자산의 현재 수준을 파악한다 |
| 3-6 | 블로그/SNS 게시물을 직접 작성합니까, 외주를 주십니까? | 콘텐츠 생산 체계와 현실적 발행 빈도를 파악한다 |
| 3-7 | 광고 소재(이미지/영상)를 자체 제작할 수 있습니까? | 제작 브리프의 상세 수준을 결정한다 |
| 3-8 | 현재 전환 추적(GA4, 픽셀, 네이버 전환추적)이 설치되어 있습니까? | 측정 환경 구축 우선순위를 결정한다 |

## 4. 컴플라이언스

업종별 광고 규제, 금지 표현, 법적 제약을 확인하기 위한 질문이다. **이 영역의 미확인은 작업 시작을 차단한다.**

| # | 질문 | 왜 필요한가 |
|---|------|-------------|
| 4-1 | 귀사의 업종에 광고 관련 법적 규제가 있습니까? (의료광고법, 변호사광고규정 등) | 모든 산출물의 표현 범위를 결정한다 |
| 4-2 | 전후 사진(Before/After)을 광고에 사용할 수 있습니까? 환자/고객 동의를 받고 있습니까? | 의료광고법 위반 리스크를 사전에 차단한다 |
| 4-3 | 고객 후기/리뷰를 마케팅 소재로 사용해도 됩니까? 동의 절차가 있습니까? | 후기 활용 시 동의 없으면 법적 문제가 된다 |
| 4-4 | 가격이나 할인 정보를 공개적으로 노출할 수 있습니까? | 의료/법률 업종은 가격 광고에 제한이 있다 |
| 4-5 | "최고", "최초", "유일", "보장" 같은 표현에 대한 내부 가이드가 있습니까? | 금지 표현 목록의 기준이 된다 |
| 4-6 | 관련 자격증, 인증, 수상 내역 중 광고에 활용 가능한 것은? | 사실 기반 신뢰 요소로 활용한다 |
| 4-7 | 과거에 광고 심의나 행정 지도를 받은 적이 있습니까? | 반복 위반 리스크를 사전에 파악한다 |

---

## 5. 목표/KPI

기대 성과, 측정 기준, 성공 정의를 확인하기 위한 질문이다.

| # | 질문 | 왜 필요한가 |
|---|------|-------------|
| 5-1 | 마케팅으로 달성하고 싶은 가장 중요한 목표 1가지는? | 주 KPI를 설정하는 기준이다 |
| 5-2 | 월 문의/예약/상담 건수 목표가 있습니까? (구체적 숫자) | KPI 목표값을 설정한다 |
| 5-3 | 현재 문의 1건당 비용(CPL)은 얼마입니까? 목표 CPL은? | 퍼포먼스 팀의 기준선이 된다 |
| 5-4 | 마케팅 성과를 "성공"이라고 판단하는 기준은 무엇입니까? | 품질 게이트와 리포트의 기준이다 |
| 5-5 | 단기(1개월) 목표와 중기(3개월) 목표를 구분할 수 있습니까? | 실행 계획의 페이즈를 나눈다 |
| 5-6 | 마케팅 성과를 누가, 어떻게 확인하고 있습니까? | 리포트 수신자와 형식을 결정한다 |
| 5-7 | 성과가 기대에 못 미칠 때 예산/채널 변경이 가능합니까? | 최적화 루프의 자유도를 파악한다 |
| 5-8 | 이전 마케팅에서 가장 좋았던 성과 수치는? (최고 월 문의 수, 최저 CPL 등) | 현실적 목표 설정의 벤치마크가 된다 |

---

## 질문 선별 원칙

1. **5개 이내**: 클라이언트에게 한 번에 5개를 초과하지 않는다
2. **우선순위**: 컴플라이언스 > 목표/KPI > 타깃 > 비즈니스 기본 > 마케팅 현황
3. **중복 제거**: 브리프에 이미 답이 있는 항목은 질문하지 않는다
4. **구체화 요청**: "좀 더 자세히" 대신 "월 몇 건입니까?" 식으로 구체적으로 묻는다
5. **가정 금지**: 질문 대신 추측으로 넘어가는 것을 금지한다
