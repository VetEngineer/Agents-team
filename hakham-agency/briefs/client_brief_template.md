# 클라이언트 브리프 템플릿

## 브리프 작성 안내

이 브리프는 하캄솔루션 에이전트 에이전시의 **모든 작업의 출발점**이다. 브리프의 완성도가 산출물의 품질을 결정한다.

### 작성 원칙

1. **빈칸 없이 작성**: 모든 항목을 가능한 한 구체적으로 채운다
2. **모르면 "미정"으로 표시**: 빈칸으로 두지 말고 "미정" 또는 "확인 필요"로 표기한다
3. **사실만 기재**: 희망 사항이 아닌 현재 확인된 사실을 적는다
4. **수치가 있으면 수치로**: "많이" 대신 "월 50건", "좋은 편" 대신 "CTR 2.3%"

### 누락 항목 처리 규칙

- 필수 항목이 비어 있거나 모호하면, 오케스트레이터가 **필수 확인 질문을 5개 이내로 제시**한다
- 답을 가정하지 않는다 (추측으로 작업을 시작하지 않음)
- 질문에 대한 답변이 돌아온 후에 팀별 작업을 배정한다
- 컴플라이언스 관련 항목이 비어 있으면 **최우선으로 확인**한다
