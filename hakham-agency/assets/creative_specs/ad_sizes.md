# 광고 사이즈 규격 가이드

> 플랫폼별 광고 소재 및 텍스트 규격 정리. 2024-2025년 기준이며, 플랫폼 업데이트에 따라 변경될 수 있다.

## 메타 광고 (Facebook / Instagram)

### 이미지 광고

| 배치 | 사이즈 (px) | 비율 | 파일 형식 | 최대 용량 | 안전 영역 |
|------|------------|------|----------|----------|----------|
| 피드 (정사각) | 1080 x 1080 | 1:1 | JPG, PNG | 30MB | 상하좌우 각 50px 여백 권장 |
| 피드 (세로) | 1080 x 1350 | 4:5 | JPG, PNG | 30MB | 상단 100px, 하단 150px 텍스트 영역 피하기 |
| 스토리/릴스 | 1080 x 1920 | 9:16 | JPG, PNG | 30MB | 상단 250px (프로필), 하단 350px (CTA 버튼) 피하기 |
| 캐러셀 | 1080 x 1080 | 1:1 | JPG, PNG | 30MB | 카드 간 연속성 고려 시 좌우 50px 여백 |
| 우측 컬럼 | 1200 x 1200 | 1:1 | JPG, PNG | 30MB | 작게 표시되므로 텍스트 최소화 |

### 텍스트 규격

| 항목 | 권장 길이 | 최대 길이 | 비고 |
|------|----------|----------|------|
| 기본 텍스트 | 125자 | 제한 없음 | 125자 초과 시 "더 보기"로 접힘 |
| 헤드라인 | 40자 | 제한 없음 | 40자 초과 시 잘림 가능 |
| 설명 | 30자 | 제한 없음 | 모든 배치에 표시되지 않음 |
| 링크 URL | - | - | UTM 파라미터 포함 권장 |

### 메타 광고 체크리스트
- [ ] 이미지 내 텍스트 비율 20% 이하 권장 (정책 완화되었으나 여전히 성과에 영향)
- [ ] 세로형(4:5) 소재 준비 (피드에서 화면 점유율 높음)
- [ ] 스토리/릴스용 9:16 소재 별도 제작
- [ ] CTA 버튼 영역과 소재 하단 요소 겹침 확인

## 네이버 검색광고

### 파워링크

| 항목 | 규격 | 비고 |
|------|------|------|
| 제목 | 15자 이내 | 한글 기준. 영문/숫자는 2자 = 한글 1자 |
| 설명 | 45자 이내 | 줄바꿈 불가 |
| 표시 URL | 35자 이내 | 도메인 기준 |
| 확장 소재 (추가 제목) | 15자 이내 | 선택 |
| 확장 소재 (추가 설명) | 25자 이내 | 선택 |

| 항목 | 규격 | 비고 |
|------|------|------|
| 상품 이미지 | 250 x 250 (최소) | 정사각형 필수, 흰 배경 권장 |
| 상품명 | 50자 이내 | 키워드 포함 권장 |
| 파일 형식 | JPG, PNG | GIF 불가 |

## 소재 제작 범용 체크리스트

- [ ] 각 플랫폼별 안전 영역을 지켰는가
- [ ] 텍스트가 작은 화면에서도 읽히는 크기인가 (모바일 우선)
- [ ] 핵심 메시지가 3초 이내에 인식되는가
- [ ] 브랜드 로고/요소가 일관되게 적용되었는가
- [ ] 파일 용량이 플랫폼 제한 이내인가
- [ ] 다크모드에서도 가독성이 확보되는가
- [ ] 컴플라이언스 검수를 완료했는가 (safe_claims_examples.md 참고)
