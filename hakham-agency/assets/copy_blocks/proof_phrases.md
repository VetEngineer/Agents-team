# 증거 문구 라이브러리

> 신뢰를 높이는 팩트 기반 문구 모음. 각 문구는 검증 후 사용해야 하며, 컴플라이언스 주의사항을 반드시 확인한다.

---

## 자격/인증 (10개)

### 1. "[전문의/변호사/세무사] 자격 보유"
- **텍스트 예시:** "대한[학회명] 인증 [과목] 전문의가 직접 진료합니다"
- **사용처:** 블로그 소개, 랜딩페이지 신뢰 섹션, 광고 헤드라인
- **검증 필요 여부:** 필수 - 자격증 사본 확인
- **컴플라이언스:** 의료법상 전문의 표기는 해당 전문과목만 가능. 복수 자격 표기 시 각각 검증.

### 2. "[학회명] 정회원"
- **텍스트 예시:** "대한구강악안면외과학회 정회원"
- **사용처:** 블로그 저자 소개, 랜딩페이지 신뢰 배지
- **검증 필요 여부:** 필수 - 학회 회원 상태 연 1회 확인
- **컴플라이언스:** 학회 정회원과 이사/임원은 구분 표기. 탈퇴/휴면 상태에서 사용 금지.

### 3. "[N]년 경력"
- **텍스트 예시:** "15년 경력의 피부과 전문의"
- **사용처:** 블로그, 랜딩페이지, 광고
- **검증 필요 여부:** 필수 - 개업 시점 또는 경력 시작점 기준 확인
- **컴플라이언스:** 경력 계산 기준을 명확히 한다(면허 취득 후? 개원 후? 해당 분야 전환 후?).

### 4. "[대학교/기관] 출신"
- **텍스트 예시:** "서울대학교 의과대학 졸업"
- **사용처:** 블로그 저자 소개, 랜딩페이지
- **검증 필요 여부:** 필수 - 졸업증명서 확인
- **컴플라이언스:** 수료와 졸업을 구분한다. 연수/연수과정은 "수료"로 표기.

### 5. "[자격증/인증명] 취득"
- **텍스트 예시:** "CFP(국제공인재무설계사) 자격 보유"
- **사용처:** 블로그, 랜딩페이지 신뢰 섹션
- **검증 필요 여부:** 필수 - 자격증 유효 기간 확인
- **컴플라이언스:** 갱신형 자격증은 유효 기간 내인지 확인. 만료된 자격 표기 금지.

### 6. "[수상/선정] 이력"
- **텍스트 예시:** "2024년 [매체명] 선정 [분야] 우수 [업종]"
- **사용처:** 랜딩페이지 신뢰 배지, 블로그
- **검증 필요 여부:** 필수 - 수상 증빙 확인
- **컴플라이언스:** 유료 광고성 선정(돈을 내고 받은 상)은 사용에 주의. 소비자가 객관적 평가로 오인할 수 있다.

### 7. "[기관명] 지정/인증 [업종]"
- **텍스트 예시:** "보건복지부 지정 전문병원"
- **사용처:** 랜딩페이지, 광고
- **검증 필요 여부:** 필수 - 지정 유효 기간 확인
- **컴플라이언스:** 지정 기간이 만료되면 즉시 삭제. 지정 범위를 정확히 표기(예: 특정 질환군만 지정).

### 8. "해외 [학회/기관] 연수 이력"
- **텍스트 예시:** "미국 [기관명] 임상 연수 수료"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - 연수 증명서 확인
- **컴플라이언스:** "연수"와 "자격 취득"을 혼동하지 않는다. 단기 참관을 장기 연수처럼 표현 금지.

### 9. "[교수/강사] 이력"
- **텍스트 예시:** "[대학교] 의과대학 외래교수"
- **사용처:** 블로그 저자 소개, 랜딩페이지
- **검증 필요 여부:** 필수 - 현재 재직 상태 확인
- **컴플라이언스:** 전임/외래/겸임을 구분 표기. 퇴직 후 "전(前)"을 붙이거나 삭제한다.

### 10. "전문 분야 집중 [N]년"
- **텍스트 예시:** "임플란트 시술 집중 10년"
- **사용처:** 블로그, 광고
- **검증 필요 여부:** 권장 - 진료 분야 이력 기준 확인
- **컴플라이언스:** "집중"이라는 표현은 해당 분야 매출/건수가 전체의 상당 비율을 차지할 때 사용. 단순 경력 기간과 구분.

## 시설/장비 (5개)

### 1. "최신 [장비명] 도입"
- **텍스트 예시:** "2024년형 [브랜드] [장비명] 도입, 보다 정밀한 시술이 가능합니다"
- **사용처:** 블로그 (장비 소개 포스트), 랜딩페이지
- **검증 필요 여부:** 필수 - 장비 구매/리스 증빙
- **컴플라이언스:** "최신"은 실제 최신 모델일 때만 사용. 구형 모델이면 "도입" 또는 "보유"로 표현. 장비 효과를 과장하지 않는다.

### 2. "독립 [시술/상담]실 운영"
- **텍스트 예시:** "완전 독립된 상담실에서 프라이버시를 보장합니다"
- **사용처:** 블로그, 랜딩페이지 시설 소개
- **검증 필요 여부:** 권장 - 시설 사진으로 확인
- **컴플라이언스:** 실제로 칸막이가 아닌 완전 분리된 공간일 때 "독립"이라고 표기.

### 3. "무균/멸균 시스템 운영"
- **텍스트 예시:** "1인 1기구 원칙, 멸균 시스템을 운영합니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - 멸균 프로세스 문서화 확인
- **컴플라이언스:** 의료기관은 법적 의무 사항이므로 차별화 포인트로 강조하되, 타 기관이 하지 않는 것처럼 표현하면 비교 비하에 해당할 수 있다.

### 4. "[면적/규모] 전용 공간"
- **텍스트 예시:** "200평 규모의 쾌적한 진료 공간"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 권장 - 임대차계약서 또는 도면 확인
- **컴플라이언스:** 전용 면적과 공용 면적을 혼동하지 않는다.

### 5. "CCTV/안전 관리 시스템"
- **텍스트 예시:** "원내 CCTV 운영 및 안전 관리 체계를 갖추고 있습니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - CCTV 설치 및 개인정보 처리방침 확인
- **컴플라이언스:** CCTV 운영 시 개인정보보호법 준수 여부 확인. 촬영 범위, 보관 기간 고지 필요.

## 프로세스/사후관리 (5개)

### 1. "시술 후 [기간] 무료 경과 확인"
- **텍스트 예시:** "시술 후 3개월간 무료 경과 확인 프로그램을 운영합니다"
- **사용처:** 블로그, 랜딩페이지, 광고
- **검증 필요 여부:** 필수 - 실제 프로그램 운영 여부 확인
- **컴플라이언스:** 무료 범위를 명확히 한다(경과 확인만? 추가 시술 포함?). 조건부라면 조건 병기.

### 2. "[N]단계 체계적 [상담/관리] 프로세스"
- **텍스트 예시:** "5단계 체계적 상담 프로세스로 꼼꼼하게 안내합니다"
- **사용처:** 블로그 (프로세스 소개), 랜딩페이지
- **검증 필요 여부:** 권장 - 프로세스 문서화 확인
- **컴플라이언스:** 각 단계가 실제로 구분되고 의미 있는 차이가 있어야 한다. 형식적 단계 나열은 지양.

### 3. "24시간 비상 연락 체계"
- **텍스트 예시:** "시술 후 불편 사항은 24시간 비상 연락 체계를 통해 대응합니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - 실제 연락 가능 여부 테스트
- **컴플라이언스:** 24시간 연락이 불가능하면 사용 금지. 실제 응대 가능 시간을 정직하게 표기.

### 4. "맞춤형 [사후관리/케어] 프로그램"
- **텍스트 예시:** "개인별 맞춤 사후관리 프로그램을 제공합니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 권장 - 프로그램 내용 확인
- **컴플라이언스:** "맞춤형"이라면 실제로 개인화된 요소가 있어야 한다. 모든 고객에게 동일한 프로그램이면 "표준 사후관리 프로그램"으로 표현.

### 5. "상담 내용 문서화 제공"
- **텍스트 예시:** "상담 내용을 문서로 정리하여 제공합니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 권장 - 샘플 문서 확인
- **컴플라이언스:** 개인정보가 포함된 문서의 전달 방식(암호화, 보안 등)을 확인한다.

## 접근성/편의 (5개)

### 1. "[역명] 도보 [N]분"
- **텍스트 예시:** "강남역 2번 출구 도보 3분"
- **사용처:** 블로그, 광고, 랜딩페이지, SNS
- **검증 필요 여부:** 필수 - 실제 도보 시간 측정
- **컴플라이언스:** 도보 시간은 성인 평균 보행 속도(분속 약 80m) 기준으로 정직하게 표기.

### 2. "주말/야간 진료(운영) 가능"
- **텍스트 예시:** "토요일 진료 가능 | 평일 야간 20시까지"
- **사용처:** 블로그, 광고, 랜딩페이지
- **검증 필요 여부:** 필수 - 실제 운영 시간 확인
- **컴플라이언스:** 운영 시간 변경 시 모든 채널에서 즉시 업데이트한다.

### 3. "주차 [N]대 가능 / 무료 주차"
- **텍스트 예시:** "건물 내 무료 주차 30대 가능"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - 주차 조건 확인
- **컴플라이언스:** 시간 제한, 유효성 검증(주차 도장 등) 조건이 있으면 반드시 명시.

### 4. "키즈존/대기 공간 완비"
- **텍스트 예시:** "어린이 동반 고객을 위한 키즈존을 운영합니다"
- **사용처:** 블로그, SNS
- **검증 필요 여부:** 권장 - 시설 사진 확인
- **컴플라이언스:** 키즈존 안전 기준을 충족하는지 확인. 보호자 없이 아동을 맡기는 서비스가 아님을 명시.

### 5. "장애인 편의시설 완비"
- **텍스트 예시:** "엘리베이터, 장애인 화장실 등 편의시설을 갖추고 있습니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - 시설 현황 확인
- **컴플라이언스:** 장애인편의법 기준 충족 여부를 확인한다. "완비"라고 하려면 법적 기준을 모두 충족해야 한다.

## 실적/경험 (5개)

### 1. "누적 [N]건 [시술/상담] 경험"
- **텍스트 예시:** "누적 5,000건 이상의 임플란트 시술 경험"
- **사용처:** 블로그, 랜딩페이지, 광고
- **검증 필요 여부:** 필수 - 실적 데이터 근거 확인 (차트/EMR 등)
- **컴플라이언스:** 건수의 기준을 명확히 한다(개원 이후? 전체 경력? 특정 시술만?). 의료법상 과대광고에 해당하지 않는지 확인.

### 2. "[N]년 연속 [지역] 운영"
- **텍스트 예시:** "강남에서 12년 연속 운영, 지역 기반 신뢰를 쌓아왔습니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - 사업자등록 이력 확인
- **컴플라이언스:** 이전/휴업 기간이 있었으면 "연속"을 사용할 수 없다.

### 3. "재방문율 [N]%"
- **텍스트 예시:** "고객 재방문율 85%를 유지하고 있습니다"
- **사용처:** 랜딩페이지, 블로그
- **검증 필요 여부:** 필수 - 내부 데이터 근거 확인
- **컴플라이언스:** 재방문율의 산출 기준(기간, 모수)을 명시할 수 있어야 한다. 검증 불가능한 수치는 사용 금지.

### 4. "월 평균 [N]건 [진행/시술]"
- **텍스트 예시:** "월 평균 200건 이상의 상담을 진행합니다"
- **사용처:** 블로그, 랜딩페이지
- **검증 필요 여부:** 필수 - 최근 6개월 데이터 기준
- **컴플라이언스:** 평균 산출 기간을 명시할 수 있어야 한다. 특정 달만 높았던 수치를 일반화하지 않는다.

### 5. "개원 이래 [N]명 고객"
- **텍스트 예시:** "개원 이래 20,000명의 고객이 방문했습니다"
- **사용처:** 랜딩페이지, 블로그
- **검증 필요 여부:** 필수 - CRM/접수 데이터 확인
- **컴플라이언스:** 고객 수의 기준(순 방문자? 연 방문 건수?)을 명확히 한다. 중복 카운트 여부 확인.
