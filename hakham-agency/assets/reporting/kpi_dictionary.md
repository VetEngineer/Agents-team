# KPI 사전

> 마케팅 주요 지표 정의. 각 지표의 정의, 계산식, 벤치마크, 개선 방향을 포함한다.

---

## 트래픽 지표

### 1. 세션 (Sessions)
- **영문:** Sessions
- **정의:** 사용자가 웹사이트를 방문하여 활동한 단위. 30분 비활동 후 새 세션으로 카운트.
- **계산식:** GA4 자동 집계 (event-based session)
- **단위:** 건
- **업종별 벤치마크:**
  - 로컬 의료: 월 1,000-5,000 세션 (소규모), 5,000-20,000 (중규모)
  - 전문서비스 (법률/세무): 월 500-3,000 세션
  - 뷰티/웰니스: 월 2,000-10,000 세션
- **관측 주기:** 주간 (추이), 월간 (보고)
- **개선 방향:** SEO 최적화, 콘텐츠 발행 빈도 증가, 광고 트래픽 확대, SNS 유입 강화

### 2. 페이지뷰 (Pageviews)
- **영문:** Pageviews
- **정의:** 페이지가 로드(새로고침 포함)된 총 횟수.
- **계산식:** GA4 자동 집계
- **단위:** 건
- **업종별 벤치마크:** 세션 대비 1.5-3배 (페이지/세션 기준)
  - 의료/전문서비스: 세션당 2-4 페이지
  - 블로그 중심: 세션당 1.5-2.5 페이지
- **관측 주기:** 주간
- **개선 방향:** 내부 링크 구조 개선, 관련 콘텐츠 추천, 사이트 구조 최적화

### 3. 이탈률 (Bounce Rate)
- **영문:** Bounce Rate
- **정의:** 단일 페이지만 보고 이탈한 세션의 비율. GA4에서는 "참여하지 않은 세션"의 비율.
- **계산식:** 참여하지 않은 세션 수 / 전체 세션 수 x 100
- **단위:** %
- **업종별 벤치마크:**
  - 랜딩페이지: 60-90% (정상 범위)
  - 블로그: 65-85%
  - 서비스 사이트: 40-60%
- **관측 주기:** 주간
- **개선 방향:** 페이지 로딩 속도 개선, 콘텐츠 품질 향상, CTA 명확화, 모바일 UX 개선

### 4. 평균 세션 시간 (Avg. Session Duration)
- **영문:** Average Session Duration / Average Engagement Time
- **정의:** 사용자가 사이트에서 활동한 평균 시간. GA4에서는 "평균 참여 시간".
- **계산식:** 총 참여 시간 / 세션 수
- **단위:** 초 또는 분:초
- **업종별 벤치마크:**
  - 블로그/정보 사이트: 2-4분
  - 서비스 사이트: 1-3분
  - 랜딩페이지: 30초-2분
- **관측 주기:** 주간
- **개선 방향:** 콘텐츠 깊이 증가, 멀티미디어 활용, 스크롤 유도 디자인, 인터랙티브 요소 추가

## 전환 지표

### 5. CTR (Click-Through Rate)
- **영문:** Click-Through Rate
- **정의:** 노출 대비 클릭이 발생한 비율.
- **계산식:** 클릭 수 / 노출 수 x 100
- **단위:** %
- **업종별 벤치마크:**
  - 네이버 검색광고: 3-8% (파워링크)
  - 구글 검색광고: 3-7% (검색 네트워크)
  - 메타 피드 광고: 0.8-2%
  - 디스플레이 광고: 0.3-0.8%
  - 이메일 마케팅: 2-5%
- **관측 주기:** 일간 (광고), 주간 (오가닉)
- **개선 방향:** 광고 소재/카피 최적화, 타겟팅 정밀화, A/B 테스트, 키워드 관련성 향상

### 6. CVR (Conversion Rate)
- **영문:** Conversion Rate
- **정의:** 방문자 중 목표 행동(전환)을 완료한 비율.
- **계산식:** 전환 수 / 방문(세션) 수 x 100
- **단위:** %
- **업종별 벤치마크:**
  - 의료 (상담 예약): 2-5%
  - 법률 (문의): 3-8%
  - 뷰티 (예약): 3-7%
  - 랜딩페이지: 5-15% (최적화 시)
- **관측 주기:** 주간
- **개선 방향:** 랜딩페이지 UX 개선, CTA 최적화, 폼 필드 최소화, 사회적 증거 추가, 로딩 속도 개선

### 7. CPL (Cost Per Lead)
- **영문:** Cost Per Lead
- **정의:** 리드(잠재 고객 정보) 1건을 획득하는 데 든 비용.
- **계산식:** 총 광고비 / 리드 수
- **단위:** 원
- **업종별 벤치마크:**
  - 의료 (상담 예약): 15,000-50,000원
  - 법률 (문의): 30,000-100,000원
  - 뷰티 (예약): 10,000-30,000원
  - 교육 (상담): 20,000-60,000원
- **관측 주기:** 주간
- **개선 방향:** 타겟팅 정밀화, 소재 최적화, 랜딩페이지 전환율 개선, 저효율 키워드/소재 중단

### 8. CPA (Cost Per Acquisition)
- **영문:** Cost Per Acquisition
- **정의:** 실제 고객(유료 전환) 1명을 획득하는 데 든 비용.
- **계산식:** 총 광고비 / 획득 고객 수
- **단위:** 원
- **업종별 벤치마크:**
  - 의료 (내원): 50,000-200,000원
  - 법률 (수임): 200,000-1,000,000원
  - 뷰티 (시술): 20,000-80,000원
- **관측 주기:** 월간
- **개선 방향:** 리드→고객 전환율(내원율, 수임률) 개선, 팔로업 프로세스 강화, 리드 품질 향상

### 9. ROAS (Return on Ad Spend)
- **영문:** Return on Ad Spend
- **정의:** 광고비 대비 발생한 매출의 비율.
- **계산식:** 광고를 통한 매출 / 광고비 x 100
- **단위:** %
- **업종별 벤치마크:**
  - 의료: 300-800% (시술 단가에 따라 편차 큼)
  - 법률: 500-2000% (수임료 기준)
  - 뷰티: 200-500%
  - 일반적 손익분기점: 200-300%
- **관측 주기:** 월간
- **개선 방향:** 고단가 전환 유도, CPA 절감, 고객 생애 가치(LTV) 고려, 크로스셀/업셀

## 콘텐츠 지표

### 10. 검색 노출 순위 (Search Ranking)
- **영문:** Search Ranking Position
- **정의:** 특정 키워드에 대한 검색 결과 페이지에서의 위치.
- **계산식:** Google Search Console / 네이버 서치어드바이저 데이터
- **단위:** 위 (순위)
- **업종별 벤치마크:**
  - 핵심 키워드: 1-3위 목표
  - 롱테일 키워드: 1-10위 (첫 페이지)
  - 신규 콘텐츠: 발행 후 2-4주 내 30위 이내 진입
- **관측 주기:** 주간
- **개선 방향:** 키워드 최적화, 콘텐츠 품질 개선, 내부 링크 강화, 백링크 확보, 기술 SEO 개선

### 11. 유기 트래픽 (Organic Traffic)
- **영문:** Organic Traffic
- **정의:** 검색 엔진을 통해 자연 유입된 트래픽.
- **계산식:** GA4 소스/매체 = organic 필터
- **단위:** 세션 수
- **업종별 벤치마크:** 전체 트래픽의 30-60%가 이상적
- **관측 주기:** 주간 (추이), 월간 (보고)
- **개선 방향:** SEO 콘텐츠 지속 발행, 기존 콘텐츠 업데이트, 검색 의도 일치 최적화

### 12. 체류 시간 (Time on Page)
- **영문:** Time on Page / Average Engagement Time per Page
- **정의:** 특정 페이지에서 사용자가 머문 평균 시간.
- **계산식:** GA4 페이지별 참여 시간 / 페이지 조회 수
- **단위:** 초 또는 분:초
- **업종별 벤치마크:**
  - 블로그 포스트 (1,000자): 1-2분
  - 블로그 포스트 (3,000자+): 3-5분
  - 랜딩페이지: 30초-2분
- **관측 주기:** 주간
- **개선 방향:** 콘텐츠 구조 개선 (소제목, 이미지, 리스트), 가독성 향상, 인터랙티브 요소

### 13. 공유/저장 수 (Shares/Saves)
- **영문:** Shares / Saves
- **정의:** 콘텐츠가 공유되거나 저장(북마크)된 횟수.
- **계산식:** 플랫폼별 집계
- **단위:** 건
- **업종별 벤치마크:**
  - 인스타그램 저장률: 게시물 도달 대비 1-3%
  - 블로그 공유: 포스트당 5-20건
- **관측 주기:** 주간
- **개선 방향:** 실용적/교육적 콘텐츠 비중 확대, 인포그래픽 활용, 공유 유도 CTA

## 소셜 지표

### 14. 도달 (Reach)
- **영문:** Reach
- **정의:** 콘텐츠를 본 고유 계정 수 (중복 제외).
- **계산식:** 플랫폼 인사이트 자동 집계
- **단위:** 명
- **업종별 벤치마크:**
  - 인스타그램: 팔로워 수의 10-30% (알고리즘에 따라 변동)
  - 페이스북: 팔로워 수의 5-15%
  - 릴스/쇼츠: 팔로워 수의 50-200% (바이럴 가능성)
- **관측 주기:** 주간
- **개선 방향:** 릴스/숏폼 콘텐츠 확대, 발행 시간 최적화, 해시태그 전략, 협업 콘텐츠

### 15. 참여율 (Engagement Rate)
- **영문:** Engagement Rate
- **정의:** 콘텐츠에 반응(좋아요, 댓글, 공유, 저장)한 비율.
- **계산식:** (좋아요 + 댓글 + 공유 + 저장) / 도달 수 x 100 (또는 팔로워 기준)
- **단위:** %
- **업종별 벤치마크:**
  - 인스타그램 (도달 기준): 3-8%
  - 인스타그램 (팔로워 기준): 1-5%
  - 페이스북: 0.5-2%
- **관측 주기:** 주간
- **개선 방향:** 캐러셀/릴스 비중 확대, 질문/투표 활용, 댓글 적극 응대, 저장 유도 콘텐츠

### 16. 팔로워 증가율 (Follower Growth Rate)
- **영문:** Follower Growth Rate
- **정의:** 특정 기간 동안 팔로워가 증가한 비율.
- **계산식:** (기간 말 팔로워 - 기간 초 팔로워) / 기간 초 팔로워 x 100
- **단위:** %
- **업종별 벤치마크:**
  - 월간 증가율: 1-5% (안정적 성장)
  - 초기 계정 (1,000명 이하): 5-15%
  - 성숙 계정 (10,000명 이상): 1-3%
- **관측 주기:** 월간
- **개선 방향:** 일관된 발행 스케줄, 바이럴 콘텐츠 기획, 협업/태그, 프로필 최적화

### 17. 저장률/공유률 (Save Rate / Share Rate)
- **영문:** Save Rate / Share Rate
- **정의:** 콘텐츠를 저장하거나 공유한 비율.
- **계산식:** 저장(공유) 수 / 도달 수 x 100
- **단위:** %
- **업종별 벤치마크:**
  - 저장률: 도달 대비 1-3% (높으면 알고리즘 우대)
  - 공유률: 도달 대비 0.5-2%
- **관측 주기:** 주간
- **개선 방향:** "저장해 두세요" CTA 활용, 체크리스트/가이드 등 실용 콘텐츠, 인포그래픽

## 지표 간 관계도

```
[노출/도달] → [클릭/CTR] → [방문/세션] → [전환/CVR] → [매출/ROAS]
     ↑              ↑             ↑              ↑             ↑
  광고 예산       소재 품질     랜딩 품질      UX/CTA       상품/서비스
  타겟팅         카피 라이팅   콘텐츠 품질    폼 최적화     가격 경쟁력
  키워드         브랜드 인지   로딩 속도      사회적 증거    팔로업 품질
```

## 벤치마크 활용 주의사항

1. 벤치마크는 참고 수치이며, 업종/지역/경쟁 상황에 따라 크게 달라진다
2. 자사 데이터의 추이(트렌드)가 절대 수치보다 더 중요하다
3. 단일 지표가 아닌 퍼널 전체를 종합적으로 판단한다
4. 벤치마크 대비 극단적으로 높거나 낮은 수치는 데이터 오류를 먼저 의심한다
5. 계절성(시즌)을 고려한다 (예: 1월 다이어트, 3월 이사/인테리어)
