## 여정 전체 흐름

```
인식 → 검색 → 비교 → 문의 → 전환 → 재방문
```

---

## 1단계: 인식 (Awareness)

> 고객이 문제를 자각하거나 니즈가 생기는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "나 혹시 ___한 건 아닐까?" / "이런 거 다른 사람들은 어떻게 하지?" |
| **고객 심리** | 막연한 불안, 호기심, 정보 부족 |
| **반론/저항** | "아직 심각하지 않아" / "나중에 알아봐도 돼" |
| **필요한 증거** | |
| **적합 채널** | |
| **콘텐츠 유형** | 정보성 블로그, 체크리스트, 증상/상황 자가진단 |
| **CTA** | |

## 2단계: 검색 (Search)

> 적극적으로 정보를 찾는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "___은 어떻게 하는 거지?" / "___하려면 어디로 가야 하지?" |
| **고객 심리** | 적극적 탐색, 정보 비교 시작 |
| **반론/저항** | "정보가 너무 많아서 모르겠다" / "믿을 만한 곳을 찾기 어렵다" |
| **필요한 증거** | |
| **적합 채널** | |
| **콘텐츠 유형** | 가이드, 비용 안내, 방법 설명, 동영상 |
| **CTA** | |

## 3단계: 비교 (Comparison)

> 여러 선택지를 저울질하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "A와 B 중 어디가 나을까?" / "여기가 정말 잘하는 곳인가?" |
| **고객 심리** | 비교 분석, 리스크 회피, 후회 방지 |
| **반론/저항** | "다른 곳이 더 싸네" / "후기가 너무 적어" / "직접 가봐야 알겠다" |
| **필요한 증거** | |
| **적합 채널** | |
| **콘텐츠 유형** | 비교표, 후기/사례, FAQ, 시설 투어 |
| **CTA** | |

## 4단계: 문의 (Inquiry)

> 직접 연락하거나 상담을 요청하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "내 경우에는 어떻게 되나?" / "비용이 정확히 얼마인가?" |
| **고객 심리** | 구체적 확인 욕구, 마지막 확신 필요 |
| **반론/저항** | "전화하기 귀찮다" / "상담받으면 강매당할 것 같다" / "아직 결정 못 했다" |
| **필요한 증거** | |
| **적합 채널** | |
| **콘텐츠 유형** | 상담 안내, 무료 체험, 사전 문진, 간편 예약 |
| **CTA** | |

---

## 5단계: 전환 (Conversion)

> 구매, 예약, 가입을 결정하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "지금 해도 괜찮을까?" / "취소는 가능한가?" |
| **고객 심리** | 최종 결단, 리스크 불안, 즉각 행동 |
| **반론/저항** | "조금 더 생각해볼까" / "다음에 해도 되지 않나" / "가격이 부담된다" |
| **필요한 증거** | |
| **적합 채널** | |
| **콘텐츠 유형** | 한정 오퍼, 보증/환불 안내, 즉시 예약, 결제 편의 |
| **CTA** | |

## 6단계: 재방문 (Retention/Referral)

> 재이용 또는 주변 추천을 하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "결과가 만족스러운가?" / "다시 가도 괜찮을까?" / "주변에 추천할까?" |
| **고객 심리** | 만족도 평가, 습관화, 추천 의향 |
| **반론/저항** | "한 번이면 충분해" / "다른 곳도 가보고 싶다" |
| **필요한 증거** | |
| **적합 채널** | |
