## 점수 기준

### Impact (영향도) 1-5

| 점수 | 기준 |
|------|------|
| 5 | 주 KPI에 직접적이고 큰 영향. 전환율 또는 전환수 20% 이상 개선 예상 |
| 4 | 주 KPI에 직접적 영향. 10-20% 개선 예상 |
| 3 | 주 KPI에 간접적 영향. 보조 KPI 개선을 통한 5-10% 개선 예상 |
| 2 | 보조 KPI에 소폭 영향. 5% 미만 개선 예상 |
| 1 | 효과가 불확실하거나 미미함. 장기적 개선에 기여 |

### Effort (투입량) 1-5

| 점수 | 기준 |
|------|------|
| 1 | 1일 이내. 카피 변경, 설정 변경 등 즉시 실행 가능 |
| 2 | 2-3일. 소재 교체, 간단한 A/B 테스트 설정 |
| 3 | 1주. 랜딩 페이지 수정, 새 소재 제작 필요 |
| 4 | 2주. 디자인/개발 협업 필요, 복합적 변경 |
| 5 | 3주 이상. 시스템 변경, 새 도구 도입, 대규모 구조 변경 |

### 우선순위 점수 = Impact / Effort (높을수록 먼저)

## 백로그 운영 규칙

1. **매주 월요일**: 새로운 인사이트에서 도출된 개선안을 백로그에 추가한다
2. **Impact/Effort 재평가**: 새 데이터가 나오면 점수를 업데이트하고 우선순위를 재정렬한다
3. **완료 항목**: 결과를 기록하고 학습 아카이브로 이동한다
4. **상위 3개**: 항상 다음 주 실행 대상으로 관리한다
5. **실험 연결**: 백로그 항목 중 가설 검증이 필요한 것은 Agent 05의 7일 실험 계획으로 연결한다
