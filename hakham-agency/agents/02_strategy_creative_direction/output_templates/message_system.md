## 1. 핵심 메시지

### 구조: What + Why + Proof

> **[핵심 메시지 1문장]**

| 요소 | 내용 |
|------|------|
| What (우리가 제공하는 것) | |
| Why (고객에게 중요한 이유) | |
| Proof (믿을 수 있는 근거) | |

### 검증

- [ ] 고객이 3초 내에 이해할 수 있는가
- [ ] 경쟁사가 동일하게 주장할 수 없는가
- [ ] 01팀 페르소나의 트리거 문장과 연결되는가

## 3. 메시지 계층 구조

```

├── 보조 메시지 #1: 결과 앵글
```
