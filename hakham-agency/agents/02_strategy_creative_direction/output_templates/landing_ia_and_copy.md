## 랜딩 구조 개요

```
[1] 히어로 → [2] 신뢰 → [3] 문제 → [4] 해결 → [5] 증거 → [6] FAQ → [7] CTA
```

| 섹션 | 역할 | 스크롤 비중 |
|------|------|-------------|
| 히어로 | 첫인상, 핵심 메시지 전달, 즉시 CTA | 화면 1 |
| 신뢰 | 자격/인증/실적으로 신뢰 형성 | 화면 0.5 |

## 모바일 최적화 체크리스트

- [ ] 히어로 섹션이 모바일 1화면에 핵심 요소(헤드라인 + CTA) 포함
- [ ] 텍스트 크기가 모바일에서 읽기 편함 (최소 16px)
- [ ] CTA 버튼이 엄지 터치 영역에 위치
- [ ] 이미지가 모바일 비율에 맞게 크롭 가능
- [ ] 폼 입력 필드가 최소화됨 (3개 이하 권장)
- [ ] 전화 CTA가 탭 시 바로 전화 연결
