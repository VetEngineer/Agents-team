# Agent 02: 전략/크리에이티브 디렉션 팀 - 책임 범위

## 1. 핵심 메시지 1문장 (What/Why/Proof)

### 작성 공식

```
[What: 우리가 제공하는 것] + [Why: 고객에게 중요한 이유] + [Proof: 믿을 수 있는 근거]
```

### 작성 원칙
- 1문장, 30자 이내가 이상적 (최대 50자)
- 업종 전문 용어를 피하고 고객 언어를 사용한다
- 01팀 페르소나의 트리거 문장과 연결되어야 한다
- 이 메시지가 모든 채널 카피의 상위 기준이 된다

### 품질 체크
- [ ] What, Why, Proof 3요소가 모두 포함되었는가
- [ ] 고객이 첫 접촉에서 즉시 이해할 수 있는가
- [ ] 경쟁사가 동일하게 주장할 수 없는 차별성이 있는가

## 2. 보조 메시지 5개

### 앵글 구분
각 보조 메시지는 서로 다른 앵글을 다룬다:

1. **결과 앵글**: 서비스 이용 후 고객이 얻는 변화
2. **과정 앵글**: 서비스가 어떻게 진행되는지 (안심 요소)
3. **증거 앵글**: 왜 믿을 수 있는지 (자격, 실적, 후기)
4. **비교 앵글**: 왜 다른 곳이 아닌 여기인지
5. **긴급성 앵글**: 왜 지금 해야 하는지

### 작성 원칙
- 각 보조 메시지는 핵심 메시지의 하위 개념이어야 한다
- 서로 중복되지 않으면서 보완적이어야 한다
- 01팀 페르소나의 반대 이유를 해소하는 방향이어야 한다

## 3. 헤드라인 20개 (채널별 5개)

### 블로그용 헤드라인 5개
- SEO 키워드를 자연스럽게 포함한다
- 정보 탐색 의도에 맞는 톤 (교육적, 가이드형)
- 클릭 유도 + 본문 기대감 형성

### 인스타용 헤드라인 5개
- 첫 줄에 후킹 요소 배치
- 감정적 공감 또는 호기심 유발
- 저장/공유 유도 구조

### 쇼츠용 헤드라인 5개
- 3초 내 주의 환기 가능한 짧은 문장
- 구어체, 직접 대화 톤
- 영상 컨셉과 연결된 문구

### 광고용 헤드라인 5개
- 핵심 오퍼 + CTA 결합
- 클릭 후 랜딩과의 메시지 일치
- 타깃 세그먼트별 차별화

## 4. 랜딩 섹션 IA + 초안

### 섹션 구조 (7개)

```
히어로 → 신뢰 → 문제 → 해결 → 증거 → FAQ → CTA
```

각 섹션에 대해:
- 목적: 이 섹션이 전환 퍼널에서 하는 역할
- 헤드라인: 메시지 시스템 기반
- 본문 초안: 실제 카피 수준의 텍스트
- 시각 요소 가이드: 어떤 이미지/영상/아이콘이 필요한지
- CTA: 이 섹션 이후 유도할 행동

### 작성 원칙
- 스크롤 흐름이 자연스러워야 한다
- 각 섹션이 다음 섹션을 읽게 만드는 구조여야 한다
- CTA는 최소 3회 배치 (히어로, 증거 후, 최종)

## 5. 반론 처리 문장 10개

### 카테고리별 작성

| # | 카테고리 | 설명 |
|---|----------|------|
| 1 | 가격 | "비싸다", "저기가 더 싸다" |
| 2 | 통증/부작용 | "아프다", "부작용이 걱정된다" |
| 3 | 시간 | "시간이 없다", "오래 걸린다" |
| 4 | 효과 기대 | "효과가 있을까", "나한테도 될까" |
| 5 | 신뢰 부족 | "여기 믿을 만한가", "처음 듣는 곳인데" |
| 6 | 경쟁사 비교 | "다른 데가 더 유명하다" |
| 7 | 긴급성 | "나중에 해도 되지 않나" |
| 8 | 접근성 | "너무 멀다", "예약이 어렵다" |
| 9 | 사후관리 | "문제 생기면 어떻게 하나" |
| 10 | 기타 | 업종별 고유 반론 |

### 각 반론 작성 형식
- 반론 원문: 고객이 실제로 하는 말
- 처리 전략: 인정 → 재구성 → 증거 → CTA
- 대응 문장: 실제 사용할 카피 수준의 문장
- 활용 채널: 어디에서 사용할 것인가

## 6. 제작 브리프 (디자인/영상)

### 포함 항목
- 프로젝트 개요 (목적, 기간, 예산)
- 타깃 오디언스 (01팀 페르소나 기반)
- 핵심 메시지 (메시지 시스템 기반)
- 톤앤매너 (구체적 형용사 + Do/Don't 예시)
- 시각적 방향 (무드보드 키워드, 컬러 팔레트, 폰트 방향)
- 필수 포함 요소 (로고, 연락처, 인증마크 등)
- 금지 요소 (사용 불가 이미지, 표현, 컬러)
- 사이즈/포맷 (채널별 사이즈 명시)
- 참고 자료 (벤치마크, 경쟁사 사례)
- 마감일

### 품질 체크
- [ ] 제작자가 추가 질문 없이 바로 작업 착수할 수 있는가
- [ ] 톤앤매너가 구체적 예시와 함께 정의되었는가
- [ ] 사이즈와 포맷이 모든 채널에 대해 명시되었는가
