## CRO 점검 체크리스트

### 히어로 섹션
- [ ] 헤드라인이 3초 내에 핵심 가치를 전달하는가
- [ ] 서브 헤드라인이 타깃의 문제/욕구에 공감하는가
- [ ] 히어로 이미지/영상이 서비스 결과를 보여주는가
- [ ] 첫 화면에 CTA가 보이는가

### 사회적 증거
- [ ] 고객 후기가 3개 이상 있는가
- [ ] 숫자 기반 실적이 있는가 (고객 수, 만족도 등)
- [ ] 인증/수상/미디어 노출이 있는가
- [ ] 후기에 구체적 결과(수치)가 포함되어 있는가

### 폼/전환 요소
- [ ] 폼 필드가 5개 이하인가
- [ ] 폼 제출 버튼 문구가 명확한가
- [ ] 폼 주변에 불안 해소 요소가 있는가 (개인정보 보호, 무료 등)
- [ ] 폼 완료 후 감사 페이지/확인 메시지가 있는가

### CTA
- [ ] CTA 버튼이 시각적으로 눈에 띄는가
- [ ] CTA 문구가 행동을 유도하는가 ("신청하기" vs "더 알아보기")
- [ ] 페이지 내 CTA가 2-3곳에 배치되어 있는가
- [ ] 모바일에서 CTA 터치 영역이 충분한가

### 페이지 속도/모바일
- [ ] 모바일 로딩 3초 이내인가
- [ ] 모바일에서 텍스트가 읽기 편한가
- [ ] 모바일에서 폼 입력이 편한가
- [ ] 불필요한 팝업이 전환을 방해하지 않는가
