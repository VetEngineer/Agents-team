## 촬영 공통 체크리스트

### 촬영 전
- [ ] 배터리 충전 확인 (스마트폰 80% 이상)
- [ ] 저장 공간 확인 (최소 5GB 여유)
- [ ] 조명 세팅 (역광 금지, 얼굴에 그림자 없이)
- [ ] 마이크 테스트 (10초 녹음 후 확인)
- [ ] 배경 정리 (불필요한 물건 제거)
- [ ] 의상 확인 (브랜드 컬러 또는 깔끔한 단색)

### 촬영 중
- [ ] 카메라 눈높이 또는 약간 위에서
- [ ] 9:16 세로 촬영
- [ ] 각 컷 시작/끝 1초씩 여유
- [ ] 대본 읽기 아닌 말하기 톤
- [ ] 3컷 이상 연속 촬영 후 확인

### 촬영 후
- [ ] 모든 컷 촬영 완료 체크
- [ ] 음성 품질 확인
- [ ] 파일 백업
