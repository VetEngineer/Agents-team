# 반복 포맷 3종 정의

> 모든 영상은 아래 3종 포맷 중 하나에 기반한다. 매번 새로 구성하지 않고, 포맷 구조를 따르되 주제만 교체한다.

---

## 포맷 1: 문제 제기형

**목적**: 잠재 고객의 문제를 건드려서 "나도 해당되나?"라는 반응 유도
**핵심 감정**: 공감, 불안, 궁금증

### 구조

| 단계 | 시간 | 내용 | 화면 |
|------|------|------|------|
| 훅 (충격/공감) | 0~3초 | 문제를 직설적으로 던진다 | 얼굴 클로즈업, 텍스트 오버레이 |
| 문제 설명 | 3~20초 | 왜 이것이 문제인지 구체적으로 설명 | 말하기 + B-roll 전환 |
| 해결 힌트 | 20~35초 | 해결 방향 제시 (서비스 직접 언급은 부드럽게) | 해결 관련 시각 자료 |
| CTA | 35~45초 | 1가지 행동 유도 | 텍스트 + 말하기 |

### 시간 배분 변형

**15초 버전**: 훅(3초) → 문제 핵심(7초) → CTA(5초)
**30초 버전**: 훅(3초) → 문제(12초) → 힌트(10초) → CTA(5초)
**45초 버전**: 훅(3초) → 문제(17초) → 힌트(15초) → CTA(10초)

### 적합 주제
- 방치하면 악화되는 문제 (건강, 재정, 피부 등)
- 많은 사람이 겪지만 대수롭지 않게 넘기는 문제
- "이런 증상이 있다면" 시리즈

### 예시 주제 3개
1. "[증상]이 반복된다면, 그냥 넘기면 안 되는 이유"
2. "[습관]이 [문제]를 악화시키고 있을 수 있습니다"
3. "[N]명 중 [N]명이 모르고 있는 [문제]의 신호"

### 오프닝 훅 공식
- "혹시 [증상/상황]이신가요? 그냥 넘기시면 안 됩니다."
- "[N]명 중 [N]명이 이걸 모르고 방치합니다."
- "이 [N]가지 중 하나라도 해당되면 영상 끝까지 보세요."

## 포맷 2: 오해 교정형

**목적**: 잘못 알고 있는 상식을 바로잡아 전문성/신뢰 구축
**핵심 감정**: 놀람, 의외, 신뢰

### 구조

| 단계 | 시간 | 내용 | 화면 |
|------|------|------|------|
| 훅 (흔한 오해) | 0~3초 | 사람들이 믿고 있는 오해를 제시 | 텍스트 강조 + 표정 연기 |
| 진실/팩트 | 3~20초 | 실제 사실을 근거와 함께 설명 | 데이터/시각자료 + 말하기 |
| 올바른 방법 | 20~35초 | 그렇다면 어떻게 해야 하는지 | 단계별 설명 또는 시연 |
| CTA | 35~45초 | 1가지 행동 유도 | 텍스트 + 말하기 |

### 시간 배분 변형

**15초 버전**: 훅(3초) → 팩트 핵심(7초) → CTA(5초)
**30초 버전**: 훅(3초) → 팩트(12초) → 올바른 방법(10초) → CTA(5초)
**45초 버전**: 훅(3초) → 팩트(15초) → 올바른 방법(17초) → CTA(10초)

### 적합 주제
- "~하면 ~된다"는 잘못된 상식
- 인터넷에서 퍼진 오해/미신
- 전문가만 아는 진실

### 예시 주제 3개
1. "[서비스]하면 [오해]된다? 사실은 정반대입니다"
2. "인터넷에 떠도는 [주제] 정보, [N]가지가 틀렸습니다"
3. "[업종] 전문가가 말하는, 절대 하면 안 되는 [N]가지"

### 오프닝 훅 공식
- "[흔한 오해]라고 생각하시죠? 틀렸습니다."
- "이거 아직도 믿고 계시면 큰일 납니다."
- "[업종] [N]년 차가 말하는, 가장 위험한 오해."

## 포맷 3: 체크리스트형

**목적**: 실용적 정보 전달로 저장/공유 유도, "나중에 봐야지" 반응
**핵심 감정**: 유용함, 정리됨, 안심

### 구조

| 단계 | 시간 | 내용 | 화면 |
|------|------|------|------|
| 훅 (몇 가지 확인) | 0~3초 | 확인해야 할 항목 수 제시 | 숫자 텍스트 크게 |
| 항목 나열 | 3~30초 | 항목을 하나씩 설명 (번호 매기기) | 항목별 텍스트 + 말하기 |
| 요약 | 30~40초 | 핵심을 한 문장으로 정리 | 전체 리스트 표시 |
| CTA | 40~45초 | 1가지 행동 유도 | 텍스트 + 말하기 |

### 시간 배분 변형

**15초 버전**: 훅(2초) → 항목 3개(10초) → CTA(3초)
**30초 버전**: 훅(3초) → 항목 5개(20초) → 요약+CTA(7초)
**45초 버전**: 훅(3초) → 항목 5~7개(27초) → 요약(8초) → CTA(7초)

### 적합 주제
- "[서비스] 전에 확인해야 할 체크리스트"
- "[상황]별 선택 가이드"
- "[주제] 필수 준비물/단계"

### 예시 주제 3개
1. "[서비스] 받기 전에 꼭 확인할 [N]가지"
2. "[업종] 고를 때 이것만 확인하세요 (체크리스트)"
3. "[주제] 초보를 위한 [N]단계 가이드"

### 오프닝 훅 공식
- "[서비스] 전에 이 [N]가지 확인하셨나요?"
- "이 영상 저장해두세요. [주제] 체크리스트입니다."
- "[N]가지만 확인하면 [결과]를 피할 수 있습니다."

## 포맷 선택 기준

| 상황 | 추천 포맷 | 이유 |
|------|----------|------|
| 긴급성/위험성 전달 | 문제 제기형 | 감정적 반응 유도, 댓글 유발 |
| 전문성/신뢰 구축 | 오해 교정형 | "이 사람 진짜 아는구나" 반응 |
| 저장/공유 극대화 | 체크리스트형 | 실용적 정보 → 저장률 높음 |
| 새 팔로워 확보 | 문제 제기형 + 오해 교정형 | 강한 훅으로 알고리즘 추천 |
| 기존 팔로워 유지 | 체크리스트형 | 꾸준한 가치 제공 |

## 포맷 믹스 권장 비율

- **초기 채널 (0~1,000 팔로워)**: 문제제기 40% / 오해교정 40% / 체크리스트 20%
- **성장 채널 (1,000~10,000)**: 문제제기 30% / 오해교정 30% / 체크리스트 40%
- **안정 채널 (10,000+)**: 균등 33% / 33% / 33% + 신규 포맷 테스트 월 1개
