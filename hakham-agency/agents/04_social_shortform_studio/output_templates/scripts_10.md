## 대본 1: [제목] - 문제 제기형

**포맷**: 문제 제기형
**총 길이**: 30초
**톤**: 진지하되 공포 유발 아님. 걱정하는 친구 톤.
**속도**: 보통 (분당 250~280자)

```
[0~3초] 오프닝 훅
[진지한 표정, 카메라 정면]
"혹시 [증상/상황]이 반복되고 계신가요? 그냥 넘기시면 안 됩니다."

[3~15초] 문제 설명
[말하기 + B-roll 전환]
"[증상/상황]이 계속되면 [구체적 악화 결과]로 이어질 수 있거든요.
실제로 [관련 수치나 사례] 정도가 이 문제를 겪고 있습니다.
문제는, 대부분 [잘못된 대처법]으로 대응한다는 거예요."

[15~25초] 해결 힌트
[다시 카메라 정면]
"가장 먼저 해야 할 건 [구체적 행동 1]입니다.
그리고 [구체적 행동 2]을 확인해 보시는 게 좋아요.
※ 결과는 개인에 따라 다를 수 있습니다."

[25~30초] CTA
[밝은 톤으로 전환]
"더 궁금하신 분은 프로필 링크에서 상담 예약해 주세요."
```

**자막 텍스트**:
- 0~3초: "[증상] 반복된다면?"
- 3~15초: "[악화 결과]로 이어질 수 있음" / "[N]%가 겪는 문제"
- 15~25초: "1. [행동 1]" / "2. [행동 2]"
- 25~30초: "프로필 링크 → 상담 예약"

## 대본 2: [제목] - 오해 교정형

**포맷**: 오해 교정형
**총 길이**: 30초
**톤**: 자신감 있는 전문가. 단정이 아닌 교육 톤.
**속도**: 약간 빠름 (분당 280~310자)

```
[0~3초] 오프닝 훅
[손사래 치며, 카메라 정면]
"[흔한 오해]라고 알고 계시죠? 사실 정반대입니다."

[3~15초] 진실/팩트
[말하기 + 데이터 화면]
"많은 분들이 [오해 내용]이라고 생각하시는데요.
실제로는 [올바른 사실]입니다.
[근거: 연구/통계/전문가 의견 간단 인용]"

[15~25초] 올바른 방법
[단계별 설명]
"그래서 올바른 방법은 이렇습니다.
첫째, [올바른 방법 1].
둘째, [올바른 방법 2].
이 두 가지만 지켜도 [긍정적 결과]를 기대할 수 있습니다."

[25~30초] CTA
[친근한 톤]
"다른 궁금한 점은 댓글로 남겨주세요. 다음 영상에서 답해드릴게요."
```

**자막 텍스트**:
- 0~3초: "[오해] → 사실은 정반대!"
- 3~15초: "실제로는 [올바른 사실]"
- 15~25초: "1. [방법 1]" / "2. [방법 2]"
- 25~30초: "댓글로 질문 남겨주세요"

## 대본 작성 시 공통 주의사항

### 의료/전문직 완충 표현
| 상황 | 금지 표현 | 완충 표현 |
|------|----------|----------|
| 효과 언급 | "확실히 좋아집니다" | "개선을 기대할 수 있습니다" |
| 결과 언급 | "100% 효과" | "많은 분들이 만족하고 계십니다" |
| 비교 언급 | "최고의 방법" | "효과적인 방법 중 하나" |
| 부작용 | "부작용 없음" | "개인에 따라 다를 수 있습니다" |
| 권유 | "무조건 해야 합니다" | "전문가 상담을 권장합니다" |

### 구어체 변환 규칙
| 문어체 | 구어체 |
|--------|--------|
| ~하는 것이 바람직합니다 | ~하는 게 좋아요 |
| ~할 수 있을 것으로 사료됩니다 | ~할 수 있습니다 |
| 상기 내용을 참고하여 | 위에 말씀드린 것처럼 |
| 다양한 옵션을 고려하여 | 여러 가지를 비교해 보시고 |
