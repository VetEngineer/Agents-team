## 캡션 작성 가이드

### 인스타 릴스
```
[후킹 첫 줄 - 더보기 누르게 만드는 문장]

[본문 2~3줄 - 영상 핵심 요약]

[CTA - 저장/공유/댓글/프로필 중 1개]

.
.
.
[해시태그 5~10개]
```

### 유튜브 쇼츠
```
[제목에 키워드 포함 - 50자 이내]
[설명란: 1~2줄 요약 + 프로필/채널 링크]
[해시태그 3~5개 - 제목이나 설명에 포함]
```

### 틱톡
```
[짧은 캡션 1~2줄 - 궁금증 유발]
[해시태그 3~5개 - 트렌드 태그 1개 포함]
```

### 스레드
```
[대화하듯 작성 - 질문 형태로 마무리]
[해시태그 사용 자제 - 있어도 1~2개]
[다른 사람 의견 유도가 핵심]
```

## 해시태그 전략

### 해시태그 구성 비율 (인스타 기준, 10개)
- 대형 (100만+ 게시물): 1~2개 → 노출 기회
- 중형 (10만~100만): 3~4개 → 경쟁 균형
- 소형 (1만~10만): 3~4개 → 상위 노출 가능
- 브랜드/지역: 1~2개 → 고유 태그

### 업종별 해시태그 뱅크 (예시)
```
[업종 공통]: #[업종명] #[서비스명] #[관련키워드1] #[관련키워드2]
[지역]: #[지역명] #[지역+업종]
[콘텐츠 유형]: #꿀팁 #체크리스트 #오해교정 #알려주는사람
[트렌드 (주기적 교체)]: #[현재트렌드태그]
```

## 멀티 플랫폼 변환 규칙

1개 원본 영상을 여러 플랫폼에 게시할 때:

| 항목 | 인스타 → 유튜브 | 인스타 → 틱톡 | 인스타 → 스레드 |
|------|---------------|--------------|---------------|
| 영상 | 그대로 또는 약간 수정 | 워터마크 제거 후 업로드 | 영상 → 텍스트 변환 |
| 캡션 | 간결하게 수정 | 더 캐주얼하게 | 대화체로 재작성 |
| 해시태그 | 3~5개로 축소 | 트렌드 태그 추가 | 최소화 또는 없음 |
| CTA | 고정 댓글로 이동 | 프로필 링크 | 의견 요청 |
| 음악 | 원본 유지 | 틱톡 트렌드 음악 교체 | 없음 |
| 게시 간격 | 같은 날 또는 +1일 | +1~2일 | +2~3일 |
