# 커뮤니티 답변 템플릿 20개

> 카테고리별 분류. 의료/전문직 업종은 완충 표현 필수. [업종명], [서비스명], [연락처] 등은 프로젝트에 맞게 치환.

---

## 카테고리 1: 가격 질문 (4개)

### 1-1. 직접 가격 질문

**질문 예시**: "[서비스] 가격이 얼마인가요?"

**답변 템플릿**:
```
안녕하세요! 관심 가져주셔서 감사합니다.
[서비스] 비용은 개인 상황에 따라 다르게 안내드리고 있어요.
정확한 안내를 위해 [카카오톡/전화]로 문의해 주시면
상황에 맞는 맞춤 상담을 도와드리겠습니다.
→ [연락처/링크]
```

**톤 가이드**: 친절하지만 가격을 공개 댓글에 직접 노출하지 않는다. DM/전화로 유도.
**주의사항**: 공개 댓글에 구체적 가격을 적으면 가격 비교의 빌미가 된다. 반드시 비공개 채널로 안내.

---

### 1-2. 가격 비싼 것 아닌가요?

**질문 예시**: "다른 데보다 비싼 거 같은데요", "가격이 좀 부담스러워요"

**답변 템플릿**:
```
솔직한 의견 감사합니다!
저희는 [차별점 1]과 [차별점 2]를 포함한 비용이라
단순 비교가 어려울 수 있어요.
자세한 내용은 상담 시 구체적으로 안내드리고 있습니다.
부담 없이 문의해 주세요!
→ [연락처/링크]
```

**톤 가이드**: 방어적이지 않게, 가치를 설명하는 톤. "비싸다"에 직접 반박하지 않는다.

---

### 1-3. 할인/이벤트 있나요?

**질문 예시**: "할인 이벤트 없나요?", "첫 방문 혜택 있나요?"

**답변 템플릿**:
```
문의 감사합니다!
현재 진행 중인 [이벤트/혜택] 관련 안내는
DM 또는 [카카오톡]으로 문의해 주시면
자세히 안내드리겠습니다.
→ [연락처/링크]
```

**톤 가이드**: 이벤트가 있으면 간단히 언급, 없으면 "상담 시 안내"로 유도.

---

### 1-4. 보험/의료보험 적용되나요?

**질문 예시**: "이거 보험 되나요?", "의보 적용 가능한가요?"

**답변 템플릿**:
```
좋은 질문이에요!
[서비스] 중 [보험 적용 가능 항목]은 보험 적용이 가능하고,
[적용 불가 항목]은 별도입니다.
정확한 확인을 위해 상담 시 안내드리겠습니다.
→ [연락처/링크]
```

**톤 가이드**: 가능한 범위에서 정보 제공, 정확한 확인은 상담으로 유도.

---

## 카테고리 2: 위치/접근성 (3개)

### 2-1. 위치 질문

**질문 예시**: "어디에 있어요?", "주소 알려주세요"

**답변 템플릿**:
```
[지역구/동] [랜드마크] 근처에 있습니다!
[도로명 주소]이고, [지하철역] [N]번 출구에서 도보 [N]분이에요.
네이버 지도에서 "[업종명]" 검색하시면 바로 나옵니다.
```

**톤 가이드**: 간결하고 실용적. 찾아오는 방법을 구체적으로.

---

### 2-2. 주차 가능 여부

**질문 예시**: "주차 되나요?", "주차장 있어요?"

**답변 템플릿**:
```
네! [건물 내 주차장/인근 공영주차장]을 이용하실 수 있습니다.
[주차 지원 여부: 예) 1시간 무료 주차 지원 / 주차 비용 별도].
자세한 안내는 방문 시 말씀해 주세요.
```

---

### 2-3. 운영 시간 질문

**질문 예시**: "몇 시까지 해요?", "일요일도 하나요?"

**답변 템플릿**:
```
운영 시간은 [요일별 시간]입니다.
[휴무일] 정보도 참고해 주세요!
예약 후 방문하시면 대기 없이 안내드릴 수 있어요.
→ 예약: [연락처/링크]
```

---

## 카테고리 3: 예약/문의 방법 (3개)

### 3-1. 예약 방법

**질문 예시**: "예약 어떻게 하나요?", "예약 필수인가요?"

**답변 템플릿**:
```
예약은 [카카오톡/전화/온라인 예약] 모두 가능합니다!
[카카오톡 채널명]으로 메시지 보내시면 빠르게 안내드려요.
원하시는 날짜/시간 말씀해 주시면 됩니다.
→ [연락처/링크]
```

---

### 3-2. 상담만 받고 싶어요

**질문 예시**: "상담만 받을 수 있나요?", "일단 얘기만 들어볼 수 있나요?"

**답변 템플릿**:
```
물론이죠! 상담만 받으셔도 전혀 부담 없습니다.
상황을 파악하고 맞춤 안내를 드리는 것이 상담의 목적이에요.
편하게 문의해 주세요!
→ [연락처/링크]
```

**톤 가이드**: "상담 = 구매 의무"라는 부담을 명확히 없앤다.

---

### 3-3. 급하게 방문 가능한가요?

**질문 예시**: "오늘 바로 갈 수 있나요?", "당일 예약 되나요?"

**답변 템플릿**:
```
당일 예약도 가능한 경우가 있어요!
[전화/카카오톡]으로 먼저 확인해 주시면
빈 시간을 안내드리겠습니다.
→ [연락처]
```

---

## 카테고리 4: 효과/결과 질문 (3개) - 완충 표현 필수

### 4-1. 효과가 있나요?

**질문 예시**: "진짜 효과 있어요?", "효과 얼마나 가나요?"

**답변 템플릿**:
```
많은 분들이 만족하고 계시지만,
결과는 개인 상황에 따라 다를 수 있습니다.
상담 시 예상되는 결과와 기간을 구체적으로 안내드리고 있어요.
궁금하신 점은 편하게 문의해 주세요!
→ [연락처/링크]
```

**톤 가이드**: 효과를 단정하지 않는다. "많은 분들이 만족"까지만.
**주의사항**: "확실히 효과 있습니다", "100% 만족" 등 절대 사용 금지.

---

### 4-2. 얼마나 걸리나요?

**질문 예시**: "기간이 얼마나 걸려요?", "결과 보려면 얼마나 기다려야 해요?"

**답변 템플릿**:
```
일반적으로 [대략적 기간 범위]가 소요되는 경우가 많습니다.
다만 개인 상황에 따라 다를 수 있어서,
상담 시 예상 기간을 안내드리고 있어요.
→ [연락처/링크]
```

---

### 4-3. 다른 분들 결과 볼 수 있나요?

**질문 예시**: "전후 사진 있나요?", "후기 볼 수 있나요?"

**답변 템플릿**:
```
네! 상담 시 실제 사례를 보여드리며 안내드리고 있습니다.
개인정보 보호를 위해 공개 채널에서는 제한이 있어요.
방문 상담 또는 DM으로 문의해 주시면 안내드리겠습니다.
→ [연락처/링크]
```

**주의사항**: 전후 사진은 규정(의료법 등) 확인 후 공유. 공개 댓글에 직접 게시 금지.

---

## 카테고리 5: 부작용/위험 질문 (3개) - 완충 표현 필수

### 5-1. 부작용 있나요?

**질문 예시**: "부작용 없나요?", "위험하지 않아요?"

**답변 템플릿**:
```
좋은 질문이에요.
[서비스]는 일반적으로 안전하게 진행되지만,
개인에 따라 [가능한 반응 예시: 약간의 불편감 등]이
있을 수 있습니다.
상담 시 개인 상황에 맞는 안내를 자세히 드리고 있어요.
→ [연락처/링크]
```

**톤 가이드**: "부작용 없다"고 단정하지 않는다. 가능성을 인정하되 과장하지 않는다.
**주의사항**: "부작용 전혀 없습니다", "안전합니다" 단독 사용 금지.

---

### 5-2. 아프지 않나요?

**질문 예시**: "아파요?", "통증이 심한가요?"

**답변 템플릿**:
```
[서비스]는 통증을 최소화하는 방식으로 진행하고 있어요.
개인에 따라 느끼는 정도가 다를 수 있지만,
대부분 [구체적 설명: 예) 가벼운 불편감 정도]로 느끼시는 편입니다.
걱정되시면 상담 시 자세히 안내드릴게요.
→ [연락처/링크]
```

---

### 5-3. [특정 조건]인데 가능한가요?

**질문 예시**: "임산부도 가능한가요?", "[질환]이 있는데 괜찮나요?"

**답변 템플릿**:
```
중요한 부분을 확인해 주셔서 감사합니다.
[특정 조건]의 경우 상황에 따라 진행 여부가 달라질 수 있어요.
정확한 확인을 위해 전문가 상담을 권장드립니다.
[전화/방문] 상담 시 상세히 안내드리겠습니다.
→ [연락처/링크]
```

**주의사항**: 의학적 판단이 필요한 질문에는 절대 댓글로 가/불가를 단정하지 않는다. 반드시 상담 유도.

---

## 카테고리 6: 비교 질문 (2개)

### 6-1. A랑 B 중에 뭐가 나아요?

**질문 예시**: "[A 서비스] vs [B 서비스] 뭐가 좋아요?"

**답변 템플릿**:
```
좋은 질문이에요!
[A]와 [B]는 각각 [장점 간단 비교]가 다릅니다.
어떤 것이 맞는지는 개인 상황에 따라 달라요.
상담 시 상황에 맞는 추천을 드리고 있으니 편하게 문의해 주세요!
→ [연락처/링크]
```

**톤 가이드**: 특정 서비스를 일방적으로 밀지 않는다. 상담으로 유도.

---

### 6-2. 다른 곳이랑 뭐가 다른가요?

**질문 예시**: "다른 [업종]이랑 차이가 뭐예요?"

**답변 템플릿**:
```
관심 가져주셔서 감사합니다!
저희는 [차별점 1]과 [차별점 2]에 집중하고 있어요.
[구체적 예시 한 문장].
더 자세한 내용은 상담 시 안내드리겠습니다!
→ [연락처/링크]
```

**톤 가이드**: 경쟁사를 직접 언급하거나 비하하지 않는다. 자사 강점만 이야기한다.

---

## 카테고리 7: 일반 감사/칭찬 (2개)

### 7-1. 좋은 정보 감사합니다

**질문 예시**: "유용해요!", "좋은 정보 감사합니다", "공유할게요!"

**답변 템플릿**:
```
도움이 되셨다니 정말 기쁩니다!
앞으로도 유용한 정보 계속 올릴게요.
궁금한 주제 있으시면 댓글로 남겨주세요!
```

**톤 가이드**: 감사를 표하고, 다음 참여를 유도한다.

---

### 7-2. 방문 후기/만족 댓글

**질문 예시**: "여기서 [서비스] 받았는데 좋았어요!", "추천합니다"

**답변 템플릿**:
```
소중한 후기 감사합니다!
[고객명/닉네임]님이 만족하셨다니 저희도 보람을 느낍니다.
앞으로도 더 좋은 서비스로 보답하겠습니다.
감사합니다!
```

**톤 가이드**: 진심 어린 감사. 과도한 리액션은 피한다.

---

## 공통 대응 규칙

### 답변 속도 기준
| 채널 | 목표 응답 시간 | 최대 허용 |
|------|--------------|----------|
| 댓글 (공개) | 1시간 이내 | 24시간 |
| DM (비공개) | 30분 이내 | 12시간 |
| 스레드 댓글 | 2시간 이내 | 24시간 |

### 부정 댓글 대응 프로세스

| 유형 | 대응 |
|------|------|
| 건설적 비판 | 감사 + 개선 의지 표명 + 상담 유도 |
| 단순 불만 | 공감 + 죄송 + DM 전환 제안 |
| 비방/욕설 | 숨김 처리 (삭제 아님) + 기록 |
| 경쟁사 어뷰징 의심 | 숨김 + 내부 보고 |
| 허위 사실 유포 | 사실 관계 정정 (차분하게) + 필요 시 법적 조치 고지 |

### 절대 하지 않는 것
- 경쟁사 이름 직접 언급하며 비교
- 공개 댓글에서 가격 구체적 공개
- 효과/결과를 단정하는 표현
- 감정적 대응 (화, 비꼼, 냉소)
- 댓글 무시 (모든 질문형 댓글에 반드시 응답)
