## 클러스터 간 연결 구조

```
[정보형 클러스터]
    │
    ├── 내부링크 ──→ [비교형 클러스터]
    │                     │
    │                     ├── 내부링크 ──→ [전환형 클러스터]
    │                     │                     │
    └── 직접 링크 ────────────────────────────→ [전환형 클러스터]
```

**연결 원칙**:
- 정보형 → 비교형: "더 알아보기" 스타일 링크
- 비교형 → 전환형: "나에게 맞는 선택은?" 스타일 링크
- 정보형 → 전환형: 글 하단 CTA 배너

## 작성 가이드

### 키워드 소스
1. 네이버 키워드 도구 / 구글 키워드 플래너
2. 연관 검색어 / 자동완성
3. 네이버 지식iN, 카페 질문 패턴
4. 경쟁사 상위 노출 키워드
5. 고객 실제 문의 내용

### 우선순위 기준 (1 = 최우선)
- **1순위**: 검색량 높음 + 전환 가능성 높음 + 난이도 낮음
- **2순위**: 검색량 중간 + 전환 가능성 높음
- **3순위**: 검색량 높음 + 난이도 중간 (장기 전략)
- **4순위**: 롱테일, 틈새 키워드 (빠른 상위 노출 가능)
- **5순위**: 브랜드 키워드, 방어적 목적

### 검색량 추정 기준
- 네이버 기준: 월간 PC + 모바일 합산
- 구글 기준: 월간 검색량 (한국)
- 추정치임을 명시하고, 실제 데이터와 비교 후 수정
