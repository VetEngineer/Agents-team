# 글 템플릿 2종

> 모든 글은 독자가 읽고 난 후 **다음 행동**을 할 수 있도록 설계한다.

---

## 템플릿 1: 전환형

**목적**: 서비스/제품 관심자를 예약/문의/구매로 전환
**적합 키워드 유형**: "[지역] + [서비스]", "[서비스] 가격", "[서비스] 잘하는 곳"
**목표 길이**: 1,500~2,500자

### 구조

```
[H1] 제목 (키워드 포함, 30~50자)
[메타 설명] 155자 이내, 행동 유도 포함

─── 섹션 1: 후킹 도입 (문제 공감) ───
- 독자의 현재 상황/고민을 정확히 짚는다
- "이런 경험 있으신가요?" 또는 구체적 시나리오 제시
- 2~3문장 이내

─── 섹션 2: 원인/배경 ───
[H2] 왜 [문제]가 생기는 걸까요?
- 문제의 원인을 2~3가지로 정리
- 독자가 "맞아, 나도 그래"라고 느끼게 한다
- 전문 용어 사용 시 바로 풀어서 설명

─── 섹션 3: 해결책 (서비스 연결) ───
[H2] [문제]를 해결하는 방법
- 일반적 해결 방법 → 우리 서비스가 왜 적합한지 자연스럽게 연결
- 과정/절차를 단계별로 설명 (번호 리스트)
- 차별점을 1~2개 구체적으로 제시

─── 섹션 4: 증거 (사례/데이터/자격) ───
[H2] [서비스명] 결과와 후기
- 실제 사례 또는 데이터 (숫자 포함)
- 전문가 자격/경력 간단 소개
- 후기 인용 (있을 경우)
- ※ 의료 업종: 과장/보장 표현 금지

─── 섹션 5: CTA (상담/예약) ───
[H2] 지금 바로 상담받아 보세요
- 행동 유도 문구 1개 (명확하고 구체적)
- 연락 방법 2~3가지 제시 (전화, 카카오톡, 온라인 예약)
- 부담 낮추는 한 마디: "부담 없이 문의해 주세요"
```

### 전환형 체크리스트
- [ ] 제목에 타겟 키워드가 자연스럽게 포함되었는가
- [ ] 도입부에서 3문장 이내에 독자의 관심을 잡았는가
- [ ] 서비스 연결이 강요가 아닌 자연스러운 흐름인가
- [ ] CTA가 1개이며 명확한가
- [ ] 증거 섹션에 구체적 숫자/사례가 있는가
- [ ] 금지 표현 체크리스트를 통과했는가

## 템플릿 2: 정보형

**목적**: 검색 유입 확보, 전문성/신뢰 구축, 내부링크를 통한 사이트 순환
**적합 키워드 유형**: "[주제] 방법", "[주제]란", "[주제] 주의사항"
**목표 길이**: 1,200~2,000자

### 구조

```
[H1] 제목 (키워드 포함, 30~50자)
[메타 설명] 155자 이내

─── 섹션 1: 후킹 도입 (궁금증) ───
- 독자가 궁금해할 만한 질문 또는 의외의 사실로 시작
- "많은 분들이 [오해]하고 계십니다" 또는 구체적 숫자
- 2~3문장 이내

─── 섹션 2: 핵심 정보 전달 ───
[H2] [주제]에 대해 알아야 할 것들
- 핵심 내용을 3~5개 소제목(H3)으로 구분
- 각 소제목당 2~4문장
- 리스트/표 활용하여 가독성 확보
- 전문 용어는 괄호 안에 쉬운 설명 추가

─── 섹션 3: 추가 팁/주의사항 ───
[H2] 꼭 알아두세요
- 실수하기 쉬운 부분, 주의사항
- "~하면 안 됩니다" 보다 "~하는 것이 좋습니다" 톤
- 팁 형식으로 정리 (번호 또는 체크 리스트)

─── 섹션 4: 관련 글 링크 (내부링크) ───
[H2] 함께 읽으면 좋은 글
- 관련 주제 글 2~3개 링크
- 자연스러운 맥락으로 연결 ("더 궁금하시다면", "관련해서")
- 앵커 텍스트에 키워드 포함

─── 섹션 5: 소프트 CTA ───
- 직접 판매가 아닌 부드러운 행동 유도
- "궁금한 점이 있으시면 편하게 문의해 주세요"
- 또는 "다른 궁금한 점은 [관련 글]에서 확인하세요"
```

### 정보형 체크리스트
- [ ] 독자가 이 글을 읽고 실제로 유용한 정보를 얻었는가
- [ ] 내부링크가 2개 이상 자연스럽게 삽입되었는가
- [ ] 소프트 CTA가 존재하는가 (정보형도 다음 행동이 있어야 한다)
- [ ] 소제목(H2, H3) 구조가 스캔 가능한가
- [ ] 문단이 3~4문장 이내인가
- [ ] 금지 표현 체크리스트를 통과했는가

## SEO 작성 규칙

1. **제목(H1)**: 타겟 키워드를 앞쪽에 배치, 30~50자
2. **메타 설명**: 155자 이내, 핵심 가치 + 행동 유도 포함
3. **URL**: 짧고 키워드 포함 (한글 가능, 영문 슬러그 권장)
4. **H2/H3**: 키워드 변형 자연 삽입
5. **키워드 밀도**: 본문 기준 1~2% (자연스러움 우선)
6. **이미지**: ALT 텍스트에 키워드 포함
7. **첫 100단어**: 타겟 키워드 1회 이상 자연 등장
8. **내부링크**: 최소 2개 (정보형), 최소 1개 (전환형)
9. **외부링크**: 신뢰 가능한 출처 1~2개 (선택)
10. **모바일 가독성**: 문단 3~4문장, 소제목 간격 적절
