# 내부링크 맵 템플릿

> 허브-스포크 구조 기반. 모든 글은 최소 1개의 내부링크를 포함해야 하며, 고아 페이지(내부링크 0개)는 허용하지 않는다.

---

## 허브-스포크 구조 개요

```
                    ┌─────────────────────────────┐
                    │     허브 페이지 (메인)        │
                    │   [핵심 서비스/주제 페이지]    │
                    └──────────┬──────────────────┘
                               │
            ┌──────────────────┼──────────────────┐
            │                  │                  │
            ▼                  ▼                  ▼
   ┌────────────────┐ ┌────────────────┐ ┌────────────────┐
   │  스포크 1       │ │  스포크 2       │ │  스포크 3       │
   │ [정보형 글]     │ │ [비교형 글]     │ │ [전환형 글]     │
   └───────┬────────┘ └───────┬────────┘ └───────┬────────┘
           │                  │                  │
     ┌─────┴─────┐      ┌────┴────┐       ┌─────┴─────┐
     ▼           ▼      ▼         ▼       ▼           ▼
  [세부 글]  [세부 글] [세부 글] [세부 글] [세부 글]  [세부 글]
```

---

## 허브 페이지 정의

| 허브 페이지 | URL | 핵심 키워드 | 역할 | 연결 스포크 수 |
|------------|-----|-----------|------|--------------|
| [메인 서비스 A 페이지] | /[url-slug] | [키워드] | 서비스 총괄 안내 | [N]개 |
| [메인 서비스 B 페이지] | /[url-slug] | [키워드] | 서비스 총괄 안내 | [N]개 |
| [블로그 카테고리 허브] | /blog/[category] | [키워드] | 정보 콘텐츠 허브 | [N]개 |

## 스포크 페이지 연결 맵

### 허브 A: [서비스 A 페이지]

| 스포크 페이지 | URL | 의도 유형 | 링크 방향 | 앵커 텍스트 |
|--------------|-----|----------|----------|------------|
| [정보형 글 1] | /blog/[slug] | 정보형 | 양방향 | "[서비스 A]에 대해 자세히 알아보기" |
| [정보형 글 2] | /blog/[slug] | 정보형 | 양방향 | "[주제] 주의사항 확인하기" |
| [비교형 글 1] | /blog/[slug] | 비교형 | 양방향 | "[A] vs [B] 비교" |
| [전환형 글 1] | /blog/[slug] | 전환형 | 단방향(스포크→허브) | "[서비스 A] 상담 예약" |
| [FAQ 페이지] | /faq/[slug] | 정보형 | 양방향 | "자주 묻는 질문" |

|--------------|-----|----------|----------|------------|
| [정보형 글 3] | /blog/[slug] | 정보형 | 양방향 | "[서비스 B] 과정 안내" |
| [비교형 글 2] | /blog/[slug] | 비교형 | 양방향 | "[서비스 B] 종류별 비교" |
| [전환형 글 2] | /blog/[slug] | 전환형 | 단방향(스포크→허브) | "[서비스 B] 예약하기" |

## 크로스 링크 (허브 간 연결)

```
[허브 A] ←──── 양방향 ────→ [허브 B]
    │                           │
    └──→ [스포크 A-1] ──→ [스포크 B-2]  (관련 주제 연결)
```

| 출발 페이지 | 도착 페이지 | 앵커 텍스트 | 링크 위치 |
|------------|------------|------------|----------|
| [허브 A] | [허브 B] | "[서비스 B]도 함께 알아보기" | 본문 하단 |
| [스포크 A-1] | [스포크 B-2] | "관련 내용: [주제]" | 본문 중간 |

## 앵커 텍스트 가이드라인

### 좋은 앵커 텍스트
- 링크 도착 페이지의 내용을 예고하는 텍스트
- 타겟 키워드를 자연스럽게 포함
- 2~8단어 길이

| 유형 | 예시 |
|------|------|
| 키워드 포함형 | "[임플란트 종류] 비교 글 확인하기" |
| 행동 유도형 | "[교정 비용] 자세히 알아보기" |
| 맥락 연결형 | "이에 대해서는 [관련 주제 글]에서 다루고 있습니다" |

### 피해야 할 앵커 텍스트
| 유형 | 예시 | 이유 |
|------|------|------|
| 일반적 텍스트 | "여기를 클릭하세요" | SEO 가치 없음 |
| URL 그대로 | "https://example.com/page" | 사용자 경험 저하 |
| 과도한 키워드 | "[키워드1] [키워드2] [키워드3] 보기" | 스팸으로 인식 |
| 동일 앵커 반복 | 모든 링크에 같은 텍스트 | 자연스럽지 않음 |

## 링크 방향 규칙

### 양방향 링크
- 허브 ↔ 스포크: 허브에서 스포크로, 스포크에서 허브로 모두 링크
- 같은 클러스터 내 스포크 간: 관련 주제끼리 상호 링크

### 단방향 링크
- 전환형 글 → 허브/서비스 페이지: 전환 유도 방향으로만
- 정보형 글 → 비교형 글: 퍼널 진행 방향으로

### 링크 수 제한
- 1개 글당 내부링크: 2~5개 (과도하면 분산)
- 허브 페이지: 스포크 전체 링크 가능 (10~15개까지)
- CTA 링크는 글당 1개만

---

## 신규 글 발행 시 링크 업데이트 체크리스트

새 글을 발행할 때마다 아래를 확인한다:

- [ ] 새 글에 기존 관련 글 2개 이상 내부링크 삽입
- [ ] 기존 관련 글 1개 이상에 새 글로의 링크 추가
- [ ] 허브 페이지에 새 글 링크 추가 (해당 시)
- [ ] 앵커 텍스트가 가이드라인에 맞는가
- [ ] 고아 페이지가 발생하지 않았는가 (모든 글에 최소 1개 인바운드 링크)

---

## 링크 건강 점검 (월 1회)

| 점검 항목 | 기준 | 조치 |
|----------|------|------|
| 깨진 링크 (404) | 0개 유지 | 즉시 수정 또는 리다이렉트 |
| 고아 페이지 | 0개 유지 | 관련 글에서 링크 추가 |
| 링크 과밀 페이지 | 15개 이하 | 불필요한 링크 제거 |
| 리다이렉트 체인 | 2단계 이하 | 직접 링크로 수정 |
| 앵커 텍스트 다양성 | 동일 텍스트 30% 이하 | 변형 텍스트 사용 |

## 시각적 맵 예시 (텍스트 다이어그램)

```
[홈페이지]
    │
    ├── [서비스 A 허브] ──┬── [A 정보글 1] ──→ [A 비교글 1]
    │                    ├── [A 정보글 2] ──→ [A 전환글 1]
    │                    ├── [A 비교글 1] ──→ [A 전환글 1]
    │                    └── [A 전환글 1] ──→ [서비스 A 허브]
    │
    ├── [서비스 B 허브] ──┬── [B 정보글 1] ──→ [B 비교글 1]
    │                    ├── [B 비교글 1] ──→ [B 전환글 1]
    │                    └── [B 전환글 1] ──→ [서비스 B 허브]
    │
    ├── [블로그 허브] ────┬── 모든 블로그 글 인덱스
    │                    └── 카테고리별 분류
    │
    └── [FAQ] ───────────── 서비스별 질문 → 각 허브로 연결

크로스 링크:
[A 정보글 2] ←──→ [B 정보글 1]  (관련 주제)
[서비스 A 허브] ←──→ [서비스 B 허브]  (상호 안내)
```
