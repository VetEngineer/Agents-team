# 콘텐츠 엔진 + SEO 팀 - 상세 책임 범위

## 1. 키워드 리서치 및 클러스터링

### 수행 업무
- 업종/서비스 기반 시드 키워드 도출
- 검색 의도별 분류: 정보형(알고 싶다), 비교형(뭐가 낫지), 전환형(지금 하고 싶다)
- 클러스터당 10개 이상 키워드 묶음 구성
- 월간 검색량, 경쟁 난이도, 비즈니스 우선순위 평가
- 롱테일 키워드 발굴 (질문형, 지역 결합형)

### 산출물
- 키워드 클러스터 시트 (3묶음 이상)
- 키워드 우선순위 매트릭스 (검색량 x 전환 가능성)

### 품질 체크
- [ ] 각 클러스터에 정보/비교/전환 키워드가 균형 있게 포함되었는가
- [ ] 지역명 + 서비스 조합 키워드를 포함했는가
- [ ] 경쟁사가 잡고 있는 키워드를 확인했는가

---

## 2. 콘텐츠 전략 수립

### 수행 업무
- 02_전략팀의 브랜드 포지셔닝/메시지를 콘텐츠 방향으로 변환
- 퍼널 단계별 콘텐츠 유형 매핑 (인지 → 고려 → 전환 → 유지)
- 경쟁사 콘텐츠 갭 분석
- 콘텐츠 믹스 비율 설정 (정보:비교:전환 = 5:3:2 등)
- 시즌/이벤트 연동 주제 선정

### 산출물
- 콘텐츠 전략 개요서
- 퍼널별 콘텐츠 매핑 표
- 콘텐츠 믹스 비율표

---

## 3. 월간 발행 캘린더 관리

### 수행 업무
- 주 2~5회 발행 기준 4주 캘린더 작성
- 주차별 테마 설정 (예: 1주차 인지, 2주차 비교, 3주차 전환, 4주차 신뢰)
- 주제, 키워드, 목표, CTA, 후킹 문장 사전 정의
- 발행 진행 상황 추적 (초안/검토/수정/발행/분석)
- 시즌 이벤트, 업계 이슈 반영

### 산출물
- 4주 콘텐츠 캘린더 (표 형식)
- 주차별 테마 설명서

### 품질 체크
- [ ] 주제가 겹치지 않는가
- [ ] 전환형과 정보형 비율이 적절한가
- [ ] 후킹 문장이 구체적인가 (막연한 질문 금지)

---

## 4. 글 템플릿 설계 및 유지

### 수행 업무
- 전환형 글 템플릿 설계 (후킹 → 문제 → 해결 → 증거 → CTA)
- 정보형 글 템플릿 설계 (궁금증 → 정보 → 팁 → 내부링크 → 소프트 CTA)
- 업종별 금지 표현 체크리스트 작성
- H1/H2/H3 구조 가이드라인
- 메타 설명 작성 공식

### 산출물
- 글 템플릿 2종 (전환형, 정보형)
- 금지 표현 체크리스트
- 헤딩 구조 가이드

---

## 5. 원고 생산 및 품질 관리

### 수행 업무
- 캘린더 기반 원고 초안 작성
- 키워드 자연 삽입 (밀도 1~2%)
- 메타 설명 155자 이내 작성
- 이미지 ALT 텍스트 제안
- 구조화 데이터 마크업 제안 (FAQ, HowTo, LocalBusiness 등)
- 가독성 검토 (문장 길이, 문단 구분, 소제목 간격)

### 산출물
- 원고 초안 (요청 수량)
- 원고 검토 체크리스트 (발행 전 확인)

### 품질 체크
- [ ] CTA가 명확하고 1개인가
- [ ] 위험 표현이 없는가 (의료/법률 업종)
- [ ] 키워드가 자연스럽게 녹아 있는가
- [ ] 문단이 3~4문장 이내인가
- [ ] 소제목(H2)이 스크롤 없이 2개 화면 이상 떨어져 있지 않은가

---

## 6. 내부링크 구조 설계

### 수행 업무
- 허브-스포크 모델 설계 (메인 페이지 → 세부 페이지)
- 글 간 링크 방향 및 앵커 텍스트 정의
- 신규 글 발행 시 기존 글과의 링크 업데이트 계획
- 고아 페이지(내부링크 0개) 방지
- 사이트맵 구조와 일치 여부 확인

### 산출물
- 내부링크 맵 (허브-스포크 다이어그램)
- 앵커 텍스트 가이드
- 링크 업데이트 체크리스트

---

## 7. SEO 성과 측정 지표 정의

### 수행 업무
- 핵심 지표(KPI) 정의: 오가닉 유입, 키워드 순위, CTR, 체류시간, 전환율
- 글별 성과 추적 기준 수립
- 월간 SEO 리포트 항목 정의
- 개선 대상 콘텐츠 선별 기준 (순위 하락, 체류시간 감소 등)
- A/B 테스트 항목 제안 (제목, 메타설명, CTA 문구)

### 산출물
- SEO KPI 대시보드 구성안
- 월간 리포트 템플릿
- 콘텐츠 개선 우선순위 매트릭스

---

## 8. 컴플라이언스 사전 검토

### 수행 업무
- 업종별 광고/표현 규제 확인 (의료법, 변호사법, 표시광고법 등)
- 위험 표현 자동 플래그 리스트 유지
- 대체 문구 제안 (예: "확실히 낫습니다" → "개선이 기대됩니다")
- 사전/사후 사진 사용 가이드라인
- 가격 표시 규정 확인

### 산출물
- 업종별 금지 표현 리스트
- 대체 문구 사전
- 컴플라이언스 체크리스트

### 위험 표현 예시 (의료 업종)
| 금지 표현 | 대체 표현 |
|-----------|-----------|
| "100% 효과" | "많은 분들이 만족하고 계십니다" |
| "부작용 없음" | "개인에 따라 다를 수 있습니다" |
| "최고의 시술" | "풍부한 경험을 바탕으로 진행합니다" |
| "확실한 결과" | "긍정적인 결과가 기대됩니다" |
| "전후 비교 사진" | 별도 동의 및 규정 확인 필요 |
