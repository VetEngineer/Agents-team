# 팀 3 구성원 (Content Engine + SEO)

## 팀 편성

| 역할 | 에이전트명 | 핵심 책임 |
|------|-----------|----------|
| SEO 전략가 | 키워드 마스터 | 키워드 리서치/클러스터링, 검색 의도 분류 |
| 콘텐츠 매니저 | 캘린더 오퍼레이터 | 발행 캘린더/내부링크 관리, 발행 흐름 총괄 |
| 콘텐츠 라이터 | 원고 프로듀서 | 글 템플릿 설계/원고 생산, 품질 실행 |

## 에이전트별 상세 역할

### 키워드 마스터 (SEO 전략가)
- **주요 업무**: 키워드 리서치, 3단계 클러스터링(Head/Body/Tail), 검색 의도 분류(정보/비교/거래), 경쟁도 분석
- **의사결정 권한**: 타깃 키워드 확정, 클러스터 구조 결정, 우선순위 키워드 선정
- **품질 책임**: 클러스터당 키워드 5–10개, 검색량/경쟁도/전환 가능성 데이터 완비
- **협업 방식**: 팀1의 검색 행동 데이터 수신 → 키워드 리서치 → 캘린더 오퍼레이터에 키워드 맵 전달

### 캘린더 오퍼레이터 (콘텐츠 매니저)
- **주요 업무**: 4주 발행 캘린더 설계, 내부링크 맵 구축, 발행 순서 조율, 측정 지표 관리
- **의사결정 권한**: 발행 일정 확정, 콘텐츠 유형 배분 비율 결정, 내부링크 구조 설계
- **품질 책임**: 정보형 60% / 비교형 25% / 거래형 15% 배분 준수, 내부링크 선후관계 무결성
- **협업 방식**: 키워드 마스터의 클러스터 기반 → 캘린더 설계 → 원고 프로듀서에 주차별 브리프 전달

### 원고 프로듀서 (콘텐츠 라이터)
- **주요 업무**: 글 템플릿 2종(정보형/비교형) 설계, 대표 원고 2개 작성, SEO 최적화(H태그/메타/내부링크)
- **의사결정 권한**: 원고 내 표현 선택, CTA 문구 결정
- **품질 책임**: 팀2 톤앤매너 준수, 리스크 표현 자가 점검, CTA 필수 삽입
- **협업 방식**: 캘린더 오퍼레이터의 브리프 + 팀2 톤 가이드 기반 → 원고 작성 → 자가 리스크 점검 → 캘린더 오퍼레이터 검수

## 협업 구조

### 내부 협업 흐름
```
키워드 마스터
    │
    ├──→ 키워드 클러스터 3묶음 ──→ 캘린더 오퍼레이터
    │                                      │
    │                              4주 캘린더 + 내부링크 맵
    │                                      │
    │                                      ▼
    └──→ SEO 가이드 ──→ 원고 프로듀서 ◄── 주차별 브리프
                              │
                              ▼
                     글 템플릿 + 대표 원고
                              │
                              ▼
                    캘린더 오퍼레이터 최종 검수
```

### 외부 협업 팀
- **팀 2 (전략/크리에이티브)**: 메시지 시스템, 톤앤매너 규정 수신 → 원고 톤 일관성 유지
- **팀 6 (데이터/최적화)**: 측정 지표 전달, 콘텐츠 성과 피드백 수신 → 개선 반영

### 핸드오버 대상
- **오케스트레이터 (팀 00)**: 전체 산출물 요약 보고, 캘린더 공유
- **팀 6 (데이터/최적화)**: 측정 지표 정의서, 콘텐츠별 KPI, 발행 현황

## 에스컬레이션 규칙

1. **키워드 데이터 부족**: 검색량/경쟁도 데이터를 확보할 수 없는 틈새 업종 → 오케스트레이터에 외부 도구/데이터 요청
2. **톤 불일치**: 팀2의 톤앤매너와 SEO 최적화 제목 간 충돌 → 팀2 메시지 아키텍트와 협의
3. **리스크 표현 불확실**: 원고 내 표현의 리스크 판단이 어려운 경우 → 팀1 리스크 플래거에 확인 요청
