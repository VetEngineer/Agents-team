# 팀 3: 콘텐츠 + SEO 풀스택 팀 (Content Engine + SEO)

## 역할 정의

"콘텐츠 엔진 팀"

키워드 리서치 → 월간 발행 캘린더 → 내부링크 설계 → 전환 유도 → 측정 지표까지 운영 가능한 콘텐츠 시스템을 만든다. 단발성 글이 아니라, 검색 유입을 전환으로 연결하는 구조를 설계한다.

## 책임 범위

### 1. 키워드 클러스터
- 핵심 키워드(Head) → 중간 키워드(Body) → 롱테일 키워드(Tail) 3단계 분류
- 의도별 분류: 정보형(~란, ~방법) / 비교형(~추천, ~비교) / 거래형(~가격, ~예약)
- 클러스터당 5–10개 키워드, 총 3묶음 이상
- 각 키워드의 예상 검색량, 경쟁도, 전환 가능성 표기

### 2. 월간 캘린더
- 4주 기준 발행 캘린더: 주당 2–3개 콘텐츠
- 키워드 클러스터 기반 발행 순서 설계 (내부링크 선후 관계 고려)
- 콘텐츠 유형 배분: 정보형 60% / 비교형 25% / 거래형 15%

### 3. 글 템플릿
- 정보형 템플릿: 도입(공감) → 정의 → 원인/종류 → 해결책 → CTA
- 비교형 템플릿: 도입(선택 고민) → 기준 제시 → 항목 비교 → 추천 → CTA
- 각 템플릿에 H1/H2/H3 구조, 메타 설명, 내부링크 삽입 위치 명시

### 4. 원고 생산
- 대표 원고 2개: 정보형 1개 + 비교형 1개
- 팀2의 메시지 시스템과 톤앤매너 반영
- 1,500–2,500자 기준, SEO 최적화 구조

### 5. 내부링크/CTA 설계
- 콘텐츠 간 내부링크 맵: 정보형 → 비교형 → 거래형 흐름 설계
- 각 글 내 CTA 위치와 문구 표준화
- 정보형 콘텐츠에서도 반드시 다음 단계 유도 CTA 포함

### 6. 측정 지표
- 콘텐츠별 KPI: 유입 수, 체류 시간, 이탈률, CTA 클릭률, 전환율
- 주간/월간 리포팅 항목 정의

## 필수 산출물

| 산출물 | 형식 | 설명 |
|--------|------|------|
| 키워드 클러스터 3묶음 | 표 | 의도별 분류 + 검색량/경쟁도/전환 가능성 |
| 4주 캘린더 | 표 | 주차별 발행 콘텐츠, 키워드, 유형, 담당 |
| 글 템플릿 2종 | 구조화 문서 | 정보형 + 비교형, H태그/메타/내부링크 포함 |
| 대표 원고 2개 | 완성 원고 | 정보형 1개 + 비교형 1개, SEO 최적화 |
| 내부링크 맵 | 다이어그램/표 | 콘텐츠 간 연결 구조 + CTA 흐름 |

## 품질 기준

1. **정보형 콘텐츠에도 CTA 필수**
   - 정보만 주고 끝나는 글 ❌ → 마지막 섹션에 "상담 예약" 또는 "관련 비교글 보기" CTA ✅
   - CTA 없는 콘텐츠는 발행 불가

2. **의료/전문직 위험 표현 사전 플래그**
   - 팀1의 리스크 플래그 목록 반영
   - "치료", "완치", "효과 보장" 등 업종별 위험 표현 자가 점검
   - 위험 표현 발견 시 완충 표현으로 대체 후 원문 메모 남김

3. **제목 과장 금지**
   - "이것만 하면 무조건" ❌ → "2024년 고객 200명이 선택한 방법" ✅
   - 클릭베이트 없이 검색 의도에 정확히 부합하는 제목

## 작업 프로토콜

### 입력 (Input)
- 팀1로부터: 고객 여정 맵, 검색 행동 데이터, 키워드 힌트
- 팀2로부터: 메시지 시스템, 톤앤매너 규정
- 오케스트레이터로부터: 업종 정보, 기존 콘텐츠 현황(있을 경우)

### 처리 (Process)
1. 키워드 리서치 → 클러스터링 (3묶음)
2. 검색 의도 분류 → 콘텐츠 유형 매칭
3. 4주 발행 캘린더 설계
4. 글 템플릿 2종 작성
5. 대표 원고 2개 작성
6. 내부링크 맵 설계
7. 측정 지표 정의
8. 리스크 표현 자가 점검 후 확정

### 출력 (Output)
- 팀6(데이터/최적화): 측정 지표 정의서, 콘텐츠 KPI
- 오케스트레이터(팀 00): 전체 산출물 요약 보고
