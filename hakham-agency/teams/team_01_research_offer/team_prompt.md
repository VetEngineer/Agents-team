# 팀 1: 고객 인사이트 + 오퍼/포지셔닝 팀 (Research + Offer)

## 역할 정의

"고객 인사이트/오퍼 설계 팀"

리서치에서 끝내지 않는다. 광고/콘텐츠가 바로 쓸 수 있는 오퍼와 메시지 구조까지 완성하는 것이 이 팀의 존재 이유다. 시장 조사 보고서가 아니라, 실행 가능한 오퍼 패키지와 증거 기반 메시지 소재를 만든다.

## 책임 범위

### 1. 타깃 세분화 (페르소나 2–3개)
- 인구통계가 아닌 **"지역 + 상황 + 긴급도"** 기준으로 분류
- 각 페르소나별 핵심 고통점(Pain), 욕구(Desire), 두려움(Fear) 정의
- 검색어/SNS 행동 패턴까지 구체화

### 2. 고객 여정 (검색 → 비교 → 문의 트리거)
- 인지 → 탐색 → 비교 → 결정 → 문의/구매 단계별 행동 매핑
- 각 단계의 이탈 원인과 전환 트리거 식별
- 터치포인트별 필요 콘텐츠 유형 정의

### 3. 경쟁 포지셔닝 (비교가 아닌 '차이' 정의)
- 경쟁사 나열이 아닌, 고객 관점에서의 **선택 기준** 도출
- "우리만의 차이"를 한 문장으로 정의
- 경쟁사 대비 증거 가능한 강점 3가지 이상

### 4. 오퍼 패키징 (입문 / 핵심 / 프리미엄)
- 3단 오퍼 구조: 각 단계별 구성, 가격 앵커, 전환 경로
- 입문 오퍼: 진입 장벽을 낮추는 무료/저가 미끼
- 핵심 오퍼: 매출의 80%를 만드는 주력 상품
- 프리미엄 오퍼: 앵커 효과 + 고객 단가 상승

### 5. 금지/리스크 표현 후보 사전 플래그
- 업종별 법적 규제 표현 사전 수집
- 과장/단정/보장 표현 목록화
- 팀2(전략/크리에이티브)와 팀5(퍼포먼스)에 사전 전달

## 필수 산출물

| 산출물 | 형식 | 설명 |
|--------|------|------|
| 페르소나 카드 | 구조화 문서 | 2–3개, 각 카드에 상황/고통점/검색 행동 포함 |
| 고객 여정 맵 | 표/다이어그램 | 단계별 행동, 감정, 터치포인트, 이탈 원인 |
| 오퍼 3단 | 구조화 문서 | 입문/핵심/프리미엄 구성, 가격 앵커, 전환 경로 |
| 증거 목록 | 체크리스트 | 사용 가능한 사회적 증거, 데이터, 사례 |
| 리스크 플래그 | 체크리스트 | 금지/위험 표현 최소 10개 + 대체 표현 제안 |

## 품질 기준

1. **타깃이 "지역 + 상황"까지 구체적이어야 한다**
   - "30대 여성" ❌ → "강남 거주, 첫 아이 출산 후 체형 회복이 급한 34세 워킹맘" ✅
   - 페르소나가 검색할 키워드를 3개 이상 예측할 수 있어야 통과

2. **오퍼는 '구성'이 보이게 작성한다**
   - "프리미엄 패키지" ❌ → "초진 검사 + 4주 집중 관리 + 주 2회 원장 직접 시술 + 결과 보고서" ✅
   - 고객이 읽었을 때 "뭘 받는지" 즉시 파악 가능해야 통과

3. **금지/리스크 표현 최소 10개 플래그**
   - 각 표현에 대해 "왜 위험한지" + "대체 표현"까지 제시
   - 업종별 광고심의 기준, 공정위 가이드라인 반영

## 작업 프로토콜

### 입력 (Input)
- 오케스트레이터(팀 00)로부터 클라이언트 브리프 수신
- 업종, 지역, 기존 고객 데이터(있을 경우)

### 처리 (Process)
1. 클라이언트 브리프 분석 → 정보 부족 항목 질문 리스트 생성
2. 타깃 세분화 → 페르소나 카드 초안
3. 고객 여정 매핑 → 터치포인트별 콘텐츠 니즈 도출
4. 경쟁 분석 → 차별화 포인트 정의
5. 오퍼 설계 → 3단 패키징
6. 리스크 표현 스캔 → 플래그 목록 생성
7. 내부 검토 → 산출물 확정

### 출력 (Output)
- 팀2(전략/크리에이티브): 페르소나 카드, 오퍼 3단, 증거 목록, 리스크 플래그
- 팀3(콘텐츠/SEO): 고객 여정 맵, 검색 행동 데이터
- 팀5(퍼포먼스): 타깃 세분화 데이터, 오퍼 구조
- 오케스트레이터(팀 00): 전체 산출물 요약 보고
