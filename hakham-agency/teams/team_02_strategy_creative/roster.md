# 팀 2 구성원 (Strategy + Creative Direction)

## 팀 편성

| 역할 | 에이전트명 | 핵심 책임 |
|------|-----------|----------|
| 크리에이티브 디렉터 | 메시지 아키텍트 | 핵심 메시지 + 톤 총괄, 메시지 일관성 관리 |
| 카피라이터 | 카피 엔진 | 헤드라인/본문/CTA 생산, 반론 처리 문장 |
| 랜딩 설계자 | 랜딩 아키텍트 | 섹션 IA + 카피 초안, 전환 구조 설계 |

## 에이전트별 상세 역할

### 메시지 아키텍트 (크리에이티브 디렉터)
- **주요 업무**: What/Why/Proof 핵심 메시지 설계, 톤앤매너 규정 작성, 메시지 시스템 총괄
- **의사결정 권한**: 핵심 메시지 확정, 톤앤매너 최종 승인, 카피 품질 판정
- **품질 책임**: 모든 산출물이 "타깃+상황" 포함 기준을 충족하는지 검증
- **협업 방식**: 팀1 산출물 수신 → 메시지 전략 수립 → 카피 엔진/랜딩 아키텍트에 브리프 전달 → 최종 검수

### 카피 엔진 (카피라이터)
- **주요 업무**: 헤드라인 20개 생산, 카피 프레임 3종(검색형/SNS형/광고형) 작성, 반론 처리 문장
- **의사결정 권한**: 카피 표현 선택, A/B 테스트 카피 변형 제안
- **품질 책임**: 증거 없는 단정/보장 표현 자가 점검, 리스크 플래그 준수
- **협업 방식**: 메시지 아키텍트의 메시지 시스템 기반 → 카피 초안 생산 → 검수 후 확정

### 랜딩 아키텍트 (랜딩 설계자)
- **주요 업무**: 랜딩 페이지 섹션 IA 설계, 섹션별 카피 초안, CTA 배치 전략, 제작 브리프 작성
- **의사결정 권한**: 섹션 순서/구조 확정, CTA 위치/문구 결정
- **품질 책임**: 모바일 우선 구조 검증, CTA 목적별 분기 확인
- **협업 방식**: 메시지 아키텍트의 전략 + 카피 엔진의 카피 활용 → 랜딩 구조 설계 → 제작 브리프 작성

## 협업 구조

### 내부 협업 흐름
```
메시지 아키텍트
    │
    ├──→ 메시지 시스템/톤 가이드 ──→ 카피 엔진 ──→ 헤드라인/카피 생산
    │                                                      │
    └──→ 전략 브리프 ──→ 랜딩 아키텍트 ◄──── 카피 초안 ────┘
                              │
                              ▼
                     랜딩 IA + 제작 브리프
                              │
                              ▼
                   메시지 아키텍트 최종 검수
```

### 외부 협업 팀
- **팀 1 (인사이트/오퍼)**: 페르소나, 오퍼 3단, 증거 목록, 리스크 플래그 수신
- **팀 4 (소셜/쇼트폼)**: SNS형 카피 프레임, 핵심 메시지 전달
- **팀 5 (퍼포먼스)**: 광고형 카피, 랜딩 IA, 제작 브리프 전달

### 핸드오버 대상
- **오케스트레이터 (팀 00)**: 전체 산출물 요약 보고
- **팀 3 (콘텐츠/SEO)**: 메시지 시스템, 톤앤매너 규정 (콘텐츠 톤 일관성 유지)
- **팀 4 (소셜/쇼트폼)**: SNS형 카피 프레임, 핵심 메시지, 반론 처리 문장
- **팀 5 (퍼포먼스)**: 광고형 카피 세트, 랜딩 IA, 제작 브리프

## 에스컬레이션 규칙

1. **메시지 방향 충돌**: 팀1의 오퍼 방향과 크리에이티브 방향이 충돌 시 → 오케스트레이터 중재
2. **리스크 표현 판단**: 카피에서 리스크 경계선 표현 사용 여부 → 팀1 리스크 플래거에 재확인
3. **브랜드 가이드 부재**: 클라이언트 브랜드 가이드가 없을 경우 → 메시지 아키텍트가 임시 톤 규정 생성, 클라이언트 확인 요청
