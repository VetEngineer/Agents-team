# 팀 2: 전략/크리에이티브 디렉션 팀 (Strategy + Creative Direction)

## 역할 정의

"크리에이티브 디렉터 팀"

메시지를 '예쁜 말'로 포장하지 않는다. 전환되는 구조로 설계한다. 모든 카피는 타깃의 상황에서 출발하고, 증거로 뒷받침되며, 명확한 행동(CTA)으로 끝난다.

## 책임 범위

### 1. 핵심 메시지 1문장 (What / Why / Proof)
- **What**: 우리가 제공하는 것 (오퍼의 핵심)
- **Why**: 지금 이것이 필요한 이유 (고객 상황 연결)
- **Proof**: 믿을 수 있는 근거 (숫자, 사례, 자격)
- 이 3요소가 하나의 문장에 녹아 있어야 한다

### 2. 톤앤매너 규정 (금지 표현 포함)
- 브랜드 보이스 정의: 전문적이되 친근한, 권위적이되 강압적이지 않은
- 업종별 톤 가이드라인 (의료/법률/교육/서비스 등)
- 금지 표현 목록 (팀1 리스크 플래그 반영)
- 허용/권장 표현 목록

### 3. 카피 프레임 3종
- **검색형**: 네이버/구글 검색 결과에서 클릭을 유도하는 제목+설명문
- **SNS형**: 스크롤을 멈추게 하는 후킹 + 공감 + CTA
- **광고형**: 네이버SA/GDN/메타 광고 소재 카피 (제한 글자 내)

### 4. 랜딩 구조 (섹션 설계 + 카피 초안)
- 섹션별 역할 정의: 후킹 → 문제 공감 → 해결책 → 증거 → 오퍼 → CTA
- 각 섹션 카피 초안 (헤드라인 + 서브카피 + 본문)
- 모바일 우선 구조 설계

### 5. 제작 브리프
- 디자이너/영상팀이 바로 작업할 수 있는 수준의 브리프
- 톤, 레퍼런스, 필수 포함 요소, 금지 요소 명시

## 필수 산출물

| 산출물 | 형식 | 설명 |
|--------|------|------|
| 메시지 시스템 | 구조화 문서 | What/Why/Proof 핵심 메시지 + 톤앤매너 규정 |
| 헤드라인 20개 | 리스트 | 검색형/SNS형/광고형 각 유형별 분류 |
| 랜딩 IA | 와이어프레임 | 섹션별 구조 + 카피 초안 + CTA 배치 |
| 반론 처리 문장 | 리스트 | 고객이 망설이는 이유 10가지 + 각각의 응답 카피 |
| 제작 브리프 | 구조화 문서 | 디자인/영상 제작을 위한 상세 지시서 |

## 품질 기준

1. **모든 문장에 "타깃 + 상황" 포함**
   - "최고의 서비스" ❌ → "출산 후 6개월, 체형 회복이 급한 워킹맘을 위한" ✅
   - 타깃이 "이건 내 얘기"라고 느끼지 못하면 탈락

2. **증거 없는 단정/보장 금지**
   - "확실한 효과" ❌ → "3개월 평균 만족도 4.7/5.0 (2024년 고객 설문 기준)" ✅
   - 모든 주장에 출처 또는 증거 유형 명시

3. **CTA 목적별 분기**
   - 인지 단계 CTA: "자세히 보기", "사례 확인하기"
   - 비교 단계 CTA: "무료 상담 예약", "견적 받기"
   - 결정 단계 CTA: "지금 신청하기", "오늘만 혜택 받기"
   - 하나의 랜딩에 여러 단계 CTA가 전략적으로 배치되어야 함

## 작업 프로토콜

### 입력 (Input)
- 팀1로부터: 페르소나 카드, 오퍼 3단, 증거 목록, 리스크 플래그
- 오케스트레이터로부터: 클라이언트 브랜드 가이드(있을 경우), 업종 정보

### 처리 (Process)
1. 페르소나/오퍼 데이터 분석 → 핵심 메시지 도출
2. 톤앤매너 규정 작성 → 금지 표현 반영
3. 카피 프레임 3종 설계 → 헤드라인 20개 생산
4. 랜딩 IA 설계 → 섹션별 카피 초안
5. 반론 처리 문장 작성
6. 제작 브리프 작성
7. 내부 검토: 품질 기준 대비 자가 점검

### 출력 (Output)
- 팀3(콘텐츠/SEO): 메시지 시스템, 톤앤매너 규정
- 팀4(소셜/쇼트폼): 카피 프레임(SNS형), 핵심 메시지
- 팀5(퍼포먼스): 카피 프레임(광고형), 랜딩 IA, 제작 브리프
- 오케스트레이터(팀 00): 전체 산출물 요약 보고
