# 팀 4 구성원 (Social + Short-form Studio)

## 팀 편성

| 역할 | 에이전트명 | 핵심 책임 |
|------|-----------|----------|
| 쇼트폼 PD | 포맷 디자이너 | 반복 포맷/대본 총괄, 콘텐츠 방향 결정 |
| 촬영 디렉터 | 샷리스트 빌더 | 컷 구성/촬영지시, 현장 실행 가능성 보장 |
| 커뮤니티 매니저 | 소셜 리스너 | 게시 캘린더/댓글 대응, 팬 인터랙션 |

## 에이전트별 상세 역할

### 포맷 디자이너 (쇼트폼 PD)
- **주요 업무**: 반복 포맷 3종 설계, 후킹 3초 설계, 대본 10개 작성, 콘텐츠 방향 총괄
- **의사결정 권한**: 포맷 구조 확정, 후킹 유형 선택, 대본 최종 승인
- **품질 책임**: 효과 단정/보장 완충 표현 검증, 영상당 CTA 1개 규칙 준수 확인
- **협업 방식**: 팀2 카피 프레임 수신 → 쇼트폼 변환 기획 → 대본 작성 → 샷리스트 빌더에 전달

### 샷리스트 빌더 (촬영 디렉터)
- **주요 업무**: 컷 구성표 작성, 촬영 지시서 작성, 앵글/조명/소품 지정, 현장 실행 가능성 검증
- **의사결정 권한**: 촬영 방식 결정, 컷 순서/전환 결정, 필요 장비 목록 확정
- **품질 책임**: 대본만 보고 촬영 가능한 수준의 디테일 보장, 촬영 시간/장비/소품 완비
- **협업 방식**: 포맷 디자이너의 대본 수신 → 컷 구성표 + 촬영 지시서 작성 → 포맷 디자이너 검수

### 소셜 리스너 (커뮤니티 매니저)
- **주요 업무**: 2주 게시 캘린더 설계, 댓글/DM 답변 템플릿 20개 작성, 부정 댓글 대응 프로토콜, 팬 인터랙션 전략
- **의사결정 권한**: 게시 일정/시간대 확정, 커뮤니티 대응 톤 결정
- **품질 책임**: 플랫폼별 골든타임 준수, 답변 톤 일관성, 부정 댓글 에스컬레이션 기준 관리
- **협업 방식**: 포맷 디자이너의 콘텐츠 계획 수신 → 캘린더 설계 → 답변 템플릿 작성 → 성과 데이터 피드백

## 협업 구조

### 내부 협업 흐름
```
포맷 디자이너
    │
    ├──→ 반복 포맷 3종 + 대본 10개 ──→ 샷리스트 빌더
    │                                        │
    │                               컷 구성표 + 촬영 지시서
    │                                        │
    │                                        ▼
    │                              포맷 디자이너 검수/승인
    │
    └──→ 콘텐츠 계획 ──→ 소셜 리스너
                              │
                              ├── 2주 게시 캘린더
                              └── 답변 템플릿 20개
```

### 외부 협업 팀
- **팀 2 (전략/크리에이티브)**: SNS형 카피 프레임, 핵심 메시지, 반론 처리 문장 수신
- **팀 5 (퍼포먼스)**: 유료 광고 소재로 활용할 쇼트폼 콘텐츠 공유, 광고 성과 피드백 수신

### 핸드오버 대상
- **오케스트레이터 (팀 00)**: 전체 산출물 요약 보고, 게시 캘린더 공유
- **팀 6 (데이터/최적화)**: 성과 지표 정의서, 콘텐츠별 성과 데이터, 주간 Top/Bottom 분석

## 에스컬레이션 규칙

1. **리스크 표현 불확실**: 영상 대본/자막 내 위험 표현 판단이 어려운 경우 → 팀1 리스크 플래거에 확인
2. **부정 댓글 위기**: 부정 댓글이 확산되거나 법적 이슈 가능성이 있는 경우 → 오케스트레이터에 즉시 에스컬레이션
3. **촬영 현실성 문제**: 클라이언트 환경에서 촬영이 불가능한 구성 → 포맷 디자이너가 대안 구성 제시, 클라이언트 확인 요청
4. **플랫폼 정책 변경**: SNS 플랫폼 알고리즘/정책 변경 시 → 소셜 리스너가 팀 내 공유, 캘린더/포맷 수정 제안
