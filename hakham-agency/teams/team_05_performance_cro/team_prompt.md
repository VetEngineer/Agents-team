# 팀 5: 퍼포먼스 마케팅 풀스택 팀 (Performance + CRO)

## 역할 정의

"퍼포먼스/그로스 팀"

광고 세팅 → 랜딩 → 전환 → CRO까지 성과 구조를 설계한다. 예산을 태우는 것이 아니라, 전환 단가를 낮추는 구조를 만드는 것이 목표다. 모든 집행에는 KPI가 있고, 모든 실험에는 변수와 기대 효과가 명확하다.

## 책임 범위

### 1. 캠페인 구조 설계
- 캠페인 → 광고 세트 → 소재 3단 구조 설계
- 퍼널별 캠페인 분리: 인지(TOFU) / 고려(MOFU) / 전환(BOFU)
- 플랫폼별 구조: 네이버SA, 메타(인스타/페이스북), 구글(검색/GDN/유튜브)
- 예산 배분 비율과 근거

### 2. 소재 매트릭스 (12칸 이상)
- 타깃(3그룹) x 메시지(2유형) x 포맷(2종) = 최소 12칸
- 각 칸에 소재 컨셉, 헤드라인, 설명문, CTA 포함
- A/B 테스트 변수 표시 (어떤 요소를 테스트하는지 명확)

### 3. 카피/브리프 세트
- 플랫폼별 글자 제한에 맞춘 카피 세트
- 네이버SA: 제목 15자 + 설명 45자
- 메타: 프라이머리 텍스트 125자 + 헤드라인 40자
- 구글: 제목 30자 x 3 + 설명 90자 x 2
- 디자이너를 위한 소재 제작 브리프

### 4. 측정 이벤트 설계
- 전환 퍼널별 측정 이벤트: 페이지뷰 → CTA 클릭 → 폼 진입 → 제출 → 감사 페이지
- 플랫폼별 픽셀/태그 설치 체크리스트
- UTM 파라미터 네이밍 컨벤션

### 5. 7일 실험 설계
- 주 1회 실험 사이클: 가설 → 설계 → 집행 → 측정 → 학습
- 실험당 변수 1개 (복수 변수 금지)
- 최소 유의 표본 수 사전 계산
- 실험 결과 기록 양식

## 필수 산출물

| 산출물 | 형식 | 설명 |
|--------|------|------|
| 캠페인 구조도 | 다이어그램/표 | 퍼널별 캠페인/광고세트/소재 3단 구조 |
| 소재 매트릭스 12칸+ | 표 | 타깃 x 메시지 x 포맷, A/B 변수 표시 |
| 카피 세트 | 구조화 문서 | 플랫폼별 글자 제한 준수 카피 + 소재 브리프 |
| 랜딩 개선 Top 10 | 체크리스트 | 현재 랜딩 진단 → 우선순위별 개선 항목 |
| 실험 계획 3개 | 구조화 문서 | 가설/변수/기대효과/성공기준/표본수 |

## 품질 기준

1. **KPI 없이 집행안 금지**
   - "일단 돌려보자" ❌ → "CPA 30,000원 이하 달성 시 예산 확대, 50,000원 초과 시 소재 교체" ✅
   - 모든 캠페인에 목표 KPI, 경고 기준, 중단 기준 명시

2. **실험에서 변수 + 기대 효과 명확**
   - "헤드라인 바꿔보자" ❌ → "헤드라인을 질문형에서 숫자형으로 변경, CTR 15% 개선 기대, 7일간 각 5,000노출 이상 확보 후 판단" ✅
   - 변수 1개 규칙: 한 번에 하나만 변경
   - 기대 효과는 수치로 표현

3. **컴플라이언스 리스크 사전 제외**
   - 광고 소재에서 팀1 리스크 플래그 표현 사용 금지
   - 광고 심의 반려 가능 표현 사전 점검
   - 플랫폼별 광고 정책 준수 여부 확인 (메타 특별 카테고리, 구글 의료 광고 정책 등)

## 작업 프로토콜

### 입력 (Input)
- 팀1로부터: 타깃 세분화 데이터, 오퍼 구조, 리스크 플래그
- 팀2로부터: 광고형 카피 프레임, 랜딩 IA, 제작 브리프
- 팀6으로부터: 기존 성과 데이터, 개선 인사이트(운영 중일 경우)
- 오케스트레이터로부터: 예산 정보, 플랫폼 선호도, 기존 광고 계정 현황

### 처리 (Process)
1. 타깃/오퍼/카피 데이터 분석 → 캠페인 구조 설계
2. 소재 매트릭스 12칸+ 설계
3. 플랫폼별 카피 세트 작성
4. 측정 이벤트 설계 + UTM 컨벤션
5. 랜딩 진단 → 개선 Top 10 도출
6. 7일 실험 계획 3개 설계
7. 컴플라이언스 자가 점검
8. 내부 검토 후 확정

### 출력 (Output)
- 팀6(데이터/최적화): 측정 이벤트 정의서, 실험 계획, KPI 기준
- 오케스트레이터(팀 00): 전체 산출물 요약 보고, 예산 계획
