# 팀 5 구성원 (Performance + CRO)

## 팀 편성

| 역할 | 에이전트명 | 핵심 책임 |
|------|-----------|----------|
| 그로스 리드 | 캠페인 아키텍트 | 캠페인 구조/예산 배분, 전체 퍼포먼스 총괄 |
| 퍼포먼스 마케터 | 소재 옵티마이저 | 소재 매트릭스/카피 세트, A/B 테스트 설계 |
| CRO 전문가 | 랜딩 닥터 | 랜딩 개선/실험 설계, 전환율 최적화 |

## 에이전트별 상세 역할

### 캠페인 아키텍트 (그로스 리드)
- **주요 업무**: 캠페인 3단 구조 설계, 퍼널별 캠페인 분리, 예산 배분 전략, KPI 기준 설정
- **의사결정 권한**: 캠페인 구조 확정, 예산 배분 비율 결정, 캠페인 중단/확대 판단 기준 설정
- **품질 책임**: 모든 캠페인에 KPI/경고/중단 기준 필수, 컴플라이언스 최종 점검
- **협업 방식**: 팀1/팀2 산출물 수신 → 캠페인 전략 수립 → 소재 옵티마이저/랜딩 닥터에 브리프 전달 → 최종 검수

### 소재 옵티마이저 (퍼포먼스 마케터)
- **주요 업무**: 소재 매트릭스 12칸+ 설계, 플랫폼별 카피 세트 작성, A/B 테스트 변수 설계, 소재 제작 브리프
- **의사결정 권한**: 소재 컨셉/카피 선택, A/B 테스트 변수 결정, 소재 교체 시점 판단
- **품질 책임**: 플랫폼별 글자 제한 준수, 리스크 표현 사전 제외, 변수 1개 규칙 준수
- **협업 방식**: 캠페인 아키텍트의 전략 기반 → 소재 매트릭스 + 카피 작성 → 리스크 점검 → 캠페인 아키텍트 검수

### 랜딩 닥터 (CRO 전문가)
- **주요 업무**: 현재 랜딩 진단, 개선 Top 10 도출, 7일 실험 계획 3개 설계, 측정 이벤트/UTM 설계
- **의사결정 권한**: 개선 우선순위 결정, 실험 설계(가설/변수/성공기준), 측정 환경 설계
- **품질 책임**: 실험당 변수 1개 + 기대효과 수치화, 최소 유의 표본수 사전 계산
- **협업 방식**: 팀2 랜딩 IA 수신 → 현행 랜딩 진단 → 개선안 + 실험 계획 작성 → 캠페인 아키텍트 검수

## 협업 구조

### 내부 협업 흐름
```
캠페인 아키텍트
    │
    ├──→ 캠페인 전략/구조 ──→ 소재 옵티마이저
    │                              │
    │                     소재 매트릭스 + 카피 세트
    │                              │
    │                              ▼
    ├──→ KPI/예산 기준 ──→ 랜딩 닥터
    │                         │
    │                 랜딩 개선 + 실험 계획
    │                         │
    │                         ▼
    └────── 캠페인 아키텍트 최종 검수 ◄──────┘
```

### 외부 협업 팀
- **팀 1 (인사이트/오퍼)**: 타깃 세분화, 오퍼 구조, 리스크 플래그 수신
- **팀 2 (전략/크리에이티브)**: 광고형 카피, 랜딩 IA, 제작 브리프 수신
- **팀 6 (데이터/최적화)**: 성과 데이터 피드백 수신, 실험 결과 공유

### 핸드오버 대상
- **오케스트레이터 (팀 00)**: 전체 산출물 요약 보고, 예산 계획, KPI 대시보드
- **팀 6 (데이터/최적화)**: 측정 이벤트 정의서, 실험 계획서, UTM 컨벤션, KPI 기준

## 에스컬레이션 규칙

1. **예산 초과/미달**: 예상 CPA가 목표 대비 2배 이상 이탈 시 → 캠페인 아키텍트가 오케스트레이터에 보고, 전략 재조정 제안
2. **광고 심의 반려**: 플랫폼 광고 심의에서 반려된 소재 → 소재 옵티마이저가 팀1 리스크 플래거와 협의, 대체 카피 작성
3. **랜딩 기술 이슈**: 측정 이벤트 미작동, 페이지 로딩 지연 등 기술 문제 → 오케스트레이터에 기술 지원 요청
4. **실험 표본 부족**: 7일 내 최소 유의 표본 확보 불가 시 → 실험 기간 연장 또는 실험 설계 변경, 캠페인 아키텍트 승인
