# 핸드오버 및 요청 티켓 프로토콜

> 하캄 에이전시 팀 간 산출물 인수인계 표준 포맷

---

## 1. 핸드오버 포맷

모든 팀 간 산출물 전달 시 아래 포맷을 **빠짐없이** 작성해야 한다.
하나라도 비어 있으면 **자동 반려** 처리된다.

```
[핸드오버]
산출물명/버전:
목적(해결하는 문제 1줄):
적용 범위(채널/기간/타깃):
핵심 요약 5줄:
포함된 파일/섹션 목록:
다음 액션(담당/기한/합격 기준):
리스크/주의(컴플라이언스 포함):
질문(필요 시, 5개 이내):
```

---

## 2. 필드별 작성 지침

### 산출물명/버전
- 네이밍 컨벤션(`naming_conventions.md`)에 따른 정식 파일명 기입
- 버전 번호 필수 (예: v1.0, v1.1, v2.0)
- 동일 산출물의 이전 버전이 있으면 변경 이력 1줄 추가

### 목적(해결하는 문제 1줄)
- **단 1문장**으로 이 산출물이 해결하는 비즈니스 문제를 기술
- "~을 위해 ~을 정의/분석/제작했다" 형태 권장
- 추상적 표현 금지 (예: "마케팅 개선" -> "30대 여성 타깃 전환율 3% 달성을 위한 랜딩페이지 카피 제작")

### 적용 범위(채널/기간/타깃)
- **채널**: 적용되는 채널 명시 (인스타그램, 구글 검색, 유튜브, 이메일 등)
- **기간**: 캠페인 시작~종료일 또는 콘텐츠 게시 기간
- **타깃**: 페르소나명 또는 세그먼트 (예: "페르소나 A - 30대 워킹맘")

### 핵심 요약 5줄
- 정확히 5줄로 작성 (3줄이나 7줄 불가)
- 줄 1: 배경/맥락
- 줄 2: 핵심 발견 또는 제작 방향
- 줄 3: 주요 산출물 내용
- 줄 4: 기대 성과 또는 KPI 연결
- 줄 5: 후속 팀이 반드시 알아야 할 사항

### 포함된 파일/섹션 목록
- 전달하는 파일 전체를 목록으로 나열
- 각 파일의 역할을 10자 이내로 설명
- 파일 형식(PDF, PPTX, CSV 등) 명시
- 예: `HKM-2024-T01-persona-v1.0-240115.pdf — 페르소나 정의서`

### 다음 액션(담당/기한/합격 기준)
- **담당**: 다음 작업을 수행할 팀 번호와 역할
- **기한**: 구체적 날짜 (예: 2024-01-20)
- **합격 기준**: 이 산출물을 기반으로 다음 산출물이 통과하려면 충족해야 할 조건 1~3개

### 리스크/주의(컴플라이언스 포함)
- 법적 검토가 필요한 표현이 있는지 명시
- 경쟁사 언급, 비교 광고, 의료/금융 관련 표현 주의 사항
- 데이터 출처의 신뢰도 등급 (1차 데이터/2차 데이터/추정치)
- 브랜드 가이드라인 위반 가능성 여부
- 비어 있을 수 없음 — 리스크가 없으면 "확인된 리스크 없음" 기입

### 질문(필요 시, 5개 이내)
- 후속 팀에게 확인이 필요한 사항
- 의사결정이 필요한 선택지 제시 (A안/B안 형태)
- 5개 초과 시 별도 미팅 요청으로 전환
- 질문이 없으면 "없음" 기입

## 3. 핸드오버 작성 예시

```
[핸드오버]

산출물명/버전:
HKM-2024-T01-persona-v1.0-240115 (페르소나 정의서)

목적(해결하는 문제 1줄):
건강기능식품 브랜드의 핵심 구매층 3개 세그먼트를 정의하여 채널별 메시지 전략의 기반을 마련했다.

적용 범위(채널/기간/타깃):
채널: 전 채널 공통 적용 | 기간: 2024-Q1 캠페인 | 타깃: 30대 워킹맘, 50대 건강관심층, 20대 다이어터

핵심 요약 5줄:
1. 자사 구매 데이터 12개월 + 설문조사 500명 기반으로 3개 핵심 세그먼트 도출
2. 각 세그먼트별 구매 동기, 정보 탐색 채널, 가격 민감도, 콘텐츠 선호 유형 정리
3. 페르소나 카드 3장 (인구통계, 심리, 행동, 미디어 습관, 구매 여정 포함)
4. 전환율 목표: 페르소나 A 3.2%, B 2.1%, C 4.5% (현재 대비 +1.0%p)
5. 페르소나 C(20대 다이어터)는 숏폼 콘텐츠 반응이 높아 팀4 우선 대응 권장

포함된 파일/섹션 목록:
- HKM-2024-T01-persona-v1.0-240115.pdf — 페르소나 정의서 본문 (18p)
- HKM-2024-T01-journey-v1.0-240115.pdf — 구매 여정 맵 3종 (6p)
- HKM-2024-T01-data-raw-240115.csv — 설문 원데이터 (500건)
- HKM-2024-T01-competitor-v1.0-240115.pdf — 경쟁사 포지셔닝 분석 (8p)

다음 액션(담당/기한/합격 기준):
담당: 팀2 (전략/크리에이티브) | 기한: 2024-01-20
합격 기준:
  1) 페르소나 3종 각각에 대한 메시지 프레임워크 완성
  2) 채널별 톤앤매너 가이드 포함
  3) 헤드라인 후보 페르소나당 최소 5개

리스크/주의(컴플라이언스 포함):
- 페르소나 B(50대 건강관심층) 대상 표현 시 "질병 치료/예방" 문구 사용 금지 (건강기능식품법 위반)
- 경쟁사 C사 제품과의 직접 비교 표현 주의 (비교광고 심의 기준 확인 필요)
- 설문 데이터 표본이 수도권 편중(72%)이므로 지방 타깃 확대 시 별도 검증 필요

질문(필요 시, 5개 이내):
1. 페르소나 C(20대 다이어터)의 메인 채널을 틱톡으로 할지 인스타 릴스로 할지 클라이언트 확인 필요
2. 예산 배분 시 페르소나 우선순위: A > C > B 순서가 맞는지 확인 요청
```

## 4. 핸드오버 규칙

| 규칙 | 내용 |
|------|------|
| **필수 완성** | 모든 필드가 채워져야 한다. 비어 있는 필드가 하나라도 있으면 자동 반려 |
| **버전 명시** | 산출물명에 버전 번호가 없으면 반려 |
| **5줄 엄수** | 핵심 요약은 정확히 5줄. 초과/미달 시 반려 |
| **기한 명시** | 다음 액션의 기한이 구체적 날짜가 아니면 반려 (예: "빠른 시일 내" 불가) |
| **리스크 필수** | 리스크/주의 필드가 비어 있으면 반려. 없으면 "확인된 리스크 없음" 기입 |
| **파일 목록 정합성** | 포함된 파일 목록에 있는 파일이 실제로 첨부되지 않으면 반려 |
| **단방향 전달** | 핸드오버는 앞 팀 -> 뒤 팀 순서. 역방향 전달 시 별도 요청 티켓 사용 |
| **수정 이력** | v1.1 이상 버전은 변경 사항 요약을 산출물명/버전 필드에 1줄 추가 |
| **24시간 응답** | 핸드오버를 받은 팀은 24시간 이내 수령 확인 또는 반려 사유 회신 |
| **질문 응답 의무** | 질문이 있으면 수신 팀은 12시간 이내 답변 |

## 5. 요청 티켓 포맷

팀 간 작업 요청, 역방향 요청, 추가 산출물 요청 시 사용한다.

```
[요청 티켓]
프로젝트명:
팀명:
요청 산출물(필수 목록):
마감:
품질 기준(불합격 조건 포함):
제약(표현/예산/채널/데이터):
참고(기존 소재/링크/가이드):
```

### 필드별 작성 지침

| 필드 | 지침 |
|------|------|
| **프로젝트명** | 프로젝트 코드 + 프로젝트 한글명 (예: HKM-2024 건강기능식품 론칭) |
| **팀명** | 요청하는 팀(발신)과 요청받는 팀(수신) 모두 기입 (예: T02 -> T04) |
| **요청 산출물** | 필요한 산출물을 목록으로 나열. 각 항목에 산출물 유형 코드 포함 |
| **마감** | 구체적 날짜와 시간 (예: 2024-01-22 18:00 KST) |
| **품질 기준** | 합격 조건 + 불합격 조건 명시. 불합격 조건은 "~이면 불합격" 형태 |
| **제약** | 사용 금지 표현, 예산 한도, 채널 제한, 데이터 접근 범위 등 |
| **참고** | 관련 기존 산출물 파일명, 외부 레퍼런스 링크, 브랜드 가이드 등 |

### 요청 티켓 작성 예시

```
[요청 티켓]

프로젝트명:
HKM-2024 건강기능식품 Q1 론칭 캠페인

팀명:
T02(전략/크리에이티브) -> T04(소셜/쇼트폼)

요청 산출물(필수 목록):
1. 인스타그램 릴스 대본 5편 (페르소나 C 타깃)
2. 틱톡 숏폼 대본 3편 (페르소나 C 타깃)
3. 각 대본별 촬영 지시서

마감:
2024-01-25 18:00 KST

품질 기준(불합격 조건 포함):
합격:
  - 각 대본 30초 이내 분량
  - 3초 이내 훅 포함
  - CTA 명확 (링크인바이오 유도)
불합격:
  - "최고", "1위" 등 최상급 표현 사용 시
  - 의학적 효능 암시 문구 포함 시
  - 훅 없이 바로 제품 소개로 시작하는 대본

제약(표현/예산/채널/데이터):
- "다이어트", "살빠지는" 표현 사용 금지 (식약처 가이드라인)
- 촬영 예산 편당 50만원 이내
- 인스타그램 릴스 + 틱톡 동시 게시 (비율 조정 가능)

참고(기존 소재/링크/가이드):
- HKM-2024-T01-persona-v1.0-240115.pdf (페르소나 C 참조)
- HKM-2024-T02-message-v1.0-240120.pdf (메시지 프레임워크)
- 브랜드 가이드: [내부 링크]
- 레퍼런스 계정: @competitor_a, @competitor_b
```

### 요청 티켓 규칙

- 모든 필드 필수. 비어 있으면 접수 거부
- 마감은 최소 3영업일 이후로 설정 (긴급 시 PM 승인 필요)
- 하나의 티켓에 하나의 산출물 유형만 요청 (복합 요청 시 티켓 분리)
- 요청받은 팀은 24시간 이내 수락/거절/협의 회신 의무
