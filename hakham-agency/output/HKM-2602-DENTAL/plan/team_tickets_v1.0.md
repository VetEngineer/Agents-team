### 제약 사항

- [ ] 헤드라인 뱅크 20개

- 모든 카피가 T01 리스크 플래그를 통과

### 불합격 조건
- 핵심 메시지가 임플란트 USP와 무관
- 카피에 금지 표현 포함 ("최고", "무통", "보장" 등)
- 블로그 타이틀에 타깃 키워드 미포함

### 제약 사항

- "효과 보장", "통증 없음" 등 단정적 표현 금지

### 참고 자료

## 티켓 #3: 콘텐츠 엔진/SEO 팀

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 스마일플러스치과 신규환자 유입 캠페인 |
| 팀명 | T01+T02 → 03_콘텐츠엔진SEO |
| 티켓 번호 | HKM-2602-DENTAL-03-001 |
| 우선순위 | **상** (네이버 블로그 = 유기 유입 메인 채널) |
| 마감 | Day 4 오후 |

### 요청 산출물 (필수)
- [ ] 키워드 클러스터 3개 (임플란트 중심)
  - 클러스터 1: 임플란트 정보형 (비용, 과정, 기간, 수명 등)
  - 클러스터 2: 임플란트 비교형 (브랜드 비교, 틀니 vs 임플란트 등)
  - 클러스터 3: 지역 + 임플란트 (지역명 치과, 지역명 임플란트)
  - 각 키워드에 월간 검색량 추정·경쟁도·검색 의도 분류
- [ ] 4주 콘텐츠 캘린더
  - 주 2-3회 발행 (총 8-12편)
  - 비율: 정보형 60% / 비교형 25% / 전환형 15%
  - 각 편에 타깃 키워드·형식·CTA 명시
- [ ] 아티클 템플릿 2종 (정보형 + 비교형)
  - 네이버 블로그 최적화 구조 (H2-H3, 이미지 위치, CTA 위치)
- [ ] 대표 블로그 원고 2편 (1편 정보형 + 1편 비교형)
  - 1,500-2,500자
  - SEO 최적화 (키워드 밀도, 메타 디스크립션)
  - 하단 CTA: 전화번호 + 네이버 예약 링크
- [ ] 내부 링크 맵 (블로그 간 상호 링크 설계)

### 품질 기준
- 키워드에 "지역명 + 임플란트" 조합이 필수 포함
- 블로그 원고가 T02 메시지 시스템과 톤 일관
- 모든 원고 하단에 CTA(전화/예약) 포함

### 불합격 조건
- 키워드 리서치 없이 작성한 콘텐츠
- T02 핵심 메시지와 불일치하는 톤/내용
- 컴플라이언스 위반 표현 포함
- CTA 누락

### 제약 사항
- T01 여정맵 + T02 메시지 시스템 완성 후 착수
- 네이버 블로그 전용 (구글 SEO는 이번 스코프 외)
- 의료 정보 표현 시 "개인차 있음" 고지 필수

### 참고 자료
- T01 산출물 (여정맵, 검색 키워드)
- T02 산출물 (메시지 시스템, 톤앤매너)
- 콘텐츠 템플릿: `agents/03_content_engine_seo/output_templates/`
