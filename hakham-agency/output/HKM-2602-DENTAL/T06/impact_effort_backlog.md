## 점수 기준

### Impact (영향도) 1-5

| 점수 | 기준 |
|------|------|
| 5 | 주 KPI(월 예약 30건)에 직접적이고 큰 영향. 전환수 20% 이상 개선 예상 |
| 4 | 주 KPI에 직접적 영향. 10-20% 개선 예상 |
| 3 | 주 KPI에 간접적 영향. 보조 KPI 개선을 통한 5-10% 개선 예상 |
| 2 | 보조 KPI에 소폭 영향. 5% 미만 개선 예상 |
| 1 | 효과가 불확실하거나 미미함. 장기적 개선에 기여 |

### Confidence (확신도) 1-5

| 점수 | 기준 |
|------|------|
| 5 | 데이터/사례가 명확하여 성공 확률 90% 이상 |
| 4 | 유사 사례가 있고 논리적으로 타당. 성공 확률 70% 이상 |
| 3 | 합리적 추정이나 데이터 부족. 성공 확률 50% |
| 2 | 가설 단계. 검증이 필요. 성공 확률 30% |
| 1 | 직감 수준. 불확실성이 높음 |

### Ease (용이성) 1-5

| 점수 | 기준 |
|------|------|
| 5 | 1일 이내. 설정 변경, 카피 수정 등 즉시 실행 가능 |
| 4 | 2-3일. 간단한 콘텐츠 제작, A/B 테스트 설정 |
| 3 | 1주. 콘텐츠 제작, 프로세스 변경 필요 |
| 2 | 2주. 다수 관계자 협업, 교육 필요 |
| 1 | 3주 이상. 시스템 변경, 외부 도구 도입, 대규모 구조 변경 |

### ICE Score = Impact x Confidence x Ease (높을수록 먼저)

## 백로그 운영 규칙

1. **매주 월요일**: 새로운 인사이트에서 도출된 개선안을 백로그에 추가한다
2. **ICE 재평가**: 새 데이터가 나오면 점수를 업데이트하고 우선순위를 재정렬한다
3. **완료 항목**: 결과를 기록하고 학습 아카이브로 이동한다
4. **상위 3개**: 항상 다음 주 실행 대상으로 관리한다
5. **실험 연결**: 백로그 항목 중 가설 검증이 필요한 것은 T05의 7일 실험 계획으로 연결한다
