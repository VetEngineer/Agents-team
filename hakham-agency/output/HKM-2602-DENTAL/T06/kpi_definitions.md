## 주 KPI

| 항목 | 내용 |
|------|------|
| **지표명** | 월간 상담 예약 건수 |
| **정의** | 네이버 검색광고, 블로그, 플레이스를 통해 유입된 잠재 고객 중 전화 또는 네이버 예약을 완료한 건수의 합계 |
| **계산식** | 전화 상담 예약 건수 + 네이버 예약 건수 (수기 집계 + 네이버 전환추적) |
| **현재값** | 월 약 10건 (추정, 체계적 측정 미설정 상태) |
| **목표값 (단기 4주)** | 월 20건 (현재 대비 2배, 측정 체계 구축 + 검색광고 최적화) |
| **목표값 (중기 12주)** | 월 30건 (최종 목표) |
| **관측 주기** | 주간 집계, 월간 리뷰 |
| **데이터 소스** | 수기 집계 양식 (전화/예약) + 네이버 검색광고 전환추적 + 네이버 플레이스 예약 데이터 |
| **담당 팀** | T06 집계, T05 실행, 원장/데스크 직원 수기 기록 |
| **벤치마크** | 로컬 치과 임플란트: 월 20~50건 (지역/규모에 따라 편차. 근거: 치과 마케팅 업종 평균) |
| **주의사항** | (1) 초기 4주는 측정 환경 구축 기간으로 수치 변동이 클 수 있다. (2) 전화 예약은 수기 기록 의존도가 높아 누락 가능성이 있다. (3) 명절/연휴 시즌에는 예약 건수가 일시적으로 하락한다. |

## 보조 KPI 1

| 항목 | 내용 |
|------|------|
| **지표명** | CPL (Cost Per Lead, 전환당 비용) |
| **정의** | 상담 예약 1건을 획득하는 데 소요된 광고비 |
| **계산식** | 월간 검색광고 집행 비용 / 월간 상담 예약 건수 (광고 경유) |
| **주 KPI와의 관계** | CPL이 낮아지면 동일 예산(200만원)으로 더 많은 예약을 확보할 수 있다. CPL 10만원이면 200만원으로 20건, 목표(30건) 달성을 위해서는 CPL 6.7만원 또는 예산 증액이 필요하다 |
| **현재값** | 측정 미설정 (전환추적 없음. 추정: 월 200만원 / 10건 = 약 20만원) |
| **목표값 (단기 4주)** | 15만원 이하 |
| **목표값 (중기 12주)** | 10만원 이하 |
| **관측 주기** | 주간 |
| **데이터 소스** | 네이버 검색광고 관리자 (비용) + 수기 집계 양식 (예약 건수) |
| **담당 팀** | T06 집계, T05 광고 최적화 실행 |
| **벤치마크** | 치과 임플란트 CPL: 3만~10만원 (키워드 경쟁도/지역에 따라 편차. KPI 사전 참조: 의료 상담 예약 15,000~50,000원) |

## 보조 KPI 2

| 항목 | 내용 |
|------|------|
| **지표명** | 블로그 유기 유입 세션 |
| **정의** | 네이버 블로그에 발행한 콘텐츠를 통해 검색으로 자연 유입된 방문자 수 |
| **계산식** | 네이버 서치어드바이저 유입 클릭 수 + 네이버 블로그 통계 > 검색 유입 수 |
| **주 KPI와의 관계** | 블로그 유기 유입이 증가하면 광고 의존도를 낮추면서 예약 건수를 늘릴 수 있다. 유기 유입 방문자의 일부가 블로그 내 CTA(전화번호, 예약 링크)를 통해 예약으로 전환된다 |
| **현재값** | 측정 미설정 (블로그 미운영 또는 초기 단계로 추정치 없음) |
| **목표값 (단기 4주)** | 월 300세션 (블로그 개설 및 초기 콘텐츠 4편 발행 기준) |
| **목표값 (중기 12주)** | 월 1,000세션 |
| **관측 주기** | 주간 (추이 관찰), 월간 (리포트) |
| **데이터 소스** | 네이버 서치어드바이저 + 네이버 블로그 통계 |
| **담당 팀** | T06 집계, T03 콘텐츠 발행 |
| **벤치마크** | 로컬 의료 블로그: 월 1,000~5,000세션 (소규모. KPI 사전 참조). 신규 블로그는 8~12주 후 유의미한 유기 트래픽 발생 |

## KPI 간 관계도

```
[보조 KPI 1: CPL 낮추기]
  → 동일 예산으로 광고 예약 건수 증가
       │
       ▼
[주 KPI: 월 상담 예약 30건]
       ▲
       │
[보조 KPI 2: 블로그 유기 유입 1,000세션]
  → 무료 유입 기반 예약 건수 추가 확보
       │
       ▼
[비즈니스 목표: 임플란트 시술 매출 증대]
```

**해석**: 광고 효율(CPL)을 개선하여 유료 채널의 예약 건수를 늘리고, 동시에 블로그 유기 유입을 키워 무료 채널에서도 예약이 발생하도록 한다. 두 보조 KPI가 모두 개선되면 주 KPI(월 30건) 달성이 가능하다.

## KPI 리뷰 규칙

1. **주간**: 주 KPI + 보조 KPI 현황을 주간 리포트에 포함한다
2. **월간**: KPI 달성률을 리뷰하고, 목표값 조정이 필요한지 판단한다
3. **조정 기준**:
   - 4주 연속 목표 초과 달성: 목표값을 상향 조정한다
   - 4주 연속 목표 미달: 원인을 분석하고, 목표값 또는 전략을 조정한다
   - 외부 변수(계절, 시장 변화)가 발생하면 별도 주석을 남긴다
4. **특수 규칙 (초기 4주)**:
   - 측정 환경 구축 기간이므로 KPI 수치보다 "데이터 수집 정상 작동 여부"를 우선 확인한다
   - 수기 집계 양식의 기록 누락률을 별도로 모니터링한다 (목표: 누락률 10% 이하)
