## 포맷 1: 문제제기형

**콘셉트**: "임플란트, 이것만은 꼭 확인하세요"
**목적**: 잠재 환자의 불안/궁금증을 건드려 "나도 해당되나?" 반응 유도
**핵심 감정**: 공감, 경각심, 궁금증
**타깃 반응**: 댓글("저도요"), 프로필 방문, 상담 문의

### 영상 구조

| 단계 | 시간 | 내용 | 화면 구성 |
|------|------|------|----------|
| 훅 (0~3초) | 3초 | 문제를 직설적으로 던진다 | 원장 얼굴 클로즈업 + 텍스트 오버레이 |
| 문제 설명 (3~25초) | 22초 | 왜 이것이 문제인지 구체적으로 설명 | 원장 말하기 + 관련 이미지/일러스트 전환 |
| 해결 힌트 (25~45초) | 20초 | 올바른 확인 방법/기준 제시 | 체크리스트 그래픽 + 원장 설명 |
| CTA (45~60초) | 15초 | 상담 예약 유도 (1가지만) | 연락처/예약 링크 텍스트 + 원장 마무리 멘트 |

### 오프닝 훅 예시 3개

1. "임플란트 전 이 검사, 꼭 확인하세요."
2. "잇몸이 자꾸 부어오르시나요? 그냥 넘기시면 안 됩니다."
3. "임플란트, 가격만 보고 결정하시면 후회할 수 있습니다."

### 적합 주제 (치과 특화)

- "임플란트 전에 CT 안 찍는다면, 다시 생각해 보세요"
- "치아가 흔들리는데 방치하면 생기는 일"
- "임플란트 수명, 이것에 따라 달라집니다"
- "발치 후 빈 자리, 왜 빨리 채워야 하는지"

### 컴플라이언스 체크포인트

- [ ] "꼭 해야 한다", "반드시" 등 공포 조성 표현을 사용하지 않았는가 (경각심은 주되 공포 조성은 금지)
- [ ] 타 치과를 직간접적으로 비하하지 않았는가
- [ ] 효과를 단정하는 표현이 없는가
- [ ] 수술 장면을 직접 노출하지 않았는가

## 포맷 2: 오해교정형

**콘셉트**: "임플란트에 대한 흔한 오해 3가지"
**목적**: 잘못 알려진 정보를 바로잡아 전문성과 신뢰 구축
**핵심 감정**: 놀람, "이 사람 진짜 아는구나" 신뢰감
**타깃 반응**: 저장, 공유, 팔로우

### 영상 구조

| 단계 | 시간 | 내용 | 화면 구성 |
|------|------|------|----------|
| 훅 (0~3초) | 3초 | 흔한 오해를 제시 | "X" 표시 그래픽 + 원장 표정 연기 |
| 진실/팩트 (3~25초) | 22초 | 실제 사실을 근거와 함께 설명 | 원장 설명 + 일러스트/데이터 시각화 |
| 올바른 방법 (25~45초) | 20초 | 그렇다면 어떻게 판단해야 하는지 | 단계별 설명 텍스트 + 원장 |
| CTA (45~60초) | 15초 | 상담 예약 유도 (1가지만) | 연락처 텍스트 + 마무리 멘트 |

### 오프닝 훅 예시 3개

1. "임플란트는 아프다? 많은 분이 오해하고 계십니다."
2. "나이 들면 임플란트 못 한다고요? 사실은 다릅니다."
3. "임플란트는 비싸기만 하다? 알고 보면 다른 관점이 있습니다."

### 적합 주제 (치과 특화)

- "임플란트 수명이 10년뿐이다? 관리에 따라 다릅니다"
- "뼈가 약하면 임플란트를 못 한다? 사실은..."
- "임플란트는 자연치아보다 약하다? 올바른 비교 방법"
- "임플란트 후 MRI 못 찍는다? 확인해야 할 사항"

### 컴플라이언스 체크포인트

- [ ] 오해 교정 시 "절대 안전하다", "부작용 없다" 등 반대 방향의 단정도 하지 않았는가
- [ ] 팩트 근거가 검증 가능한 수준인가 (완충 표현 적용)
- [ ] "통증을 줄이기 위해 OO 방식을 적용합니다" 등 프로세스 중심 표현을 사용했는가
- [ ] 수술 장면을 직접 노출하지 않았는가

## 포맷 3: 체크리스트형

**콘셉트**: "좋은 임플란트 치과 고르는 5가지 기준"
**목적**: 실용적 정보 전달로 저장/공유 극대화, "나중에 봐야지" 반응
**핵심 감정**: 유용함, 정리됨, 안심
**타깃 반응**: 저장, 공유, 스크린샷

### 영상 구조

| 단계 | 시간 | 내용 | 화면 구성 |
|------|------|------|----------|
| 훅 (0~3초) | 3초 | 확인할 항목 수 제시 | 숫자 텍스트 크게 + 원장 |
| 항목 나열 (3~40초) | 37초 | 항목을 하나씩 설명 (번호 매기기) | 항목별 텍스트 카드 + 원장 설명 |
| 요약 (40~50초) | 10초 | 핵심을 한 문장으로 정리 | 전체 리스트 한 화면 표시 |
| CTA (50~60초) | 10초 | 상담 예약 유도 (1가지만) | 연락처 텍스트 + "저장해두세요" |

### 오프닝 훅 예시 3개

1. "임플란트 치과 고르기 전에 이 5가지 확인하세요."
2. "이 영상 저장해두세요. 임플란트 체크리스트입니다."
3. "3가지만 확인하면 후회 없는 선택을 하실 수 있습니다."

### 적합 주제 (치과 특화)

- "임플란트 치과 고를 때 확인할 5가지 (전문의/장비/사후관리/상담/비용 투명성)"
- "임플란트 후 관리법 체크리스트 (양치/검진/음식/습관)"
- "임플란트 상담 시 꼭 물어봐야 할 질문 5가지"
- "어르신 임플란트, 가족이 함께 확인할 3가지"

### 컴플라이언스 체크포인트

- [ ] 체크리스트 항목이 자사에만 유리하게 편향되지 않았는가
- [ ] "이것만 확인하면 된다"는 식의 단정 표현을 피했는가
- [ ] 타 치과를 간접적으로라도 비하하는 기준이 없는가
- [ ] 가격 관련 항목에서 "저렴", "부담 없는" 등 주관적 표현을 사용하지 않았는가

## 포맷 공통 규칙

### 영상 제작 원칙 (향후 참고)

1. **CTA는 영상 1개당 1개만**: "예약 전화", "프로필 방문", "저장" 중 하나만 선택
2. **첫 3초가 전부**: 오프닝 훅이 약하면 나머지는 의미 없음
3. **대본은 촬영자가 그대로 읽고 찍을 수 있는 수준**: 추상적 방향 아닌 구체적 멘트
4. **수술 장면 직접 노출 금지**: 일러스트, 모형, 그래픽으로 대체
5. **금지 표현 32개 항목 체크**: 효과 단정, 비교 비하, 과장 표현 절대 불가

### 의료광고법 필수 적용 사항

| 구분 | 적용 내용 |
|------|----------|
| 효과 표현 | "개인에 따라 결과가 다를 수 있습니다" 고지 필수 |
| 전문의 표기 | 전문의 자격 보유 시에만 "OO 전문의" 표기 가능 |
| 전후 사진 | 환자 동의 + 동일 촬영 조건 + 개인차 고지 필수 |
| 후기 활용 | 작성자 동의 + 대가성 명시 + "개인의 경험" 고지 |
| 가격 표시 | 조건 명시, 허위 할인 금지, "무료" 표현 금지 |

### 포맷 도입 로드맵 (제안)

| 단계 | 시기 | 내용 |
|------|------|------|
| 준비기 | 진출 결정 후 2주 | 원장 촬영 테스트, 조명/배경 세팅, 대본 3개 확정 |
| 시범기 | 3~4주차 | 주 2회 업로드 (인스타 릴스 중심), 반응 모니터링 |
| 확장기 | 5~8주차 | 주 3회 업로드, 유튜브 쇼츠 동시 운영, 포맷 비율 조정 |
| 안정기 | 9주차~ | 주 3~4회, 성과 기반 포맷 믹스 최적화 |

### 포맷 믹스 권장 비율 (치과 채널 초기)

- 문제제기형 40% -- 관심 확보, 댓글 유발
- 오해교정형 40% -- 전문성/신뢰 구축
- 체크리스트형 20% -- 저장/공유 유도

> 채널 성장에 따라 체크리스트형 비율을 점진적으로 높인다.
