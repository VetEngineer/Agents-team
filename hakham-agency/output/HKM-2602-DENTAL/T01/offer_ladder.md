## 입문 오퍼: 정밀 CT 촬영 + 1:1 맞춤 상담

### 오퍼 설계

| 항목 | 내용 |
|------|------|
| 오퍼명 | 정밀 CT 촬영 + 1:1 맞춤 상담 |
| 한줄 설명 | 현재 구강 상태를 CT로 정밀하게 확인하고 개인별 치료 방향을 안내드립니다 |
| 목적 | 첫 접점 확보, 내원 유도, 신뢰 형성, 핵심 오퍼로의 자연스러운 전환 |
| 대상 페르소나 | 페르소나 A (본인 검색형) + 페르소나 B (가족 대행 검색형) 공통 |

### 구성

| 포함 항목 | 설명 |
|-----------|------|
| 1. 3D CT 촬영 | 파노라마 + CBCT 촬영으로 잔존 뼈 상태, 신경 위치, 인접 치아 상태를 정밀 확인 |
| 2. 구강 종합 검진 | 치주 상태, 남아있는 치아 건강도, 교합 상태 점검 |
| 3. 1:1 원장 상담 (30분) | CT 결과를 함께 보며 개인별 시술 방향, 예상 기간, 비용 범위를 안내 |

### CTA 문장

1. "현재 구강 상태가 궁금하시면, CT 촬영과 1:1 상담으로 먼저 확인해 보세요"
2. "상담 후 결정하셔도 됩니다. 부담 없이 내원해 주세요"

### 가격 전략

| 항목 | 내용 |
|------|------|
| 가격 범위 | 상담 시 CT 촬영 비용 안내 (비급여 항목, 상담 시 개별 안내) |
| 가격 근거 | 첫 내원 진입 장벽을 낮추기 위한 전략. CT 촬영은 시술 결정과 무관하게 구강 건강 확인에 도움 |
| 경쟁사 대비 | 동일 (대부분의 치과가 초진 CT를 제공하나, 원장 직접 상담 30분을 명시하는 곳은 차별화 가능) |

### 차별 포인트

1. 원장이 직접 CT 결과를 설명하며 1:1로 30분간 상담 (일반 치과는 상담 실장이 대체하는 경우가 많음)
2. 상담 후 치료 계획서를 서면으로 제공하여 집에서 가족과 함께 검토 가능

### 핵심 오퍼로의 전환 설계

- 상담 시 CT 결과를 기반으로 개인별 임플란트 치료 계획을 수립하고, 비용 명세를 항목별로 안내한다
- "오늘 확인하신 결과를 바탕으로 치료 계획서를 전달드리겠습니다. 편하실 때 결정해 주세요"로 마무리하여 압박감 없이 핵심 오퍼 전환을 유도한다
- 가족 대행 검색자(페르소나 B)의 경우, 치료 계획서를 자녀에게 카카오톡으로 전송하여 함께 검토할 수 있게 한다

## 핵심 오퍼: 정밀 진단 기반 맞춤 임플란트

### 오퍼 설계

| 항목 | 내용 |
|------|------|
| 오퍼명 | 정밀 진단 기반 맞춤 임플란트 |
| 한줄 설명 | CT 기반 3D 가이드 수술로 개인별 최적 위치에 임플란트를 식립합니다 |
| 목적 | 주 매출원 (전체 매출의 70% 이상 목표), 환자 만족 극대화, 후기/추천 유도 |
| 대상 페르소나 | 페르소나 A (본인 검색형) — 1~3개 임플란트가 필요한 경우 |

### 구성

| 포함 항목 | 설명 |
|-----------|------|
| 1. 정밀 CT + 3D 시뮬레이션 | 식립 위치를 사전에 3D로 시뮬레이션하여 환자와 함께 확인 |
| 2. 개인별 치료 계획 수립 | 뼈 상태, 교합, 잔존 치아를 종합 고려한 맞춤 설계 |
| 3. 디지털 가이드 임플란트 식립 | 가이드를 활용한 정확한 식립으로 수술 시간 단축 및 정확도 향상 |
| 4. 프리미엄 픽스처 + 지르코니아 크라운 | 검증된 픽스처 브랜드 사용, 심미성과 내구성을 갖춘 크라운 |
| 5. 수술 후 3회 정기 점검 | 수술 후 1주, 1개월, 3개월 시점에 정기 점검 포함 |

### CTA 문장

1. "CT 결과를 바탕으로 본인에게 맞는 임플란트 계획을 상담에서 안내드립니다"
2. "구강외과 전문의가 진단부터 수술까지 직접 담당합니다"
3. "수술 전 3D 시뮬레이션으로 예상 결과를 함께 확인하세요"

### 가격 전략

| 항목 | 내용 |
|------|------|
| 가격 범위 | 임플란트 1개 기준, 상담 시 개인별 비용 안내 |
| 가격 근거 | 프리미엄 픽스처, 디지털 가이드 수술, 전문의 직접 시술, 3회 정기 점검 포함 |
| 경쟁사 대비 | 동일~약간 높음 (디지털 가이드 수술과 전문의 직접 시술을 감안한 합리적 가격) |
| 가격 정당화 근거 | 구강외과 전문의 직접 수술, 3D 가이드 정밀 시스템, 검증된 픽스처 사용, 정기 점검 포함 |

### 차별 포인트

1. 구강외과 전문의가 상담부터 수술, 사후 점검까지 일관되게 담당한다
2. 3D 디지털 가이드 시스템으로 수술 전 식립 위치를 미리 확인하고 계획한다
3. 수술 후 3회 정기 점검이 포함되어 있어 사후 관리에 대한 불안을 줄인다

### 왜 이 오퍼를 선택해야 하는가 (vs 입문 오퍼)

> 입문 오퍼는 현재 상태를 확인하는 단계이고, 핵심 오퍼는 확인된 문제를 해결하는 단계이다. CT 결과에서 임플란트가 필요하다고 판단된 경우, 정밀 진단에 기반한 맞춤 시술 계획으로 개인별 상황에 맞는 치료를 받을 수 있다.

### 왜 이 오퍼면 충분한가 (vs 프리미엄 오퍼)

> 1~3개의 개별 임플란트가 필요한 경우라면 핵심 오퍼로 충분하다. 프리미엄 오퍼는 다수의 치아를 동시에 해결하거나 전악 재건이 필요한 경우에 적합하다. 핵심 오퍼에도 3회 정기 점검이 포함되어 있어 일반적인 사후 관리는 충분히 커버된다.

## 프리미엄 오퍼: 전악 임플란트 + 12개월 토탈케어

### 오퍼 설계

| 항목 | 내용 |
|------|------|
| 오퍼명 | 전악 임플란트 + 12개월 토탈케어 |
| 한줄 설명 | 다수의 치아를 한 번에 해결하고, 12개월간 정기 점검과 관리를 받을 수 있습니다 |
| 목적 | 고객 생애가치 극대화, VIP 경험 제공, 가족/지인 추천 유도 |
| 대상 페르소나 | 페르소나 B (가족 대행 검색형) — 부모님 전악 또는 다수 치아 임플란트 필요 시 |

### 구성

| 포함 항목 | 설명 |
|-----------|------|
| 1. 종합 구강 정밀 진단 | CT, 교합 분석, 전신 건강 상태 사전 확인 (고혈압/당뇨 등 고령 환자 안전 프로토콜) |
| 2. 전악 3D 시뮬레이션 설계 | 전체 구강의 식립 위치, 교합, 심미성을 종합 설계 |
| 3. 단계별 시술 (1차/2차 분할 가능) | 고령 환자의 체력을 고려하여 분할 시술 계획 가능 |
| 4. 프리미엄 픽스처 + 지르코니아 크라운 | 다수 식립에 적합한 검증된 시스템 사용 |
| 5. 임시 보철 제공 | 시술 기간 중 식사와 일상생활이 가능하도록 임시 보철 제공 |
| 6. 12개월 토탈케어 프로그램 | 월 1회 정기 점검 + 스케일링 + 교합 체크 + 구강 위생 관리 |

### CTA 문장

1. "다수의 치아를 한 번에 해결하고 싶으시면, 전악 정밀 진단부터 시작해 보세요"
2. "시술 후 12개월간 매월 정기 점검을 포함한 토탈케어 프로그램을 운영합니다"

### 가격 전략

| 항목 | 내용 |
|------|------|
| 가격 범위 | 시술 범위에 따라 상이, 상담 시 개인별 상세 견적 제공 |
| 가격 근거 | 전악 설계, 임시 보철, 12개월 정기 관리가 모두 포함된 토탈 패키지 |
| 경쟁사 대비 | 동일~약간 높음 (12개월 토탈케어 포함이 차별 요소) |
| 프리미엄 정당화 근거 | 전악 단위 종합 설계, 고령 환자 안전 프로토콜, 12개월 관리 포함, 임시 보철 제공 |

### 차별 포인트 (핵심 오퍼 대비)

1. 전악 단위 종합 설계: 개별 치아가 아닌 전체 구강의 교합과 심미성을 통합 설계한다
2. 12개월 토탈케어: 핵심 오퍼의 3회 점검 대비, 월 1회 정기 점검 + 스케일링을 12개월간 제공한다
3. 고령 환자 안전 프로토콜: 전신 건강 사전 확인, 분할 시술 계획, 임시 보철 제공으로 시술 기간 중 삶의 질을 유지한다

### 프리미엄 경험 요소

- 전담 코디네이터 배정: 시술 일정 관리, 리마인더, 문의 응대를 전담 코디네이터가 관리한다
- 가족 동반 상담: 자녀와 함께 내원하여 치료 계획을 설명 듣는 "가족 상담 시간"을 제공한다

## KPI 연결
- 입문 오퍼(CT+상담): 상담 예약 유입 → 월 30건 목표의 퍼널 입구
- 핵심 오퍼(맞춤 임플란트): 상담→시술 전환율 → 매출 기여
- CPL 10만원 이하: 입문 오퍼 획득 비용 기준
