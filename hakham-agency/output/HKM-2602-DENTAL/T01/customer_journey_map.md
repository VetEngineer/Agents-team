## 여정 전체 흐름

```
증상 인지 → 네이버 검색 → 블로그 탐색 → 플레이스 확인 → 전화/예약 → 상담 → 시술 → 사후관리
```

> 본 여정 맵은 네이버 검색 70%+, 지인 소개 20%, 플레이스 10%의 유입 경로를 반영한다.

## 1단계: 증상 인지 (Symptom Awareness)

> 치아 상실, 틀니 불편, 씹는 힘 저하 등 문제를 자각하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "어금니가 빠졌는데 그냥 둬도 되나?" / "틀니가 자꾸 빠지는데 다른 방법은 없나?" / "이 나이에 임플란트 해도 괜찮은 건가?" |
| **고객 심리** | 불편함은 느끼지만 수술에 대한 막연한 두려움이 있어 미루고 있는 상태. 주변 권유(배우자, 자녀)가 행동의 계기가 된다 |
| **반론/저항** | "아직 참을 만하다" / "나이가 많아서 수술이 위험하지 않을까" / "비용이 너무 클 것 같다" |
| **필요한 증거** | 치아 상실 방치 시 인접 치아에 미치는 영향에 대한 전문 정보, 연령대별 시술 가능성에 대한 객관적 설명 |
| **적합 채널** | 네이버 블로그 (정보성 콘텐츠), 네이버 검색 노출 |
| **콘텐츠 유형** | 정보성 블로그 ("어금니 빠진 후 방치하면 생기는 변화 3가지"), 자가 체크리스트 ("임플란트가 필요한 신호 5가지") |
| **CTA** | "현재 구강 상태가 궁금하시면 정밀 CT 촬영으로 확인해 보세요" |

## 2단계: 네이버 검색 (Active Search)

> "임플란트 비용", "임플란트 잘하는 치과" 등 적극적으로 정보를 탐색하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "임플란트 비용이 얼마 정도인가?" / "임플란트 수술은 어떻게 진행되나?" / "어떤 치과를 선택해야 하나?" |
| **고객 심리** | 본격적으로 정보를 모으기 시작. 비용, 과정, 기간에 대한 궁금증이 크다. 네이버 검색 결과 상단 콘텐츠에 집중한다 |
| **반론/저항** | "정보가 너무 많아서 뭘 믿어야 할지 모르겠다" / "광고 글과 진짜 후기 구분이 안 된다" / "치과마다 가격이 달라서 혼란스럽다" |
| **필요한 증거** | 시술 과정 단계별 설명, 비용 구성 요소 안내 (CT, 픽스처, 크라운, 뼈이식 등), 전문의 경력 정보 |
| **적합 채널** | 네이버 검색 (검색광고 + 블로그), 네이버 지식인 |
| **콘텐츠 유형** | 가이드형 블로그 ("임플란트 비용, 무엇이 포함되어 있나요?"), 과정 설명 콘텐츠 ("임플란트 수술 5단계 안내"), 검색광고 |
| **CTA** | "개인별 구강 상태에 따라 비용이 달라집니다. 정밀 상담으로 본인에게 맞는 계획을 확인하세요" |

---

## 3단계: 블로그 탐색 (Blog Exploration / Comparison)

> 여러 치과의 블로그를 돌아다니며 후기, 사례, 전문성을 비교하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "이 치과 원장의 경력은 어떤가?" / "실제로 시술 받은 사람의 후기는?" / "전후 사진을 보면 결과가 어떤가?" |
| **고객 심리** | 2~3곳의 치과를 비교 분석 중. 의사 경력, 후기의 진정성, 시설 수준을 기준으로 판단한다. 가족 대행 검색자(페르소나 B)는 특히 꼼꼼하게 비교한다 |
| **반론/저항** | "후기가 광고 같다" / "이 치과가 진짜 잘하는 건지 확신이 안 선다" / "다른 데가 더 저렴하다" |
| **필요한 증거** | 원장 전문의 자격 및 수련 이력, 실제 환자 동의 후기 (개인차 고지 포함), 전후 사진 (촬영 조건 동일, 시점 명시), 누적 케이스 수 |
| **적합 채널** | 네이버 블로그, 네이버 플레이스 리뷰 |
| **콘텐츠 유형** | 원장 소개 콘텐츠 ("구강외과 전문의, 대학병원 수련 후 임플란트 3,000케이스"), 환자 후기 (동의 확보, 개인차 고지 포함), 전후 사례 (촬영 조건 명시) |
| **CTA** | "궁금하신 점은 상담에서 CT 결과와 함께 자세히 안내드리겠습니다" |

---

## 4단계: 플레이스 확인 (Place Verification)

> 네이버 플레이스에서 리뷰, 위치, 영업시간, 시설 사진을 최종 확인하는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "리뷰 평점이 어떤가?" / "위치가 가까운가? 주차는 되나?" / "토요일에도 진료하나?" |
| **고객 심리** | 블로그에서 관심이 생긴 치과를 플레이스에서 재확인. 리뷰의 양과 질, 별점, 시설 사진이 최종 판단에 영향을 준다 |
| **반론/저항** | "리뷰가 적다" / "부정적 리뷰가 있다" / "위치가 멀다" |
| **필요한 증거** | 플레이스 리뷰 수 및 평점, 시설 내부 사진, 영업시간/주차 정보, 원장 프로필 |
| **적합 채널** | 네이버 플레이스 |
| **콘텐츠 유형** | 플레이스 기본 정보 최적화 (사진, 영업시간, 진료 과목), 리뷰 관리 (답변 성실도), 예약 기능 연동 |
| **CTA** | "네이버 예약으로 원하시는 시간에 편하게 상담을 예약하세요" |

---

## 5단계: 전화/예약 (Inquiry & Booking)

> 직접 전화하거나 온라인으로 예약을 잡는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "내 경우에는 비용이 얼마쯤 나오나?" / "상담만 받아보는 것도 가능한가?" / "CT 촬영 비용은 따로 있나?" |
| **고객 심리** | 거의 결정했지만 마지막 확인이 필요. 전화 응대의 친절함과 전문성이 최종 판단에 큰 영향을 준다. 상담 예약에 대한 심리적 부담("강매당할 것 같다")이 있을 수 있다 |
| **반론/저항** | "전화하기 귀찮다" / "상담 받으면 안 하기 어려울 것 같다" / "아직 100% 결정한 건 아니다" |
| **필요한 증거** | 상담 프로세스 사전 안내 (소요 시간, 진행 순서), 부담 없는 상담 분위기 안내, 입문 오퍼(정밀 CT + 1:1 상담) 안내 |
| **적합 채널** | 전화, 네이버 예약, 카카오톡 채널 |
| **콘텐츠 유형** | 상담 안내 페이지 ("첫 방문 시 이렇게 진행됩니다"), 간편 예약 시스템, 전화 응대 스크립트 |
| **CTA** | "부담 없이 CT 촬영과 1:1 상담을 받아보세요. 상담 후 결정하셔도 됩니다" |

---

## 6단계: 상담 (Consultation)

> 내원하여 CT 촬영, 구강 검진, 치료 계획 설명을 듣는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "내 뼈 상태는 어떤가?" / "시술 기간은 얼마나 걸리나?" / "통증 관리는 어떻게 하나?" / "총 비용은 정확히 얼마인가?" |
| **고객 심리** | 전문적인 설명과 진심 어린 태도에 신뢰가 형성되면 결정이 빨라진다. 반대로 과도한 업셀링이나 설명 부족은 이탈로 이어진다 |
| **반론/저항** | "생각보다 비용이 많이 나온다" / "다른 곳도 한 번 더 알아보고 싶다" / "지금 바로 결정하기 어렵다" |
| **필요한 증거** | CT 기반 3D 시뮬레이션, 시술 계획서 (단계, 기간, 비용 명세), 유사 케이스 결과 (동의 확보된 전후 사진) |
| **적합 채널** | 오프라인 (원내 상담실) |
| **콘텐츠 유형** | 상담용 시각 자료 (3D 시뮬레이션 화면), 치료 계획서 인쇄물, 비용 안내서 (항목별 명세) |
| **CTA** | "오늘 확인하신 CT 결과를 바탕으로 개인별 치료 계획서를 전달드리겠습니다. 편하실 때 결정해 주세요" |

## 7단계: 시술 (Treatment / Conversion)

> 임플란트 식립 수술을 받는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "수술 당일 준비할 것은?" / "수술 후 바로 일상생활이 가능한가?" / "문제가 생기면 어떻게 하나?" |
| **고객 심리** | 결정 후에도 수술 당일까지 불안감이 남아있다. 사전 안내와 당일 케어가 환자 경험의 핵심이다 |
| **반론/저항** | "마지막까지 불안하다" / "취소하고 싶은 마음이 든다" |
| **필요한 증거** | 수술 전 안내 문자/카톡 (준비사항, 주의사항), 수술 후 관리 안내서, 담당 원장이 직접 수술한다는 확인 |
| **적합 채널** | 카카오톡 알림, 문자, 원내 안내 |
| **콘텐츠 유형** | 수술 전후 안내 메시지, 수술 후 주의사항 카드, 담당 간호사 연락처 안내 |
| **CTA** | "수술 후 불편한 점이 있으시면 언제든 연락 주세요. 담당 간호사가 안내드리겠습니다" |

## 8단계: 사후관리 (Retention & Referral)

> 시술 후 정기 점검, 만족도 확인, 추천/후기로 이어지는 단계

| 항목 | 내용 |
|------|------|
| **고객 질문** | "정기 점검은 얼마나 자주 받아야 하나?" / "임플란트 수명은 어느 정도인가?" / "다른 치아도 추가로 해야 하나?" |
| **고객 심리** | 시술 결과에 만족하면 지인 추천과 온라인 후기 작성 의향이 높아진다. 사후 관리가 꼼꼼하면 추가 시술(다른 부위)도 같은 곳에서 진행하려 한다 |
| **반론/저항** | "굳이 정기 점검까지 가야 하나" / "후기 쓰는 게 귀찮다" |
| **필요한 증거** | 정기 점검 프로그램 안내 (주기, 항목), 사후 보증 정책, 후기 작성 시 혜택 안내 (대가성 명시 필수) |
| **적합 채널** | 카카오톡 알림, 문자, 네이버 플레이스 리뷰 요청 |
| **콘텐츠 유형** | 정기 검진 리마인더, 사후관리 가이드 ("임플란트 오래 쓰는 관리법 3가지"), 후기 작성 안내 (동의 기반) |
| **CTA** | "정기 점검 일정을 카카오톡으로 안내드리겠습니다. 편하실 때 예약해 주세요" |

| 단계 | 핵심 질문 | 핵심 반론 | 핵심 증거 | 주 채널 | 콘텐츠 | CTA |
|------|-----------|-----------|-----------|---------|--------|-----|
| 증상 인지 | 방치해도 되나? | 아직 참을 만하다 | 치아 상실 방치 영향 정보 | 블로그 | 정보성 블로그, 체크리스트 | CT 촬영으로 확인해 보세요 |
| 네이버 검색 | 비용은 얼마? 어디가 잘하나? | 정보가 너무 많다 | 비용 구성 안내, 전문의 경력 | 검색광고 + 블로그 | 비용 가이드, 과정 설명 | 정밀 상담으로 본인 맞춤 계획 확인 |
| 블로그 탐색 | 이 치과가 신뢰할 만한가? | 후기가 광고 같다 | 전문의 자격, 후기, 케이스 수 | 블로그 | 원장 소개, 후기, 전후 사례 | 상담에서 CT 결과와 함께 안내 |
| 플레이스 확인 | 리뷰/위치/시간은? | 리뷰가 적거나 부정적 | 플레이스 리뷰, 시설 사진 | 플레이스 | 정보 최적화, 리뷰 관리 | 네이버 예약으로 편하게 상담 예약 |
| 전화/예약 | 상담만도 가능한가? | 강매당할 것 같다 | 상담 프로세스 안내, 입문 오퍼 | 전화, 네이버 예약 | 상담 안내, 간편 예약 | 부담 없이 상담 받아보세요 |
| 상담 | 내 상태와 비용은? | 생각보다 비싸다 | 3D 시뮬레이션, 치료 계획서 | 오프라인 (원내) | 시각 자료, 비용 명세 | 치료 계획서 전달, 편할 때 결정 |
| 시술 | 수술 후 관리는? | 마지막까지 불안 | 수술 전후 안내, 담당 원장 확인 | 카카오톡, 문자 | 안내 메시지, 주의사항 카드 | 불편하시면 언제든 연락 주세요 |
| 사후관리 | 정기 점검 주기는? | 점검 가기 귀찮다 | 사후 보증, 점검 프로그램 | 카카오톡, 플레이스 | 검진 리마인더, 관리 가이드 | 정기 점검 일정 안내 |
