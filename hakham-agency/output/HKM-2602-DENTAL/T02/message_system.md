## 1. 핵심 메시지

### 구조: What + Why + Proof

> **"정밀 진단부터 사후관리까지, 한 분 한 분에게 맞춘 임플란트를 전문의가 직접 책임집니다."**

| 요소 | 내용 |
|------|------|
| What (우리가 제공하는 것) | CT 정밀 진단 기반 1:1 맞춤 임플란트 시술과 체계적인 사후관리 프로그램 |
| Why (고객에게 중요한 이유) | 사람마다 잇몸뼈 상태, 전신 건강, 생활 습관이 다르기 때문에 개인별 진단과 계획이 시술 결과를 좌우합니다 |
| Proof (믿을 수 있는 근거) | 구강악안면외과 전문의 / 대학병원 수련 경력 / 누적 N건 임플란트 케이스 / 3D CT + 가이드 수술 시스템 / 대한구강악안면임플란트학회 정회원 |

### 검증

- [x] 고객이 3초 내에 이해할 수 있는가
- [x] 경쟁사가 동일하게 주장할 수 없는가 (전문의 직접 + 정밀진단 + 사후관리 패키지 조합)
- [x] 01팀 페르소나의 트리거 문장과 연결되는가 (안전성, 결과 중시)

## 2. 보조 메시지 5개

### 메시지 #1: 안전성 앵글

> "3D CT 촬영과 디지털 가이드 수술로, 식립 위치를 미리 확인한 뒤 진행합니다."

| 항목 | 내용 |
|------|------|
| 앵글 | 수술 전 정밀 장비를 통해 안전하게 진행하는 과정 강조 |
| 대상 페르소나 | 페르소나A (40-60대 본인), 페르소나B (자녀가 부모님 걱정) |
| 해소하는 반대 이유 | 수술이 위험하지 않을까, 실패하면 어쩌나 |
| 활용 채널 | 블로그, 네이버 플레이스 소개글, 검색광고 |

### 메시지 #2: 전문성 앵글

> "대학병원 수련 전문의가 상담부터 시술, 사후 점검까지 직접 진행합니다."

| 항목 | 내용 |
|------|------|
| 앵글 | 의료진의 전문 자격과 경력으로 신뢰를 형성 |
| 대상 페르소나 | 페르소나A (전문성 중시), 페르소나B (부모님께 좋은 곳 찾아드리고 싶은 자녀) |
| 해소하는 반대 이유 | 여기 실력 있는 곳인지 모르겠다, 검증된 곳인지 궁금하다 |
| 활용 채널 | 블로그 원장 소개 콘텐츠, 네이버 플레이스, 검색광고 |

### 메시지 #3: 편의성 앵글

> "1:1 맞춤 상담으로 내 상황에 맞는 치료 계획과 일정을 함께 정합니다."

| 항목 | 내용 |
|------|------|
| 앵글 | 바쁜 일상 속에서도 부담 없이 진행할 수 있는 프로세스 |
| 대상 페르소나 | 페르소나A (시간/절차 부담), 페르소나B (부모님 모시고 가야 하는 자녀) |
| 해소하는 반대 이유 | 오래 걸리나, 몇 번 와야 하나, 절차가 복잡한 건 아닌지 |
| 활용 채널 | 블로그, 검색광고, 네이버 플레이스 이벤트 문구 |

### 메시지 #4: 사후관리 앵글

> "시술 후에도 정기 점검과 관리 프로그램으로 오래 편안하게 사용하실 수 있도록 돕습니다."

| 항목 | 내용 |
|------|------|
| 앵글 | 시술 이후의 책임감 있는 관리 체계 |
| 대상 페르소나 | 페르소나A (장기 유지 걱정), 페르소나B (부모님 사후관리 대신 확인) |
| 해소하는 반대 이유 | 시술 후 문제가 생기면 어떻게 하나, 관리를 안 해주면 어쩌나 |
| 활용 채널 | 블로그, 네이버 플레이스 소개글, 랜딩 대체 CTA |

### 메시지 #5: 비용 합리성 앵글

> "상담 시 개인별 치료 계획과 정확한 비용을 투명하게 안내드립니다."

| 항목 | 내용 |
|------|------|
| 앵글 | 숨겨진 비용 없이 투명하게 안내하는 비용 정책 |
| 대상 페르소나 | 페르소나A (비용 부담 고민), 페르소나B (부모님 치료비 알아보는 자녀) |
| 해소하는 반대 이유 | 임플란트가 비싸다, 추가 비용이 발생하는 건 아닌지 |
| 활용 채널 | 블로그 비용 관련 콘텐츠, 검색광고, 네이버 플레이스 이벤트 문구 |
