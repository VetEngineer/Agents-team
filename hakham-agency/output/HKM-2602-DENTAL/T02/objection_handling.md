## 반론 처리 프레임워크

모든 반론은 다음 4단계로 처리한다:

```
공감 → 사실 → 증거 → CTA
```

1. **공감**: 고객의 걱정이 타당함을 인정한다
2. **사실**: 객관적 정보로 관점을 재구성한다
3. **증거**: 구체적 근거를 제시한다
4. **CTA**: 다음 행동을 자연스럽게 제안한다
