## 5. 블로그 콘텐츠 제작 가이드

### 5-1. 콘텐츠 구조 (표준 템플릿)

```
[1] 타이틀 (SEO 키워드 포함, 30자 이내)
[2] 도입부 (공감/질문으로 시작, 3-5줄)
    - 독자의 상황에 공감하거나 질문을 던져 읽기를 유도
[3] 본문 (정보 제공, 소제목 2-4개)
    - 소제목별 핵심 정보를 3-5줄 단위로 전달
    - 리스트, 표 등으로 가독성 확보
    - 전문 용어는 괄호 안에 쉬운 설명 병기
[4] 스마일플러스치과의 경우 (자연스러운 자사 소개)
    - 위 정보와 연결하여 "저희는 이렇게 합니다" 형태
    - 과장 없이 사실 기반 차별점 1-2개 언급
[5] CTA 모듈 (표준 CTA 모듈 A 또는 B 삽입)
```

### 5-2. 톤 규칙

| 항목 | 기준 |
|------|------|
| 문체 | "-습니다" 체 기본, 필요 시 "-요" 체 혼합 |
| 문장 길이 | 1문장 30자 이내 권장, 최대 50자 |
| 문단 길이 | 3-5줄 후 줄바꿈 |
| 전문성 비중 | 80% |
| 친근함 비중 | 20% |

### 5-3. 이미지 방향

| 위치 | 이미지 유형 | 가이드 |
|------|-------------|--------|
| 썸네일 | 치과 시설 또는 상담 장면 | 밝은 톤, 텍스트 오버레이 (타이틀 포함), 1200x630px |
| 본문 상단 | 원장 프로필 또는 장비 사진 | 깨끗한 배경, 자연광 느낌, 전문적 인상 |
| 본문 중간 | 설명 도식 또는 인포그래픽 | 시술 과정 도식, 비교표, 체크리스트 그래픽 |
| 본문 하단 | 시설 내부 또는 진료 환경 | 청결하고 밝은 공간, 환자 동선이 보이는 구도 |

### 5-4. 이미지 금지사항

- 수술 장면(피, 절개 부위 등) 직접 노출 금지
- 환자 얼굴이 식별 가능한 사진 (별도 동의 없이) 금지
- 촬영 조건이 다른 전후 비교 사진 금지
- 타 의료기관 사진 무단 사용 금지
- 과도하게 보정된 전후 사진 금지
- 스톡 이미지 중 비현실적인 미소/결과물 사진 지양

### 5-5. 콘텐츠 금지사항

- 금지 표현 32개 절대 사용 금지 (message_system.md 6장 참조)
- 타 치과/병원 이름을 언급하거나 비교하는 내용 금지
- "이대로 두면 큰일 납니다" 등 공포 마케팅 금지
- "모든 분이 만족하셨습니다" 등 전수 단정 표현 금지
- 검증되지 않은 수치/통계 인용 금지
- console.log 등 코드 잔재 포함 금지 (마크다운 원고 작성 시 확인)

## 6. 네이버 플레이스 사진 가이드

### 6-1. 필수 촬영 카테고리

| # | 카테고리 | 촬영 대상 | 목적 | 권장 수량 |
|---|----------|-----------|------|-----------|
| 1 | 시설 외관 | 건물 외관, 간판, 입구 | 찾아오기 쉽게 / 첫인상 형성 | 2-3장 |
| 2 | 시설 내부 | 대기실, 접수처, 복도 | 청결하고 쾌적한 공간 인식 | 3-5장 |
| 3 | 진료실 | 진료 체어, 진료 공간 | 전문적이고 깨끗한 진료 환경 | 2-3장 |
| 4 | 정밀 장비 | 3D CT, 디지털 가이드 장비 | 기술력/전문성 증명 | 2-3장 |
| 5 | 원장/의료진 | 원장 프로필 사진, 진료복 착용 | 전문의 신뢰감 형성 | 2-3장 |
| 6 | 상담 장면 | 원장이 모니터로 설명하는 장면 | 1:1 맞춤 상담 프로세스 증명 | 1-2장 |

### 6-2. 촬영 톤 가이드

| 항목 | 기준 |
|------|------|
| 조명 | 밝은 자연광 또는 밝은 실내조명. 어두운 분위기 금지 |
| 컬러 톤 | 밝고 깨끗한 화이트/블루 톤 기반 |
| 구도 | 정돈된 공간이 보이도록. 어수선한 배경 정리 후 촬영 |
| 인물 촬영 | 진료복 착용, 자연스러운 미소 또는 진지한 진료 모습. 과도한 포즈 금지 |
| 장비 촬영 | 장비명이 보이도록 라벨/화면 포함. 사용 중인 느낌 (전원 ON 상태) |

### 6-3. 사진 금지사항

- 환자 얼굴/신체가 식별 가능한 사진 (동의 없이) 금지
- 수술 진행 중 사진 금지
- 피, 혈액, 발치된 치아 등 혐오 유발 이미지 금지
- 과도한 필터/보정 금지 (밝기/대비 보정 정도만 허용)
- 타 의료기관 사진 도용 금지
- 오래된 시설 사진 (현재 시설과 다른 사진) 사용 금지

### 6-4. 사진 업로드 규격

| 플랫폼 | 권장 사이즈 | 파일 형식 | 비고 |
|--------|-------------|-----------|------|

| 네이버 플레이스 메뉴/서비스 | 최소 480x480px | JPG/PNG | 정사각형 또는 가로형 |
