## 2. 서비스별 설명 카피

### 2-1. 임플란트 (핵심 서비스)

**서비스명**: 맞춤 임플란트

**설명 카피**:

```
치아를 상실하셨거나 틀니가 불편하신 분을 위한 맞춤 임플란트입니다.

3D CT로 잇몸뼈 상태를 정밀하게 확인한 뒤, 디지털 가이드 시스템으로
식립 위치를 사전에 설계하여 진행합니다.

전문의가 상담부터 시술, 사후 점검까지 직접 담당하며,
개인 상태에 따라 적합한 임플란트 종류와 방법을 안내드립니다.

- 단일 임플란트 / 다수 임플란트 / 전악 임플란트
- 뼈이식이 필요한 경우에도 상담 후 진행 가능
- 시술 후 정기 점검 프로그램 운영
```

### 2-2. 보철 치료

**서비스명**: 보철 치료 (크라운/브릿지)

**설명 카피**:

```
손상된 치아를 기능적으로 회복하기 위한 보철 치료입니다.

개인별 교합 상태와 잔존 치아 상태를 진단한 뒤,
크라운, 브릿지 등 적합한 방법을 안내드립니다.

자연치아를 살릴 수 있는 경우에는 보존 치료를 우선 검토합니다.
```

### 2-3. 일반 치과 진료

**서비스명**: 일반 치과 진료

**설명 카피**:

```
스케일링, 충치 치료, 잇몸 치료 등 기본 치과 진료를 제공합니다.

정기적인 구강 검진을 통해 작은 문제를 조기에 확인하고,
필요한 치료를 미리 계획하실 수 있습니다.
```

## 4. 이벤트 문구 2종

> 네이버 플레이스 이벤트 탭 및 블로그 공지용. 의료광고법 준수하여 과도한 혜택 표현 배제.

### 이벤트 문구 1: 입문 오퍼 (CT + 1:1 상담)

**제목**: 임플란트 1:1 맞춤 상담 안내

**본문**:

```
임플란트가 궁금하신 분을 위해 CT 촬영 기반 1:1 맞춤 상담을 진행합니다.

- 3D CT 촬영으로 잇몸뼈 상태 확인
- 전문의가 직접 개인별 치료 가능 여부 및 방법 안내
- 상담 소요 시간: 약 30분

전화 또는 네이버 예약으로 신청해 주세요.
(CT 촬영 비용은 상담 시 안내드립니다)
```

### 이벤트 문구 2: 사후관리 프로그램 안내

**제목**: 임플란트 시술 후 정기 점검 프로그램

**본문**:

```
스마일플러스치과의원에서 임플란트 시술을 받으신 분을 대상으로
정기 점검 프로그램을 운영합니다.

- 시술 후 주기적인 상태 확인 및 관리
- 문제 조기 발견을 위한 정기 검진
- 구강 위생 관리 안내

시술 후 관리가 임플란트의 장기적인 유지에 중요합니다.
자세한 내용은 상담 시 안내드리겠습니다.
```
