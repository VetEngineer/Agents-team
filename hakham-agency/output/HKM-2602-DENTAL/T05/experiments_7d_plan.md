## 실험 1: 검색광고 헤드라인 A/B 테스트 (안전성 vs 전문성 앵글)

### 가설

> **광고그룹 1(임플란트 핵심)의 헤드라인을 안전성 앵글에서 전문성 앵글로 바꾸면 CTR이 15% 이상 개선될 것이다.**

| 항목 | 내용 |
|------|------|
| **실험명** | 핵심 키워드 헤드라인 앵글 테스트: 안전성 vs 전문성 |
| **배경** | 임플란트 핵심 키워드 그룹은 전체 예산의 70%를 차지하는 주력 그룹이다. 헤드라인 앵글에 따라 CTR과 전환율이 크게 달라질 수 있으나, 현재 어떤 앵글이 더 효과적인지 데이터가 없다. 40-60대 타깃이 "안전한 시술"에 더 반응하는지, "전문의 경력"에 더 반응하는지 확인이 필요하다 |
| **가설** | 헤드라인을 안전성 앵글("CT정밀검사 후 맞춤 임플란트")에서 전문성 앵글("대학병원 수련 전문의 진료")로 변경하면 CTR이 15% 이상 개선될 것이다 |
| **변경 변수 (1개)** | 광고 제목 (헤드라인 카피만 변경, 설명문/도착URL/입찰가는 동일 유지) |

### 대조군 vs 실험군

| 구분 | 대조군 (A) | 실험군 (B) |
|------|-----------|-----------|
| 제목 | "CT정밀검사 후 맞춤 임플란트" (안전성 앵글) | "대학병원 수련 전문의 진료" (전문성 앵글) |
| 설명문 | 동일 (세트 A-1 설명문) | 동일 (세트 A-1 설명문) |
| 도착 URL | 동일 (네이버 플레이스) | 동일 (네이버 플레이스) |
| 입찰가 | 동일 | 동일 |
| 키워드 | 동일 (임플란트 핵심 그룹) | 동일 (임플란트 핵심 그룹) |
| 트래픽 배분 | 50% (광고 교대 노출) | 50% (광고 교대 노출) |

### 측정 계획

| 항목 | 내용 |
|------|------|
| **주 측정 지표** | CTR (클릭률) |
| **보조 지표** | 전화 클릭수, 플레이스 방문 후 체류시간 |
| **성공 기준** | CTR이 대조군 대비 15% 이상 높으면 성공 |
| **실패 기준** | CTR이 대조군 대비 20% 이상 낮으면 즉시 중단 |
| **필요 샘플** | 각 군 최소 300노출, 15클릭 이상 |
| **예상 일일 트래픽** | 약 100-150노출/일 (핵심 그룹 기준) |
| **통계 유의수준** | 95% 신뢰구간 (소규모이므로 방향성 판단 위주) |

### 성과 예측

예상 범위: CTR [3.5%~6.5%], 전환 [3건~7건]

- 대조군(안전성 앵글) 예상 CTR: 3.5~5.0%
- 실험군(전문성 앵글) 예상 CTR: 4.5~6.5%
- 7일간 예상 전환(전화 클릭): 3~7건 (일 평균 0.5~1건)
- 예상 CPA 범위: 7만~13만원

| D1 | 실험 시작, 노출/클릭 데이터 정상 수집 확인 |
| D2-3 | 중간 모니터링 (이상치 확인, 특정 시간대 편중 여부 확인) |
| D4 | 중간 점검: 누적 노출 600 이상인지 확인, 조기 종료 기준 판단 |
| D5-6 | 데이터 누적 지속, 요일별 편차 확인 |
| D7 | 실험 종료, 데이터 수집 마감 |
| D8 | 결과 분석, 학습 기록, 승리 소재 확정 후 전환 |

## 실험 2: 시간대별 입찰가 조정 테스트

### 가설

> **18:00-21:00 시간대의 입찰가를 30% 인상하면 해당 시간대 전환수가 40% 이상 증가할 것이다.**

| 항목 | 내용 |
|------|------|
| **실험명** | 저녁 시간대(18-21시) 입찰가 인상 테스트 |
| **배경** | 퇴근 후 시간대(18:00-21:00)는 가족과 상의 후 검색하는 패턴이 예상되며, 전환 의도가 높을 수 있다. 현재 모든 시간대에 동일 입찰가를 적용 중이라면, 전환율이 높은 시간대에 집중 투자하여 CPA를 개선할 수 있다. 기존 시간대 설정(+15%)보다 공격적인 +30%를 테스트하여 최적 입찰가 가중치를 찾는다 |
| **가설** | 18:00-21:00 입찰가를 기본 대비 30% 인상하면 해당 시간대 노출 순위가 올라가고, 전환수가 40% 이상 증가할 것이다 |
| **변경 변수 (1개)** | 18:00-21:00 시간대 입찰가 가중치 (기존 +15% -> 실험 +30%) |

### 대조군 vs 실험군

| 구분 | 대조군 (A) - 1주차 | 실험군 (B) - 2주차 |
|------|-------------------|-------------------|
| 18:00-21:00 입찰가 가중치 | +15% (기존 설정) | +30% (인상) |
| 나머지 시간대 입찰가 | 동일 | 동일 |
| 소재 | 동일 | 동일 |
| 키워드 | 동일 | 동일 |
| 비교 방식 | 전후 비교 (동일 요일 비교) | 전후 비교 (동일 요일 비교) |

참고: 네이버 검색광고는 동시 A/B 분할이 어려우므로, 1주차(대조군) -> 2주차(실험군) 전후 비교 방식으로 진행한다.

### 측정 계획

| 항목 | 내용 |
|------|------|
| **주 측정 지표** | 18:00-21:00 시간대 전환수 (전화 클릭 + 예약) |
| **보조 지표** | 해당 시간대 CPC, 해당 시간대 CPA |
| **성공 기준** | 18:00-21:00 전환수 40% 이상 증가, CPA 목표(10만원) 유지 |
| **실패 기준** | CPA가 15만원을 초과하면 즉시 원복 |
| **필요 샘플** | 해당 시간대 최소 50클릭/주 |
| **예상 일일 트래픽** | 18:00-21:00 기준 약 15-25클릭/일 |
| **통계 유의수준** | 전후 비교이므로 동일 요일 대비 변화율 위주 판단 |

### 성과 예측

예상 범위: CTR [4%~7%], 전환 [4건~9건]

- 대조군(+15% 가중) 18-21시 예상 전환: 주 2~4건
- 실험군(+30% 가중) 18-21시 예상 전환: 주 4~9건
- 예상 CPC 변화: +10~20% (입찰가 인상에 따른 CPC 상승)
- 예상 CPA 범위: 8만~15만원 (CPA 15만원 초과 시 즉시 원복)

### 실행 일정

| 일차 | 할 일 |
|------|-------|
| D-1 | 1주차(대조군) 데이터 기록 확인, 시간대별 데이터 추출 방법 세팅 |
| D1 | 18:00-21:00 입찰가 가중치 +15% -> +30%로 변경 |
| D2-3 | 해당 시간대 노출/클릭/비용 모니터링, CPC 변화 확인 |
| D4 | 중간 점검: CPA 15만원 초과 여부 확인, 예산 소진 속도 점검 |
| D5-6 | 데이터 누적, 요일별 패턴 확인 |
| D7 | 실험 종료, 1주차(대조군) vs 2주차(실험군) 동일 요일 비교 |
| D8 | 결과 분석, 최적 입찰가 가중치 결정 |

## 실험 3: 플레이스 소개글 변경 (전환율 변화 측정)

### 가설

> **플레이스 소개글을 핵심 메시지 + CTA 구조로 변경하면 플레이스 방문 대비 전화 클릭 전환율이 25% 이상 개선될 것이다.**

| 항목 | 내용 |
|------|------|
| **실험명** | 플레이스 소개글 리라이팅 전환율 테스트 |
| **배경** | 현재 플레이스 소개글은 일반적인 치과 소개 문구로, 임플란트 전문성이 드러나지 않고 행동 유도 요소(CTA)가 없다. 검색광고를 통해 플레이스에 도달한 고객의 전화 클릭 전환율이 낮다면, 소개글이 검색 의도와 불일치하는 것이 원인일 수 있다. CRO 백로그 1순위 항목의 효과를 실제 데이터로 검증한다 |
| **가설** | 소개글을 "핵심 메시지(전문의 책임 진료) + 차별점 3줄 + CTA" 구조로 변경하면 플레이스 방문 대비 전화 클릭 전환율이 25% 이상 개선될 것이다 |
| **변경 변수 (1개)** | 네이버 플레이스 소개글 텍스트 (사진, 영업시간, 기타 정보는 변경하지 않음) |

### 대조군 vs 실험군

| 구분 | 대조군 (A) - 변경 전 1주 | 실험군 (B) - 변경 후 1주 |
|------|------------------------|------------------------|
| 소개글 | 기존 일반 소개글 (예: "스마일플러스치과의원입니다. 친절한 진료를 약속합니다.") | 리라이팅 소개글: "구강악안면외과 전문의가 상담부터 시술, 사후 관리까지 직접 책임지는 임플란트 전문 치과입니다. / 3D CT 정밀 진단 / 개인별 맞춤 시술 계획 / 체계적 사후 관리 프로그램 / 임플란트 상담은 전화 또는 예약으로 편하게 문의해 주세요." |
| 사진 | 동일 | 동일 |
| 영업시간/기타 | 동일 | 동일 |
| 비교 방식 | 전후 비교 (변경 전 1주 vs 변경 후 1주) | 전후 비교 |

### 측정 계획

| 항목 | 내용 |
|------|------|
| **주 측정 지표** | 플레이스 방문 대비 전화 클릭 전환율 (전화 클릭수 / 플레이스 조회수) |
| **보조 지표** | 전화 클릭 절대수, 예약 클릭수 |
| **성공 기준** | 전화 클릭 전환율 25% 이상 개선 |
| **실패 기준** | 전화 클릭 전환율 15% 이상 하락 시 소개글 원복 |
| **필요 샘플** | 플레이스 주간 조회수 최소 200회 이상 |
| **예상 일일 트래픽** | 약 30-50 플레이스 조회/일 (검색광고 유입 기준) |
| **통계 유의수준** | 전후 비교, 동일 요일 대비 변화율 위주 판단 |

### 성과 예측

예상 범위: CTR [3%~5%], 전환 [5건~12건]

- 대조군(기존 소개글) 전화 클릭 전환율: 약 2~3%
- 실험군(리라이팅 소개글) 전화 클릭 전환율: 약 3~5%
- 7일간 예상 전화 클릭 증가: 5~12건 추가 전환 예상
- 예상 전화 클릭 전환율 개선폭: +25~50%

### 실행 일정

| 일차 | 할 일 |
|------|-------|
| D-1 | 변경 전 1주 데이터 확보 확인 (플레이스 조회수, 전화 클릭수), 새 소개글 최종 확정 (원장 검수), 의료광고법 금지 표현 최종 체크 |
| D1 | 플레이스 소개글 변경 적용 |
| D2-3 | 전화 클릭수 변화 모니터링, 이상치 확인 |
| D4 | 중간 점검: 전환율 방향성 확인, 급격한 하락 시 원복 판단 |
| D5-6 | 데이터 누적, 요일별 패턴 확인 |
| D7 | 실험 종료, 변경 전 1주 vs 변경 후 1주 비교 |
| D8 | 결과 분석, 소개글 확정 또는 원복 결정, 학습 기록 |
