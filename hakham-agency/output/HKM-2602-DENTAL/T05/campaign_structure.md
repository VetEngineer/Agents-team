| 연령대 | 입찰가 가중치 | 근거 |
|--------|-------------|------|
| 40대 | +20% | 핵심 타깃 (자발적 검색 비율 높음) |
| 50대 | +30% | 최핵심 타깃 (건강보험 적용 연령 포함) |

## 4. 입찰 전략

| 항목 | 내용 |
|------|------|
| 입찰 방식 | 수동 CPC (초기 데이터 축적 단계) |
| 초기 입찰가 범위 | 키워드별 500~3,500원 |
| 입찰가 조정 주기 | 3일마다 (데이터 기반 조정) |
| 1순위 노출 전략 | 핵심 키워드 5개만 상위 노출 집중, 나머지는 비용 효율 우선 |
| 최대 CPC 한도 | 3,500원 (이 이상은 ROI 역전 리스크) |

### 입찰가 조정 기준

| 조건 | 액션 |
|------|------|
| 전환 발생 + CPA 목표 이내 | 입찰가 10% 인상 (볼륨 확대) |
| 클릭 있으나 전환 없음 (7일 이상) | 소재 점검 후 입찰가 20% 인하 |
| CTR 3% 미만 | 소재 교체 우선, 입찰가 유지 |
| 노출 부족 (일 노출 100 미만) | 입찰가 15% 인상 |

| 지표 | 목표값 | 측정 방법 |

| 전환율 (클릭 -> 전환) | 3% 이상 | 전환수 / 클릭수 |
