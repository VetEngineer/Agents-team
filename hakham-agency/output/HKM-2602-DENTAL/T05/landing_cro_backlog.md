## 개선안 상세

### 1순위: 플레이스 소개글 최적화

| 항목 | 내용 |
|------|------|
| **개선 영역** | 네이버 플레이스 소개글 |
| **현재 상태** | 일반적인 치과 소개 문구 (예: "스마일플러스치과의원입니다. 친절한 진료를 약속합니다."). 임플란트 전문성이 드러나지 않고, 행동 유도 요소가 없음 |
| **문제점** | 검색광고를 통해 플레이스에 도착한 고객이 "여기가 맞는 곳인지" 즉시 판단할 수 없음. 핵심 차별점(전문의, 정밀 장비)이 소개글에 없어 이탈률이 높을 수 있음. 전화/예약으로 이어지는 CTA가 부재 |
| **개선안** | 소개글을 아래 구조로 재작성: (1) 1줄 핵심 메시지: "구강악안면외과 전문의가 상담부터 시술, 사후 관리까지 직접 책임지는 임플란트 전문 치과입니다." (2) 차별점 3줄: 3D CT 정밀 진단 / 개인별 맞춤 시술 계획 / 체계적 사후 관리 프로그램 (3) CTA: "임플란트 상담은 전화 또는 예약으로 편하게 문의해 주세요." |
| **예상 임팩트** | 상 - 플레이스 방문 후 전화/예약 전환율 20-30% 개선 예상 (소개글이 검색 의도와 일치하면 이탈률 감소) |
| **구현 난이도** | 하 - 텍스트 변경만 필요 (플레이스 관리자에서 직접 수정) |
| **담당** | 카피라이터 + 원장 확인 |
| **예상 소요** | 1일 |
| **측정 방법** | 변경 전후 7일간 전화 클릭수, 예약수 비교 |

### 2순위: 대표 사진 전략적 교체

| 항목 | 내용 |
|------|------|
| **개선 영역** | 네이버 플레이스 대표 사진 및 사진 갤러리 |
| **현재 상태** | 외관 사진 또는 오래된 인테리어 사진만 등록. 의료 장비, 진료실 내부, 원장 사진이 없거나 화질이 낮음. 사진이 5장 미만으로 정보 부족 |
| **문제점** | 임플란트를 검토하는 고객은 시설 수준과 의료진 신뢰도를 사진으로 먼저 판단함. 대표 사진이 낡으면 "오래된 치과"로 인식되어 전환 저해. 장비 사진이 없으면 전문성 인식 부족 |
| **개선안** | 대표 사진 10장 이상으로 교체/추가: (1) 원장 프로필 사진 (진료복 착용, 밝은 표정) (2) 진료실 내부 (청결하고 현대적인 느낌) (3) CT/디지털 장비 클로즈업 (4) 대기실/접수 공간 (5) 상담실 (1:1 상담 분위기). 사진 촬영 가이드: 밝은 조명, 정리된 공간, 전문적 분위기. 수술 장면 직접 노출 금지 (의료광고법) |
| **예상 임팩트** | 상 - 플레이스 체류시간 증가 및 전화 클릭율 15-25% 개선 예상 |
| **구현 난이도** | 중 - 전문 촬영 필요 (반나절 소요) |
| **담당** | 촬영 담당 + 원장 협조 |
| **예상 소요** | 3일 (촬영 1일 + 보정 1일 + 업로드 1일) |
| **측정 방법** | 교체 전후 7일간 플레이스 사진 조회수, 전화 클릭수 비교 |

### 3순위: 영업시간 및 예약 정보 정확성 정비

| 항목 | 내용 |
|------|------|
| **개선 영역** | 네이버 플레이스 영업시간, 예약 기능, 연락처 |
| **현재 상태** | 영업시간이 부정확하거나 업데이트되지 않았을 가능성. 점심시간, 토요일 진료시간 미표기. 네이버 예약 기능이 활성화되지 않았거나 예약 가능 시간이 제한적 |
| **문제점** | 영업시간 불일치는 플레이스 신뢰도를 저하시킴. "지금 전화해도 되나?"를 판단할 수 없으면 전화를 미룸 (= 이탈). 예약 기능 미활성화 시 전환 경로가 전화 1개로 제한됨 |
| **개선안** | (1) 영업시간 정확 업데이트: 평일/토요일/점심시간/공휴일 모두 명시 (2) 네이버 예약 기능 활성화: 상담 예약 가능 시간대를 30분 단위로 설정 (3) 전화번호 확인: 대표번호가 상담 전용 번호인지 확인, 부재 시 콜백 안내 문구 추가 (4) "지금 진료 중" 상태 표시 활용 |
| **예상 임팩트** | 상 - 예약 기능 활성화만으로 전환 경로 2배 확보. 정확한 영업시간은 즉시 전화 전환율 10-15% 개선 예상 |
| **구현 난이도** | 하 - 플레이스 관리자에서 직접 설정 (30분 소요) |
| **담당** | 운영 담당자 |
| **예상 소요** | 1일 |
| **측정 방법** | 네이버 예약 기능 활성화 전후 예약수 비교, 전화 클릭수 추이 |

### 4순위: 이벤트/소식 등록 (CT 정밀 상담 안내)

| 항목 | 내용 |
|------|------|
| **개선 영역** | 네이버 플레이스 소식/이벤트 탭 |
| **현재 상태** | 소식/이벤트 탭이 비어 있거나 오래된 게시물만 존재. 활성화되지 않아 플레이스 노출 우선순위에도 불리 |
| **문제점** | 플레이스 알고리즘은 최신 소식이 있는 업체를 상위 노출하는 경향. 이벤트가 없으면 방문 고객에게 "지금 연락해야 하는 이유"를 제공하지 못함. 경쟁 치과 대비 정보 부족으로 인식 |
| **개선안** | (1) 상시 소식 등록: "CT 정밀 검사 + 전문의 1:1 상담 안내" (주 1회 이상 소식 업데이트) (2) 소식 내용 구성: 제목 - "임플란트 정밀 상담 안내" / 본문 - 3D CT 촬영 후 전문의가 직접 상담하는 프로세스 설명 + 전화번호 (3) 사진 포함: 장비 사진 또는 상담실 사진. 주의: "무료" 표현 금지. "CT 검사 + 상담 안내"로 표현 (환자 유인 방지) |
| **예상 임팩트** | 중 - 플레이스 노출 순위 개선 + 방문 고객 행동 유도. 소식 등록 후 전화 클릭수 10% 내외 증가 예상 |
| **구현 난이도** | 하 - 텍스트 + 사진 1장 등록 (20분 소요) |
| **담당** | 운영 담당자 + 카피라이터 |
| **예상 소요** | 1일 (초기 등록), 이후 주 1회 업데이트 |
| **측정 방법** | 소식 등록 전후 플레이스 조회수, 전화 클릭수 비교 |

### 5순위: 리뷰 확보 프로세스 설계

| 항목 | 내용 |
|------|------|
| **개선 영역** | 네이버 플레이스 리뷰 |
| **현재 상태** | 리뷰 수가 경쟁 치과 대비 적거나 (10개 미만), 최근 리뷰가 3개월 이상 없음. 리뷰 내용에 임플란트 관련 키워드가 적어 검색 연관성 부족 |
| **문제점** | 리뷰 수와 평점은 플레이스 선택의 핵심 요인. 리뷰 3개 미만이면 신뢰도가 크게 떨어짐. 경쟁 치과가 리뷰 50개 이상이면 비교에서 밀림. 최근 리뷰가 없으면 "아직 운영하나?" 의구심 발생 |
| **개선안** | 리뷰 요청 프로세스 구축: (1) 시술 완료 후 1주 시점에 카카오톡/문자로 리뷰 요청 발송 (2) 리뷰 요청 메시지 템플릿 작성: "OOO님, 시술 후 경과가 궁금합니다. 불편한 점은 없으신가요? 저희 치과 이용 경험을 네이버에 남겨주시면 큰 힘이 됩니다." (3) 월 목표: 신규 리뷰 4건 이상 확보 (4) 리뷰 모니터링: 부정적 리뷰 발생 시 24시간 이내 정중한 답변. 주의: 리뷰 대가 제공 시 "본 후기는 OO을 제공받고 작성되었습니다" 반드시 명시. 가짜 리뷰/자작 리뷰 절대 금지 |
| **예상 임팩트** | 중 - 리뷰 10건 이상 도달 시 플레이스 전환율 20% 이상 개선 예상 (장기적 효과). 단기적으로는 월 4건씩 3개월 후 12건 추가 확보 가능 |
| **구현 난이도** | 중 - 프로세스 설계 + 메시지 템플릿 + 직원 교육 필요 |
| **담당** | 운영 담당자 + 프런트 데스크 직원 |
| **예상 소요** | 3일 (프로세스 설계), 이후 지속 운영 |
| **측정 방법** | 월간 신규 리뷰 수, 평점 추이, 플레이스 전환율 변화 |

## 플레이스 CRO 점검 체크리스트

### 기본 정보
- [ ] 업체명이 정확하고 검색 키워드를 포함하는가 (예: "스마일플러스치과의원")
- [ ] 카테고리가 "치과"로 정확히 설정되어 있는가
- [ ] 주소/전화번호/영업시간이 정확한가
- [ ] 네이버 지도에서 위치 핀이 정확한가

### 소개글
- [ ] 첫 문장에서 핵심 서비스(임플란트)를 명시하는가
- [ ] 전문의 자격/경력이 언급되는가
- [ ] 전화 또는 예약을 유도하는 CTA가 있는가
- [ ] 의료광고법 금지 표현이 없는가

### 사진
- [ ] 대표 사진이 전문적이고 밝은 분위기인가
- [ ] 사진이 10장 이상 등록되어 있는가
- [ ] 원장/의료진 사진이 포함되어 있는가
- [ ] 수술 장면 직접 노출이 없는가 (의료광고법)

### 예약/연락
- [ ] 네이버 예약 기능이 활성화되어 있는가
- [ ] 전화번호가 상담 가능한 번호인가
- [ ] 부재 시 콜백 안내가 설정되어 있는가

### 리뷰
- [ ] 최근 1개월 이내 리뷰가 있는가
- [ ] 부정적 리뷰에 답변이 달려 있는가
- [ ] 리뷰 평점이 4.0 이상인가

### 소식/이벤트
- [ ] 최근 2주 이내 소식이 등록되어 있는가
- [ ] 소식 내용이 임플란트 관련인가
- [ ] 소식에 사진이 포함되어 있는가
